5.13 @inforef: Referências cruzadas para material unicamente Info ¶

@inforef é usado para fazer referências cruzadas para documentos Info—mesmo a partir de um manual impresso. Isso originalmente era usado para arquivos Info que não fossem gerados a partir de algum fonte Texinfo. O comando agora está obsoleto e não deveria ser usado. Adicionalmente a ter pouco uso, saída similar pode ser obtida com @xref, @ref ou @pxref com o nome do arquivo Info como o quarto argumento e sem quinto argumento.

O comando recebe ou dois ou três argumentos, na seguinte ordem:

  1. O nome do nó.
  2. O nome da referência cruzada (opcional).
  3. O nome do arquivo Info.

O modelo é: 

@inforef{nome-nó, nome-referência-cruzada, nome-arquivo-info}
