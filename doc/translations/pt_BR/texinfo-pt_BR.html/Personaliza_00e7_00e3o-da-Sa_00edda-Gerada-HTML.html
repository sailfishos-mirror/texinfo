22.8 Personalização da Saída Gerada HTML ¶

Você pode usar muitas variáveis de personalização definíveis por usuário(a) para influenciar a saída HTML. Veja-se Lista de Variáveis de Personalização do HTML para a lista completa. As possibilidades oferecidas pelas variáveis de personalização, que vão desde a estrutura geral do documento e variante da linguagem HTML até a formatação de constructos específicos, deveriam cobrir a maioria das necessidades ainda não satisfeitas pela personalização de CSS (veja-se CSS do HTML).

Se você precisar de mais controle, poderá conseguir isso por meio do uso de arquivos de inicialização, que são descritos em um manual separado (veja-se Personalização da Saída do texi2any do GNU Texinfo).

Se a variável de personalização TEXI2HTML estiver configurada, o HTML gerado será o mais compatível possível com texi2html (veja-se texi2html: Ancestral do texi2any). O efeito dessa variável é bastante incomum, pois ela não modifica diretamente a saída gerada, mas configura muitas outras variáveis de personalização, incluindo algumas que só podem ser configuradas em arquivos de inicialização e estão descritas no manual separado em Personalização de Saída Gerada do texi2any. Desconfigurada no caso padrão.
