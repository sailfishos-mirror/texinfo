14.1 O Modelo Para Uma Definição ¶

@deffn categoria nome argumentos...
corpo-da-definição
@end deffn

O comando @deffn é usado para definições de entidades que se assemelham a funções—entidades que possivelmente recebam argumentos. Escreva o comando @deffn no início de uma linha e siga-o na mesma linha pela categoria da entidade, o nome da entidade em si e os argumentos dela (se existirem). Em seguida, escreva o corpo da definição nas linhas seguintes. Finalmente, termine a definição com um comando @end deffn escrito em uma linha própria.

Por exemplo, 

@deffn Command forward-word count
Esse comando move o ponto para frente @var{count} palavras
(ou para trás, se @var{count} for negativo). ...
@end deffn

produz

Command: forward-word count ¶

Esse comando move o ponto para frente count palavras (ou para trás, se count for negativo). …

Maiusculize o nome de categoria como um título. Se o nome da categoria contiver espaços, como na frase ‘Comando Interativo’, circunde-o em chaves. Por exemplo: 

@deffn {Comando Interativo} isearch-forward
...
@end deffn

Caso contrário, a segunda palavra será confundida com o nome da entidade. Como regra geral, quando quaisquer dos argumentos na linha de título, exceto o último, forem mais que uma palavra, você precisa circundá-los em chaves. Isso também possivelmente seja necessário se o texto contiver comandos, por exemplo, ‘{declaraci@'on}’ se você estiver escrevendo em espanhol.

A categoria é gerada em um local diferente para diferentes formatos de saída. Por exemplo, no arquivo Info, a categoria aparece no início da primeira linha da definição. Com a saída do TeX, a categoria é impressa próxima da margem direita.

@deffn insere nomes no índice das funções.

Três variações predefinidas e especializadas de @deffn (@defun, @defmac e @defspec) especificam a categoria para você: “Função”, “Macro” e “Forma Especial” respectivamente. (Em Lisp, uma forma especial é uma entidade muito parecida com uma função). Similarmente, o comando geral @defvr é acompanhado por diversas variações especializadas para descrever tipos particulares de variáveis.
