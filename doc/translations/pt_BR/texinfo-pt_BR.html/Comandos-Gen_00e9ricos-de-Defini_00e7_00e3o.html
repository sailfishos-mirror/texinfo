14.7 Comandos Genéricos de Definição ¶

O Texinfo fornece comandos para definições que não produzem entradas automáticas de índice.

Você cria um ambiente genérico de definição com ‘@defblock’ emparelhado com ‘@end defblock’. Nesse ambiente, use uma linha @defline ou @deftypeline para cada símbolo que você documentar. Por exemplo: 

@defblock
@defline Macro mac (arg1, arg2)
Descrição de mac.
@deftypeline Builtin int foo (int @var{bar})
Descrição de foo.
@end defblock

Isso produz a saída:

Macro: mac (arg1, arg2)

Descrição de macro.

Builtin: int foo (int bar)

Descrição de foo.

A sintaxe de @defline é semelhante àquela de @deffn. O primeiro argumento fornece uma categoria para a definição. Siga isso com o nome do símbolo, seguido por quaisquer parâmetros. Você deveria envolver com chaves quaisquer argumentos contendo espaços.

Você usa @deftypeline de maneira semelhante a @deftypefn, seguindo a categoria com um tipo de dado e marcando quaisquer parâmetros com @var. (Veja-se Funções em Linguagens Tipadas).

Para compartilhar a mesma descrição para vários símbolos, você pode juntar várias linhas @defline. Por exemplo: 

@defblock
@defline Função set-var (valor)
@defline {Variável Configurável} var
Descrição de set-var e var.
@end defblock

Isso produz a saída:

Function: set-var (value)
Settable Variable: var

Descrição de set-var e de var.

Possivelmente seja útil definir macros de linha (veja-se Macros de Linha) em combinação com esses comandos.
