22.8.5 Personalização de Código HTML Inserido ¶

Existem variáveis para configurar o código HTML inserido em vários pontos da saída gerada.

Aspa de abertura e aspas de fechamento necessárias, por exemplo, para saída @samp, são configuradas como:

&lsquo; e &rsquo;

Por padrão, com OPEN_QUOTE_SYMBOL e CLOSE_QUOTE_SYMBOL desconfiguradas.

&#8216; e &#8217;

Se você configurar USE_NUMERIC_ENTITY.

Um caractere de aspa de abertura e de fechamento

Se você configurar OUTPUT_CHARACTERS e a codificação da saída gerada incluir esse caractere.

OPEN_QUOTE_SYMBOL e CLOSE_QUOTE_SYMBOL

Se você configurar essas variáveis de personalização.

Para mudar o código HTML para quebras (regra horizontal) inseridas em vários contextos, configure DEFAULT_RULE, que é usado para a saída da maioria dos separadores horizontais no HTML resultante, e configure BIG_RULE para o separador mais largo usado algumas vezes.

Você consegue configurar HTML_ROOT_ELEMENT_ATTRIBUTES para adicionar atributos ao elemento <html>. Você pode definir a variável EXTRA_HEAD para adicionar texto dentro do elemento <head> do HTML. Similarmente, o valor de AFTER_BODY_OPEN é adicionado logo depois que <body> for gerado. Essas variáveis ficam vazias por padrão.

Você consegue configurar os atributos do elemento <body> definindo a variável de personalização BODY_ELEMENT_ATTRIBUTES. Por padrão, o atributo lang é configurado como o idioma do documento (veja-se @documentlanguage ll[_cc]: Configurar o Idioma do Documento).

Você pode definir a variável PRE_BODY_CLOSE para adicionar texto logo antes do elemento </body> do HTML. Nada é adicionado por padrão.

Similarmente, as seguintes variáveis permitem algum controle útil da formatação do sumário e do sumaríssimo:

BEFORE_TOC_LINES ¶

Inserido antes do texto do sumário.

AFTER_TOC_LINES ¶

Inserido depois do texto do sumário.

BEFORE_SHORT_TOC_LINES ¶

Inserido antes do texto do sumaríssimo.

AFTER_SHORT_TOC_LINES ¶

Inserido depois do texto do sumaríssimo.

Ao tempo desta escrita, os valores padrão dessas variáveis eram configurados como etiquetas de abertura e de fechamento para um elemento <div> que encerra os sumários.
