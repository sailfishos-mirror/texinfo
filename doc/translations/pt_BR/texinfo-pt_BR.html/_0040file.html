6.1.9 @file{nome-arquivo} ¶

Use o comando @file para indicar texto que seja o nome de um arquivo, buffer, ou diretório, ou seja o nome de um nó no Info. Você também consegue usar o comando para sufixos de nome de arquivo. Não use @file para símbolos em uma linguagem de programação; use @code.

@file é equivalente a code nos efeitos dele. Por exemplo, 

Os arquivos @file{.el} estão no
diretório @file{/usr/local/emacs/lisp}.

produz

Os arquivos .el estão no diretório /usr/local/emacs/lisp.
