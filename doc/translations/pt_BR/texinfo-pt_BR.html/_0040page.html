13.8 @page: Comece uma Nova Página ¶

Uma linha contendo somente @page inicia uma nova página em um manual impresso. Em outros formatos, sem o conceito de páginas, ele inicia um novo parágrafo. Um comando @page frequentemente é usado em uma seção @titlepage de um arquivo do Texinfo para iniciar a página de copirraite.
