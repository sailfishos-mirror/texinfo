6.2 Enfatizando Texto ¶

Normalmente, Texinfo muda a fonte para marcar palavras no texto de acordo com a categoria a que as palavras pertencem; um exemplo é o comando @code. Na maioria das vezes, essa é a melhor maneira para marcar palavras. Entretanto, ocasionalmente, você desejará enfatizar texto sem indicar uma categoria. Texinfo tem dois comandos para fazer isso. Além disso, Texinfo tem vários comandos que especificam a fonte na qual o texto será gerado. Esses comandos não tem efeito no Info e somente um deles, o comando @r, tem algum uso regular.

  • @emph{texto} e @strong{texto}
  • @sc{texto}: A Fonte de Versaletes
  • Fontes para Impressão
