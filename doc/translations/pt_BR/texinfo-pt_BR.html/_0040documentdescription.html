22.4 @documentdescription: Texto do Sumário ¶

Ao produzir saída HTML para um documento, um elemento ‘<meta>’ é escrito no ‘<head>’ para dar alguma ideia do conteúdo do documento. Por padrão, essa descrição será o título do documento, tomado a partir do comando @settitle (veja-se @settitle: Configura o Título do Documento). Para mudar isso, use o ambiente @documentdescription, como em: 

@documentdescription
texto descritivo.
@end documentdescription

Isso produzirá a seguinte saída no ‘<head>’ do HTML: 

<meta name=description content="texto descritivo.">
