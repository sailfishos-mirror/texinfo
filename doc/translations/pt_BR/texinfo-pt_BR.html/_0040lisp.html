7.6 @lisp: Marcando um Exemplo da Lisp ¶

O comando @lisp é muito semelhante ao @example, porém marca o conteúdo como código Lisp. Por exemplo: 

@lisp
Código lisp de exemplo
@end lisp

A linguagem de programação também pode ser fornecida como um argumento para o comando @example (veja-se @example: Texto de Exemplo), de modo que o exemplo acima também poderia ser escrito como: 

@example lisp
Código lisp de exemplo
@end example

Use @lisp para preservar informações relativas à natureza do exemplo. Isso é útil, por exemplo, se você escrever uma função que avalia somente e todo o código Lisp em um arquivo do Texinfo. Então você consegue usar o arquivo do Texinfo como uma biblioteca Lisp.
