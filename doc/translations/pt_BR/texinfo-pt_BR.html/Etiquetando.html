D.9.1 Etiquetando um Arquivo ¶

Os processadores do Texinfo criam tabelas de etiquetas automaticamente. A única exceção surge quando texinfo-format-buffer é chamado com um prefixo, como C-u M-x texinfo-format-buffer, para criar um arquivo não dividido do Info sem uma tabela de etiquetas (a qual pode ser útil em alguns casos para validação do arquivo do Info, veja-se Criando um Arquivo Desdividido e Adicionando uma Tabela de Etiquetas). Adicionar uma tabela de etiquetas é, portanto, mais útil geralmente para arquivos do Info escritos manualmente.

Para criar uma tabela de etiquetas para um arquivo não dividido, visite o arquivo do Info que você desejar etiquetar e digite: 

M-x Info-tagify

(Observe o ‘I’ maiúsculo no Info-tagify). Isso cria um arquivo do Info com uma tabela de etiquetas. Uma tabela de etiquetas faz parte de um bem formado arquivo do Info (veja-se Arquivos de Etiqueta e Arquivos Divididos). Uma tabela de etiquetas também é necessária para validar ou para dividir o arquivo do Info.
