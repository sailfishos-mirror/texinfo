7.1 Comandos de Cercamento de Blocos ¶

Aqui está um resumo de comandos que circundam blocos de texto, também conhecidos como ambientes. Eles estão mais explicados nas seções seguintes.

@quotation

Indica texto que seja aspeado. O texto é preenchido, recuado (a partir de ambas as margens) , e impresso em uma fonte romana por padrão.

@indentedblock

Como @quotation, mas o texto é recuado somente na esquerda.

@example

Ilustra código, comandos, e afins. O texto é impresso em uma fonte de largura fixa, e recuado, mas não preenchido.

@lisp

Como @example, mas especificamente para ilustrar código Lisp. O texto é impresso em uma fonte de largura fixa, e recuado, mas não preenchido.

@verbatim

Marca um pedaço de texto que seja para ser impresso literalmente; nenhuma substituição de caractere é feita e todos os comandos são ignorados, até o próximo @end verbatim. O texto é impresso em uma fonte de largura fixa, e não é recuado ou preenchido. Espaços extras e linhas em branco são significantes, e tabulações são expandidas.

@display

Exibe texto ilustrativo. O texto é recuado, mas não preenchido, e nenhuma fonte é selecionada (então, por padrão, a fonte é romana).

@format

Como @display (o texto não é preenchido e nenhuma fonte é selecionada), mas o texto não é recuado.

@smallquotation
@smallindentedblock
@smallexample
@smalllisp
@smalldisplay
@smallformat

Esses comandos @small... são exatamente semelhantes aos equivalentes deles não-small, exceto que geram texto em um tamanho de fonte menor, quando possível.

@flushleft
@flushright

O texto não é preenchido, mas é alinhado com a margem esquerda ou direita, respectivamente.

@raggedright

O texto é preenchido, mas justificado somente na esquerda, deixando a margem direita irregular.

@cartouche

Realça o texto, frequentemente um exemplo ou uma citação, desenhando uma caixa com cantos arredondados em torno dele.

O comando @exdent é usado dentro das construções acima para desfazer o recuo de uma linha.

O comando @noindent pode ser usado depois de uma das construções acima (ou no início de qualquer parágrafo) para evitar que o texto seguinte seja recuado como um novo parágrafo.
