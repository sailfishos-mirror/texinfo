20.4.8 Variáveis de Personalização para Múltiplos Formatos ¶

Esta tabela fornece a personalização que se aplica para múltiplos formatos.

CLOSE_QUOTE_SYMBOL ¶

Quando uma aspa de fechamento for necessária, por exemplo, para saída gerada do @samp, usar esse caractere; padrão &#8217; no DocBook. Indefinida no caso padrão em HTML e configurada como &rsquo; se USE_NUMERIC_ENTITY não estiver configurada, como &#8217; se configurada e como um caractere de aspa se OUTPUT_CHARACTERS estiver configurada e a codificação da saída gerada incluir esse caractere.

O padrão para Info é configurada da mesma forma que para OPEN_QUOTE_SYMBOL, exceto que o código Unicode é uma aspa de fechamento (veja-se abaixo).

DOCTYPE ¶

Para DocBook, HTML, XML. Especifica o SystemLiteral, o identificador de sistema da entidade. Esse é um URI que pode ser usado para recuperar a entidade e identifica o DTD canônico para o documento. O valor padrão é diferente para HTML, DocBook e XML.

EXTENSION ¶

A extensão adicionada ao nome do arquivo da saída gerada. O padrão é diferente para cada formato da saída gerada.

NO_TOP_NODE_OUTPUT ¶

Se configurada, não produzir o conteúdo do nó Top. O nó Top ainda será analisado, mas o conteúdo será descartado. Não configurada no caso padrão para HTML. Configurada no caso padrão para EPUB. Se SHOW_TITLE for ‘undef’, configurar-se NO_TOP_NODE_OUTPUT também configurará SHOW_TITLE para HTML.

Configurar-se NO_TOP_NODE_OUTPUT, que remove o nó Top e adiciona uma página de título, corresponde mais à formatação de um livro. Configurar-se NO_TOP_NODE_OUTPUT como false, com SHOW_TITLE permanecendo ‘undef’, e false, corresponde mais a uma configuração de documento para navegação, com um acesso direto para as informações no nó Top.

Para DocBook, NO_TOP_NODE_OUTPUT é configurada como verdadeira. Configurar-se NO_TOP_NODE_OUTPUT como falsa faz com que o conteúdo do nó Topo seja gerado. Não é recomendado gerar o nó Topo no DocBook, pois os textos de título e de cópia são sempre gerados. Essa opção é mantida para DocBook para compatibilidade, pois antes de 2022 o nó Topo era gerado no DocBook. Ela poderá ser removida no futuro.

OPEN_QUOTE_SYMBOL ¶

Quando uma aspa de abertura for necessária, por exemplo, para saída gerada do ‘@samp’, usar o caractere especificado; padrão &#8216; para DocBook. Indefinida no caso padrão no HTML e configurada como &lsquo; se USE_NUMERIC_ENTITY não estiver configurada; como &#8216; se configurada; e como um caractere de aspas se OUTPUT_CHARACTERS estiver configurada e a codificação da saída gerada incluir esse caractere.

Para Info, o padrão depende da codificação habilitada de documento. Se --disable-encoding estiver configurada ou a codificação do documento não for UTF-8, ‘'’ será usado. Esse caractere geralmente aparece como uma aspa simples indirecionada em sistemas modernos. Caso contrário, a saída gerada Info usará uma aspa esquerda Unicode.

OUTPUT_CHARACTERS ¶

Se não configurada, o padrão gerará caracteres acentuados e especiais em HTML, XML e DocBook usando entidades XML e em LaTeX usando macros. Se configurada, gerar caracteres acentuados na saída gerada de HTML, XML, DocBook e LaTeX e caracteres especiais na saída HTML e LaTeX baseada na codificação do documento. Veja-se @documentencoding codificação: Configurar Codificação de Entrada e Inserindo Acentos.

TOP_NODE_UP ¶

Nó Acima para o nó Topo; padrão ‘(dir)’. É presumido que esse nome de nó já esteja formatado para o formato da saída gerada. No HTML pode ser usado em atributo, de modo que não deveria conter nenhum elemento. Usado para saída HTML somente se TOP_NODE_UP_URL estiver configurada para substituir o URL; veja-se TOP_NODE_UP_URL em Lista de Variáveis de Personalização do HTML. Veja-se Personalização de Nomes de Arquivo e de Linques para HTML.

USE_NODES ¶

A unidade principal dos documentos de saída é unidade de saída. Normalmente, um nó está associado a um comando de seccionamento seguinte, enquanto um comando de seccionamento está associado a um nó anterior; ambos juntos constituem a unidade de saída.

Para Texto Simples e HTML. Usar preferencialmente nós para decidir onde unidades da saída gerada serão separadas se USE_NODES estiver configurada. Se configurada como falso, usar preferencialmente o seccionamento para decidir onde unidades da saída gerada serão separadas. O padrão é verdadeiro.

USE_NUMERIC_ENTITY ¶

Para HTML, XML e DocBook. Se configurada, usar entidades numéricas em vez de entidades nomeadas. Por padrão, configurada como verdadeiro para saída gerada DocBook.
