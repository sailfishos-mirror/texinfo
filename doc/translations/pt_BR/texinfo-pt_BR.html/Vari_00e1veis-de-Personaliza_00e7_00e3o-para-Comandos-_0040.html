20.4.1 Variáveis de Personalização para Comandos @ ¶

Cada um dos comandos @ a seguir tem uma variável de personalização associada com o mesmo nome (sem o 

@afivepaper            @afourpaper        @afourlatex
@afourwide             @allowcodebreaks   @bsixpaper
@contents              @codequotebacktick
@codequoteundirected   @deftypefnnewline  @documentdescription
@documentencoding      @documentlanguage  @evenfooting
@evenfootingmarks      @evenheading       @evenheadingmarks
@everyfooting          @everyfootingmarks @everyheading
@everyheadingmarks     @exampleindent     @firstparagraphindent
@fonttextsize          @footnotestyle     @frenchspacing
@headings              @kbdinputstyle     @microtype
@novalidate            @oddfooting        @oddfootingmarks
@oddheading            @oddheadingmarks   @pagesizes
@paragraphindent       @setfilename       @setchapternewpage
@shortcontents         @smallbook         @summarycontents
@urefbreakstyle        @xrefautomaticsectiontitle

Configurar essa variável de personalização com um valor ‘foo’ é semelhante a executar @cmd foo. Porém, não é exatamente a mesma coisa, já que quaisquer efeitos colaterais da análise do fonte do Texinfo não são refeitos. Além disso, algumas variáveis não levam código Texinfo ao gerar formatos específicos, mas sim um argumento que já está formatado. Esse é o caso, por exemplo, do HTML para documentdescription.

Observe que se texi2any for invocado para processar o arquivo com TeX (por exemplo, com a opção --pdf), então essas variáveis de personalização possivelmente não sejam passadas para TeX.
