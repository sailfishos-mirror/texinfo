3.9.1 Escrevendo um Menu ¶

Um menu consiste de um comando @menu em uma linha própria, seguido por linhas de entrada de menu ou de linhas de comentários de menu, e então seguido por um comando @end menu em uma linha própria.

Um menu se parece com isto: 

@menu
Unidades Maiores de Texto

* Arquivos::                    Tudo acerca de manuseio de arquivos.
* Múltiplos: Buffers.           Múltiplos buffers; editando
                                 vários arquivos de uma vez.
@end menu

Em um menu, cada linha que inicie com um ‘* ’ é uma entrada de menu. (Observe o espaço depois do asterisco). No exemplo acima, as duas linhas iniciando com ‘* ’ são entradas de menu.

Uma linha que não se inicie com um ‘* ’ também pode aparecer em um menu. Tal linha não é uma entrada de menu, mas sim uma linha do comentário de menu. No exemplo acima, a linha ‘Unidades Maiores de Texto’ é uma linha de comentário de menu. Linhas de comentário de menu e linhas vazias são mantidas na saída gerada.

Tecnicamente, menus podem te transportar para qualquer nó, independentemente da estrutura do documento; mesmo para nós em um arquivo Info diferente. Entretanto, o recurso de criação implícita de ponteiros do texi2any (veja-se Escrevendo uma Linha de @node) e os comandos de atualização do modo Texinfo do GNU Emacs funcionam somente para criar menus de nós subordinados em um documento hierarquicamente estruturado. Em um documento hierarquicamente estruturado, é muito melhor usar referências cruzadas para referenciar nós arbitrários.

No Info, um(a) usuário(a) seleciona um nó com o comando m (Info-menu). O nome de entrada de menu é o que o(a) usuário(a) digita depois do comando m. Na saída HTML, o atributo accesskey é usado com os valores ‘1’…‘9’ para as primeiras nove entradas. Isso permite que as pessoas usando navegadores web sigam as primeiras entradas de menu usando (tipicamente) M-dígito, por exemplo, M-1 para a primeira entrada.
