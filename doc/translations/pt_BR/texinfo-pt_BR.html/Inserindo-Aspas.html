11.5 Inserindo Aspas ¶

Use caracteres de aspas simples duplicadas para iniciar e terminar citações: ``…''. Duas aspas simples são convertidas para aspas duplicadas à esquerda e à direita, “assim”.

Ocasionalmente, você pode precisar produzir duas aspas simples consecutivas; por exemplo, ao documentar uma linguagem de computador como Maxima, onde '' é um comando válido. Você pode fazer isso com a entrada '@w{}'; o comando vazio @w interrompe a combinação nos caracteres de aspas duplas.

O caractere de aspa à esquerda (`, código ASCII 96) usado no Texinfo é um acento grave nos padrões do conjunto de caracteres ANSI e ISO. Nós o usamos como um caractere de aspas porque assim é como TeX está configurado, por padrão.

Texinfo suporta várias outras marcas de citação usadas em idiomas diferentes do inglês. Abaixo está uma tabela com os comandos que Texinfo fornece para inserir marcas de citação.

ComandoGlifoNome Unicode (ponto)
@quotedblleft{} ``“Aspa dupla à esquerda (U+201C)
@quotedblright{} ''”Aspa dupla à direita (U+201D)
@quoteleft{} `‘Aspa simples à esquerda (U+2018)
@quoteright{} '’Aspa simples à direita (U+2019)
@quotedblbase{}„Aspa dupla baixo 9 (U+201E)
@quotesinglbase{}‚Aspa simples baixo 9 (U+201A)
@guillemetleft{}«Aspa dupla angular apontando para a esquerda (U+00AB)
@guillemetright{}»Aspa dupla angular apontando para a direita (U+00BB)
@guilsinglleft{}‹Aspa simples angular apontando para a esquerda (U+2039)
@guilsinglright{}›Aspa simples angular apontando para a direita (U+203A)

Para as aspas duplas angulares, nomes de glifos da Adobe e do LaTeX também são suportados: @guillemotleft e @guillemotright. Esses nomes estão incorretos; um “guillemot” é uma espécie de pássaro (um tipo de auk).

As fontes padrão do TeX suportam as aspas usuais usadas em inglês (aquelas produzidas com aspas simples de ASCII unitárias e duplicadas). Para as outras aspas, TeX usa fontes European Computer Modern (EC) (ecrm1000 e outras variantes). Essas fontes estão disponíveis livremente, é claro; você consegue baixá-las a partir de http://ctan.org/pkg/ec, entre outros lugares.

As fontes livres EC são fontes bitmap criadas com Metafont. Especialmente para visualização online, as versões Type 1 (vetor) das fontes são preferíveis; elas estão disponíveis no pacote de fontes CM-Super (http://ctan.org/pkg/cm-super).

Ambas as distribuições incluem instruções de instalação.

As tradições para uso de aspas variam muito entre os idiomas (https://en.wikipedia.org/wiki/Quotation_mark). Texinfo não fornece comandos ou configurações para tipografar aspas de acordo com as numerosas tradições. Portanto, você tem que escolher os comandos apropriados para o idioma do teu manual. Às vezes, apelidos (veja-se ‘@alias novo=existente’) conseguem simplificar o uso e tornar o código-fonte mais legível. Por exemplo, em alemão, @quotedblbase é usado para a aspa dupla à esquerda, e a aspa dupla à direita é o glifo produzido por @quotedblleft, o que é contraintuitivo. Assim, nesse caso, os seguintes apelidos seriam convenientes: 

@alias lgqq = quotedblbase
@alias rgqq = quotedblleft
