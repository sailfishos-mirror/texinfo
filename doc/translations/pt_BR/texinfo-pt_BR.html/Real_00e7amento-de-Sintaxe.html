22.6 Realçamento de Sintaxe de Exemplos de Códigos no HTML ¶

Você pode usar a variável HIGHLIGHT_SYNTAX para realce de sintaxe do código-fonte em blocos @example para a saída HTML, com a ajuda de software externo. Você pode configurar HIGHLIGHT_SYNTAX para um dos vários valores especiais:

realçe

Usar highlight proveniente de http://www.andre-simon.de/doku/highlight/en/highlight.php.

pygments

Usar pygmentize proveniente de https://pygments.org/.

source-highlight

Usar source-highlight (veja-se GNU Source-highlight).

O primeiro argumento em uma linha @example (veja-se @example: Texto de Exemplo) fornece o nome da linguagem usada para realce de sintaxe. Blocos @example sem tal argumento só serão realçados se HIGHLIGHT_SYNTAX_DEFAULT_LANGUAGE estiver configurada, variável essa que fornece a linguagem a usar para realçamento de tais blocos.

Se você usar um valor para HIGHLIGHT_SYNTAX que não esteja listado acima, ele será um modelo para uma linha de comando que é executada para realçar código. Isso lhe dá mais controle sobre as opções exatas de linha de comando usadas para o programa de realce e permite usar outros programas além dos listados acima. Nesse modelo, o nome da linguagem realçada é substituído por ocorrências de ‘%l’ e ‘%’ é substituído por ‘%%’. texi2any passa o conteúdo de cada bloco @example (convertido para texto simples) na entrada padrão, e o HTML realçado é lido a partir da saída padrão.

Por exemplo, se você configurar HIGHLIGHT_SYNTAX como ‘colorcode -l=%l’ e existir um bloco ‘@example C++’ no documento, a linha de comando colorcode -l=C++ será executada com o bloco ‘@example’ passado para a entrada padrão do comando executado e o resultado será lido a partir da saída padrão do comando executado.
