3.6 Estrutura do Documento Texinfo ¶

Os nós podem conter menus, os quais contém os nomes de nós descendentes dentro do nó ancestral; por exemplo, um nó correspondente a um capítulo teria um menu de seções nesse capítulo. Os menus permitem que o(a) usuário(a) se movimente para os nós descendentes na saída Info.

Adicionalmente, os nós contém ponteiros de nó que nomeiam outros nós. Os ponteiros ‘Próximo’ e ‘Anterior’ vinculam nós no mesmo nível de seccionamento em uma cadeia. Conforme você pode imaginar, o ponteiro ‘Próximo’ vincula ao próximo nó, e o ponteiro ‘Anterior’ vincula ao nó anterior. Em geral, ‘Próximo’ e ‘Anterior’ referenciam nós no mesmo nível hierárquico no manual, não necessariamente ao próximo nó dentro do arquivo Texinfo. No arquivo Texinfo, o nó subsequente possivelmente esteja em um nível inferior—um nó ao nível de seção frequentemente precisa seguir um nó ao nível de capítulo, por exemplo. Assim, por exemplo, todos os nós que estejam ao nível de seções dentro de um capítulo são vinculados juntos, e a ordem nessa cadeia é a mesma que a ordem dos descendentes no menu do capítulo ancestral. Cada nó descendente grava o nome de nó do ancestral como ponteiro dele ‘Acima’.

Como o nó ‘Top’ é o único nó nesse nível, ‘Próximo’ se refere ao primeiro nó a seguir, que quase sempre é um nó de capítulo ou ao nível de capítulo. Essa é uma exceção à regra de ‘Próximo’ estar no mesmo nível hierárquico.

A saída Info e HTML para cada nó inclui vínculos para os nós ‘Próximo’, ‘Anterior’, e ‘Acima’. O HTML também usa o atributo accesskey com os valores ‘n’, ‘p’, e ‘u’, respectivamente. Isso permite que pessoas que usam navegadores web seguirem a navegação usando (tipicamente) M-letra, por exemplo, M-n para o nó ‘Próximo’, a partir de qualquer lugar dentro do nó. Os ponteiros e menus de nó fornecem estrutura para arquivos Info, exatamente como capítulos, seções, subseções e semelhantes fornecem estrutura para livros impressos. As duas estruturas teoricamente são distintas; na prática, entretanto, a estrutura de árvore dos livros impressos é também essencialmente sempre usada para o nó e estrutura de menu, pois isso conduz a um documento que é fácil de seguir.

Normalmente, a estrutura de seccionamento e a estrutura de nó são completamente paralelas, com um nó para cada capítulo, seção etc., e com os nós seguindo o mesmo arranjo hierárquico que o seccionamento. Assim, se um nó estiver no nível lógico de um capítulo, os nós descendentes dele estarão no nível das seções; similarmente, os nós descendentes das seções estarão no nível das subseções.

É tecnicamente possível criar documentos do Texinfo com somente uma estrutura ou a outra, ou para as duas estruturas não serem paralelas ou para que a estrutura de seccionamento ou a de nó seja diferente da estrutura convencional. Até onde sabemos, no entanto, todos os manuais do Texinfo atualmente em uso geral seguem a estrutura paralela convencional.
