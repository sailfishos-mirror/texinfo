22.8.7 Personalização do HTML para Matemática ¶

Você pode selecionar vários métodos para renderizar matemática em HTML (veja-se Formatando Expressões Matemáticas). Isso é controlado pela variável de personalização HTML_MATH. Por padrão, a variável de personalização está desconfigurada e a saída HTML é apenas enfatizada. Você pode selecionar outras opções para a finalidade de exibir fórmulas matemáticas formatadas corretamente. Para algumas dessas opções, se você configurar --iftex, as seções @tex serão convertidas para HTML e se você configurar --iflatex, as seções @latex serão convertidas para HTML.

l2h

Usar o programa latex2html para produzir arquivos de imagem para material matemático.

latex2html processará matemática LaTeX em comandos matemáticos, incluindo matemática TeX compatível com LaTeX. latex2html é usado para traduzir seções @tex e @latex para HTML se as seções correspondentes não forem ignoradas. Observe que latex2html só consegue processar LaTeX, inclusive ao processar seções @tex.

O processamento com latex2html deveria deixar os arquivos no diretório da saída gerada, com ‘-l2h’ no nome deles, em particular um arquivo de cache para evitar refazer a tradução para HTML se já feita.

Veja-se Variáveis de Personalização do latex2html.

mathjax

Insere referências nos arquivos de saída para conjuntos de comandos sequenciados MathJax para formatar fórmulas matemáticas. A opção MathJax exige que o JavaScript esteja habilitado no navegador para funcionar.

MathJax lida com matemática LaTeX, incluindo matemática TeX comumente usada e compatível com LaTeX. Alguns constructos específicos (por exemplo, alguns usos de \text) não são suportados, mas isso não deveria ser um problema prático.

Se os comandos matemáticos forem realmente processados, um rótulo da web de licença JavaScript será gerado para conjuntos de comandos sequenciados MathJax (veja-se Rótulos web de licença JavaScript).

Veja-se Variáveis de Personalização da MathJax.

t4h

Usar o programa tex4ht para produzir HTML para material matemático.

tex4ht processará matemática LaTeX em comandos matemáticos, incluindo matemática TeX compatível com LaTeX. tex4ht é usado para traduzir seções @tex e @latex para HTML se as seções não forem ignoradas. As seções @tex são processadas no modo TeX, enquanto as seções @latex são processadas como LaTeX.

O processamento com tex4ht deveria deixar os arquivos no diretório da saída gerada, com ‘_tex4ht’ no nomes deles.

Veja-se Variáveis de Personalização do tex4ht.

Por padrão, com CONVERT_TO_LATEX_IN_MATH indefinida, configurar-se HTML_MATH também configura CONVERT_TO_LATEX_IN_MATH. Nesse caso, comandos @ do Texinfo dentro de @math e de @displaymath serão convertidos para LaTeX, antes de converter o @math ou o @displaymath para HTML.
