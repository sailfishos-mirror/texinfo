6.1.16 @email{endereço-correio-eletrônico[, texto-exibido]} ¶

Use o comando @email para indicar um endereço de correio eletrônico. Ele recebe um argumento obrigatório, o endereço, e um argumento opcional, o texto a exibir (o padrão é o próprio endereço).

No Info, o endereço é mostrado entre colchetes angulares, precedido pelo texto a exibir, se existir. Na saída impressa, os colchetes angulares são omitidos. Na saída HTML e DocBook, @email produz um linque ‘mailto’. No HTML, um linque ‘mailto’ geralmente abre uma janela de composição de mensagem. Por exemplo: 

Envie informes de defeitos para @email{bug-texinfo@@gnu.org},
sugestões para o @email{bug-texinfo@@gnu.org, algum lugar}.

produz 

Envie informes de defeitos para bug-texinfo@gnu.org,
sugestões para o algum lugar.
