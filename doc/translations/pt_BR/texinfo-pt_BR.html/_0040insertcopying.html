2.7.2 @insertcopying: Incluir Texto de Permissões ¶

O comando @insertcopying simplesmente é escrito em uma linha própria, como esta: 

@insertcopying

Isso insere o texto previamente definido por @copying. Para atender às exigências jurídicas, ele precisa ser usado na página de direitos autorais no manual impresso (veja-se Direitos Autorais).

O próprio comando @copying faz com que o texto das permissões apareça em um arquivo Info antes do primeiro nó. O texto também é copiado no início de cada arquivo dividido de saída Info, como é juridicamente necessário. Esse local implica que um humano lendo o manual usando Info não vê esse texto (exceto quando usar o comando avançado g * do Info). Isso não importa para propósitos jurídicos, pois o texto está presente. Mas, para obter um texto visível na saída gerada, @insertcopying deveria ser usado.

Similarmente, o texto @copying é automaticamente incluído no início de cada arquivo de saída HTML, como um comentário HTML. De novo, esse texto não é visível sem @insertcopying (a menos que o(a) leitor(a) visualize o fonte HTML).

O texto de permissões definido por @copying também aparece automaticamente no início dos arquivos de saída DocBook usando-se marcação apropriada. @insertcopying pode ser usado para gerar o texto de permissão dentro do texto normal.
