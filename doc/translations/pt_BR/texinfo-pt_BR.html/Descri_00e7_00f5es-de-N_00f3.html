3.8 Descrições de Nó ¶

Você pode fornecer uma breve descrição do propósito de um nó usando o comando @nodedescription seguindo a linha @node. Essa descrição pode elaborar ou estender as informações no próprio nome do nó.

Você também pode usar um ambiente @nodedescriptionblock para fornecer uma descrição do nó. Isso possivelmente seja útil para descrições mais longas.

texi2any usa o conteúdo que você fornecer com esses comandos ao gerar menus para o formato de saída Info (e, opcionalmente, para HTML). texi2any usa a descrição depois de uma entrada de menu para o nó se estiver gerando o menu automaticamente ou se nenhuma descrição para a entrada de menu foi fornecida em um bloco explícito @menu. (Veja-se Menus).

Aqui está um exemplo do uso desses comandos: 

@node Ferramentas
@chapter Ferramentas

Este capítulo é a respeito de diferentes ferramentas que você pode usar.

@node Chaves de fenda
@nodedescription Ponta Chata e Phillips.
@section Chaves de fenda

Esta seção é a respeito de chaves de fenda.

@node Brocas
@nodedescriptionblock
Fazendo buracos em coisas com chaves elétricas de fenda, controladores de
broca, brocas combi, controladores de impacto, brocas martelo, disjuntores
e brocas de demolição.
@end nodedescriptionblock
@section Brocas

Esta seção é a respeito de brocas.

Na saída gerada Info, texi2any geraria o nó ‘Ferramentas’ com um menu conforme segue: 

* Menu:

* Chaves de fenda::       Ponta Chata e Phillips.
* Brocas::                Fazendo buracos em coisas com chaves
                          elétricas de fenda, controladores de broca,
                          brocas combi, controladores de impacto, brocas
                          martelo, disjuntores e brocas de demolição.
