22.7.5 Configuração de Referência Cruzada do HTML ¶

Para outros manuais publicados na World Wide Web estarem aptos para terem referências cruzadas corretas para teu manual, as partes dispositivo e diretório da referência cruzada precisam ser conhecidas pelos conversores de Texinfo quando eles produzirem HTML para esses outros manuais. Similarmente, para teu manual em formato HTML ter referências cruzadas corretas para outros manuais, texi2any precisa saber como construir as URLs para outros manuais.

texi2any lê um arquivo chamado htmlxref.cnf e todos os arquivos que terminam com a extensão .cnf no diretório htmlxref.d para coletar informações para referências cruzadas para outros manuais na saída HTML. htmlxref.cnf e htmlxref.d são procurados nos seguintes diretórios, com base na Especificação de Diretório Base XDG com padrões baseados em diretórios de instalação:

./

(o diretório atual)

diretório principal do caminho do arquivo de entrada

Se existir um diretório principal e não for o diretório atual. Por exemplo, se o arquivo de entrada for algum/diretorio/meumanual.texi, htmlxref.cnf será procurado em algum/diretorio e os arquivos correspondentes a algum/diretorio/htmlxref.d/*.cnf também serão lidos.

./.texinfo/

(sob o diretório atual)

XDG_CONFIG_HOME/texinfo

(com XDG_CONFIG_HOME uma varíavel de ambiente)

~/.config/texinfo/

(onde ~ é o atual diretório HOME do(a) usuário(a), somente se XDG_CONFIG_HOME não estiver configurada)

sysconfdir/xdg/texinfo/

(onde sysconfdir é o diretório de configuração do sistema especificado ao tempo da compilação, por exemplo, /usr/local/etc)

XDG_CONFIG_DIRS/texinfo

(para cada diretório na variável de ambiente XDG_CONFIG_DIRS delimitada por :)

datadir/texinfo/

(especificado ao tempo de compilação, por exemplo, /usr/local/share)

Todos os arquivos encontrados são usados, com as entradas anteriores substituindo as posteriores. A distribuição do Texinfo inclui arquivos que são instalados em datadir/texinfo/htmlxref.d, em um dos últimos dos diretórios acima:

Texinfo_GNU.cnf

Manuseia muitos manuais GNU.

Texinfo_nonGNU.cnf

Manuais livres de projetos não GNU.

Você pode usar um htmlxref.cnf local para completar ou para corrigir os arquivos padrão provenientes da distribuição do Texinfo. Isso poderia ser útil para corrigir dados desatualizados ou, até mesmo, para gerar referências cruzadas para arquivos locais para alguns manuais. Outros pacotes de software que gerenciam listas de manuais seguindo a especificação de referências cruzadas do HTML poderiam instalar arquivos .cnf em datadir/texinfo/htmlxref.d.

A variável de personalização HTMLXREF_MODE pode ser configurada para modificar como os arquivos são encontrados. Por exemplo, se configurada como ‘none’, nenhuma informação externa será usada. HTMLXREF_FILE configura o nome do arquivo para algo diferente de htmlxref.cnf. Veja-se Variáveis de Personalização do HTML.

O arquivo é orientado por linha. Linhas que consistem somente de espaços em branco são ignoradas. Comentários são indicados com um ‘#’ no início de uma linha, opcionalmente precedido por espaço em branco. Como ‘#’ pode ocorrer em URLs (como quase qualquer caractere), ele não inicia, de outro modo, um comentário.

Cada linha não vazia que não seja de comentário precisa ser ou uma atribuição de variável ou uma informação de manual.

Uma linha de atribuição de variável se parece com isto: 

nomevariável = valorvariável

Espaço em branco ao redor de ‘=’ é opcional e ignorado. A nomevariável deveria consistir de letras; diferenciação de maiúsculas e minúsculas é significativa. A valorvariável é uma sequência arbitrária de caracteres, continuando até o final da linha. As variáveis são então referenciadas com ‘${nomevariável}’; referências de variáveis podem ocorrer na valorvariável.

Uma linha de informação de manual se parece com isto: 

manual palavrachave prefixourl

com manual o identificador curto para um manual, palavrachave sendo um dos: mono, node, section, chapter e prefixourl descritos abaixo. Referências de variáveis podem ocorrer somente na prefixourl. Por exemplo (usado no arquivo canônico): 

G = https://www.gnu.org
GS = ${G}/software
hello mono    ${GS}/hello/manual/hello.html
hello chapter ${GS}/hello/manual/html_chapter/
hello section ${GS}/hello/manual/html_section/
hello node    ${GS}/hello/manual/html_node/

Se a palavra-chave for mono, prefixourl fornecerá o dispositivo, o diretório e o nome do arquivo para manual como um arquivo monolítico.

Se a palavra-chave for node, section ou chapter, prefixourl fornecerá o dispositivo e o diretório para manual divididos em nós, seções ou capítulos, respectivamente.

Se prefixourl for omitido, os elementos das referências cruzadas corresponderão a linques de referência cruzada entre uma coleção de manuais localizados lado a lado em um dispositivo (veja-se Básicos do Linque de Referência Cruzada do HTML). Isso poderia ser útil se você gerasse e publicasse uma coleção de manuais e preferisse lincar para os manuais gerados em vez de para as versões encontradas nas configurações de referências cruzadas enviadas com o Texinfo.

Quando texi2any estiver gerando um linque para outro manual do Texinfo, ele preferirá usar uma linha para o manual com a mesma opção de divisão que a da saída atual. Ou seja, ao gerar saída monolítica (--no-split), uma URL mono será preferida; ao gerar saída que seja dividida por nó, uma URL node será preferida, entre outras.

Se nenhuma linha de informação com a opção de divisão preferida estiver presente para um determinado manual, então outras linhas para esse manual poderão ser usadas, se presentes. Aqui está a ordem de pesquisa completa para cada opção de divisão: 

node    ⇒ nó,       seção,    capítulo, mono
section ⇒ seção,    capítulo, nó,       mono
chapter ⇒ capítulo, seção,    nó,       mono
mono    ⇒ mono,     capítulo, seção,    nó

Essas referências entre manuais em nível de seção e de capítulo podem ser bem-sucedidas somente quando o manual alvo foi criado usando-se --node-files; esse é o padrão para saída dividida.

Atualmente, os arquivos Texinfo_GNU.cnf e Texinfo_nonGNU.cnf distribuídos com o GNU Texinfo servem como o principal recurso para localizar manuais HTML do Texinfo na World Wide Web. Como eles são instalados em um local usado pelo texi2any, as informações acerca dos manuais HTML encontradas nesses arquivos serão usadas para referências cruzadas por padrão.

Se você tiver acréscimos ou correções para os arquivos distribuídos com o Texinfo, por favor envie uma mensagem eletrônica para bug-texinfo@gnu.org como de costume. Se você publicar um manual HTML do Texinfo na World Wide Web, ter um local atualizado listado em Texinfo_GNU.cnf ou em Texinfo_nonGNU.cnf deveria garantir que todos os manuais HTML gerados pelo texi2any usem esse local para referências cruzadas automaticamente. Você pode obter as versões mais recentes a partir de https://ftpmirror.gnu.org/texinfo/htmlxref.d/Texinfo_GNU.cnf e https://ftpmirror.gnu.org/texinfo/htmlxref.d/Texinfo_nonGNU.cnf. Se você quiser manter um arquivo separado distribuído com Texinfo, por favor envie uma mensagem eletrônica para bug-texinfo@gnu.org também.
