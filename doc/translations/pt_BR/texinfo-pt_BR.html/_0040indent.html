7.13 @indent: Forçando Recuo ¶

Para complementar o comando @noindent (veja-se a seção anterior), Texinfo fornece o comando @indent para forçar que um parágrafo seja recuado. Por exemplo, este parágrafo (o primeiro nesta seção) está recuado usando um comando @indent.

E, de fato, o primeiro parágrafo de uma seção é o lugar mais provável para se usar @indent, para substituir o comportamento normal de não recuo ali (veja-se @paragraphindent: Controlando Recuo do Parágrafo). Ele ou pode ser seguido por texto ou estar em uma linha própria.

Como um caso especial, quando @indent for usado em um ambiente onde o texto não estiver preenchido, ele produz um espaço de recuo de parágrafo na saída TeX. (Esses ambientes são onde uma linha de entrada produz uma linha de saída, como @example e @display; para um resumo de todos os ambientes, veja-se Comandos de Cercamento de Blocos).

Não coloque chaves depois de um comando @indent; elas não são usadas, pois @indent é um comando usado fora de parágrafos (veja-se Sintaxe de Comando @).
