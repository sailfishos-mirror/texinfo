10.3 Comandos Avançados de Indexação ¶

O Texinfo fornece vários outros comandos para indexação.

Primeiro, você pode criar entradas de índice multi nível, permitindo agrupar muitos subtópicos relacionados sob o mesmo tópico de nível superior. Você faz isso separando as partes de cada entrada com o comando @subentry. Esses comandos podem se parecer com isto: 

@cindex Superhumanos(as) @subentry vilões(ãs)
@cindex Superhumanos(as) @subentry heróis(ínas)

Você pode ter até três níveis em uma entrada: 

@cindex cafeteiras @subentry elétricas @subentry rosa
@cindex cafeteiras @subentry elétricas @subentry azul

Você pode usar o comando @sortas mencionado anteriormente com qualquer uma ou todas as três partes de uma entrada para fazer com que elas ordenem diferentemente do que fariam por padrão.

Segundo, você pode fornecer uma entrada de índice que aponte para outra, usando o comando @seeentry (“veja-se entrada”). Por exemplo: 

@cindex Índices @seeentry{Expoentes}

Essa entrada deveria ser única no teu documento; a ideia é a de redirecionar o(a) leitor(a) para a outra entrada, onde eles(as) encontrarão todas as informações que procuram.

Finalmente, você pode fornecer uma entrada “veja-se também” usando o comando @seealso. Essas entradas acompanham as entradas regulares e são agrupadas com elas no índice impresso final. Por exemplo: 

@cindex Café
@cindex Café @subentry Com leite e açúcar
@cindex Café @subentry Com donuts
@cindex Café @subentry Descafeinado
@cindex Café @seealso{Chá}

Ao usar todos esses três comandos avançados, não coloque uma vírgula entre as diferentes partes do texto do índice. O programa texindex, que ordena as entradas do índice e gera os comandos de formatação de indexação, se encarrega de colocar as vírgulas nos lugares corretos para você.

Não interrompa um índice ou uma entrada @subentry com @sortas ou comandos avançados com chaves; coloque os comandos com chaves no início ou no final da entrada.

Esses recursos são mais úteis com documentos impressos e ao se traduzir Texinfo para DocBook.
