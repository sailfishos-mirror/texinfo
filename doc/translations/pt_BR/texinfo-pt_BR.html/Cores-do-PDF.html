5.16 Cores do PDF ¶

Por padrão, links de URLs e de referências cruzadas são impressos em preto na saída gerada PDF. Muito ocasionalmente, entretanto, você pode querer realçar tais links “vivos” com uma cor diferente, como é feito comumente em páginas da web. Texinfo fornece uma opção específica de PDF para se especificar essas cores, a qual precisa ser usada dentro de @tex: 

@tex
\global\def\linkcolor{1 0 0}  % vermelha
\global\def\urlcolor{0 1 0}   % verde
@end tex

\urlcolor muda a cor da saída gerada @url (tanto a URL real, quanto qualquer rótulo textual), ao passo que \linkcolor muda a cor para referências cruzadas para nós, etc. Elas são independentes.

Os três valores fornecidos precisam ser números entre 0 e 1, especificando a quantidade de vermelho, verde e azul, respectivamente.

Essas definições somente tem um efeito quando a saída gerada PDF for produzida com o programa pdfTeX, não com outros meios de se obter de Texinfo para PDF (por exemplo, TeX para DVI para PDF). Consequentemente, está certo se especificar essa opção incondicionalmente dentro de @tex, conforme mostrado acima. Ela é ignorada quando DVI está sendo produzido.

Nós não recomendamos colorir apenas por diversão; a menos que você tenha um motivo específico para usar cores, melhor ignorá-las.
