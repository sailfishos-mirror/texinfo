D.4.2 Usando occur ¶

Às vezes, o comando texinfo-show-structure produz muitas informações. Talvez você queira se lembrar da estrutura geral de um arquivo do Texinfo e fique impressionado(a) pela lista detalhada produzida por texinfo-show-structure. Nesse caso, você consegue usar o comando occur diretamente. Para fazer isso, digite: 

M-x occur

e então, quando solicitado(a), digite uma regexp, uma expressão regular para o padrão que você quiser corresponder. (Veja-se Expressões Regulares em O Manual do GNU Emacs). O comando occur funciona desde o local atual do cursor no buffer até o final do buffer. Se você quiser executar occur sobre o buffer inteiro, coloque o cursor no início do buffer.

Por exemplo, para ver todas as linhas que contêm a palavra ‘@chapter’, basta digitar ‘@chapter’. Isso produzirá uma lista dos capítulos. Também listará todas as frases com ‘@chapter’ no meio da linha.

Se você quiser ver somente as linhas que comecem com a palavra ‘@chapter’, digite ‘^@chapter’ quando solicitado(a) por occur. Se você quiser ver todas as linhas que terminem com uma palavra ou frase, termine a última palavra com um ‘$’; por exemplo, ‘capturando erros$’. Isso pode ser útil quando você quiser ver todos os nós que sejam parte do mesmo capítulo ou seção e, portanto, têm o mesmo ponteiro ‘Acima’.

Veja-se Usando Occur em O Manual do GNU Emacs, para mais informações.
