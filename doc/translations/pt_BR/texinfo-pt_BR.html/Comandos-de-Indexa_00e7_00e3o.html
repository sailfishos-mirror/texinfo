10.2 Definindo as Entradas de um Índice ¶

Os dados para criar um índice vem de muitos comandos individuais de indexação espalhados pelo arquivo fonte do Texinfo. Cada comando diz para adicionar uma entrada para um índice específico; depois da formatação, o índice fornecerá o número da página atual ou o nome do nó como a referência.

Uma entrada de índice consiste de um comando de indexação no início de uma linha seguido, no restante da linha, pela entrada.

Por exemplo, esta seção começa com as seguintes cinco entradas para o índice de conceito: 

@cindex Definindo entradas de indexação
@cindex Entradas de índice, definindo
@cindex Entradas para um índice
@cindex Especificando entradas de índice
@cindex Criando entradas de índice

Cada índice predefinido tem o próprio comando dele de indexação—@cindex para o índice de conceito, @findex para o índice de função e assim por diante, conforme listado na seção anterior.

As entradas do índice deveriam preceder o material visível que estiver sendo indexado. Por exemplo: 

@cindex alô
Alô, você!

Entre outros motivos, dessa maneira linques de indexação seguintes (em qualquer contexto) acabam antes do material, onde os(as) leitores(as) querem estar, em vez de depois.

No Info, um índice geralmente é formatado como um menu. Tente evitar usar dois pontos nas entradas de índice, pois isso pode confundir alguns leitores Info. Veja-se As Partes de um Menu para mais informações acerca da estrutura de uma entrada de menu.

Por padrão, as entradas para um índice de conceito são impressas em uma fonte romana e as entradas para os outros índices são impressas em uma fonte de máquina de escrever. Você pode mudar a maneira como parte de uma entrada é impressa com os comandos usuais do Texinfo, como @file para nomes de arquivos (veja-se Marcação de Texto, Palavras e Frases) e @r para a fonte normal romana (veja-se Fontes para Impressão).

Você pode especificar uma chave explícita de ordenação para uma entrada de índice usando @sortas seguindo ou o comando de índice ou o texto da entrada. Por exemplo: ‘@findex @sortas{\} \ @r{(literal \ em @code{@@math})’ ordena a entrada de índice que isso produz sob barra invertida.

Você pode escolher ignorar determinados caracteres nas entradas de índice para fins de ordenação. Os caracteres que você pode, atualmente, escolher ignorar são ‘\’, ‘-’, ‘<’ e ‘@’, que são ignorados fornecendo-se como um argumento para o comando @set, respectivamente, txiindexbackslashignore, txiindexhyphenignore, txiindexlessthanignore e txiindexatsignignore. Por exemplo, especificar ‘@set txiindexbackslashignore’ faz com que a entrada ‘\mathopsup’ no índice para este manual seja ordenada como se fosse ‘mathopsup’, de forma que ela apareça entre as outras entradas começando com ‘M’. Isso evita a necessidade de fornecer chaves explícitas de ordenação para entradas de índice contendo esses caracteres.

Ao usar essas opções, é possível obter uma entrada de índice com uma chave vazia de ordenação. Para evitar isso, especifique uma diretiva @sortas na entrada de índice. Por exemplo: 

@set txiindexbackslashignore
@findex @sortas{\} \
