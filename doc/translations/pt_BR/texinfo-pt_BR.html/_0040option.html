6.1.11 @option{nome-opção} ¶

Use o comando @option para indicar uma opção de linha de comando; por exemplo, -l ou --version ou --output=nomearquivo.

@option é equivalente a @code nos efeitos dele. Por exemplo: 

A opção @option{-l} produz uma listagem longa.

produz

A opção -l produz uma listagem longa.
