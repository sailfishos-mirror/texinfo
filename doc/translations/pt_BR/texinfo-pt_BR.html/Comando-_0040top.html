3.5 O Comando de Seccionamento @top ¶

O comando @top é um comando especial de seccionamento que você deveria usar somente depois de uma linha ‘@node Top’ no início de um arquivo Texinfo.

Ele produz o mesmo tipo de saída que @unnumbered (veja-se @unnumbered, @appendix: Capítulos com Outra Rotulagem). No LaTeX \part* é usado.

@top é ignorado ao se elevar ou rebaixar seções. Ou seja, ele nunca é rebaixado e nada pode ser elevado a ele (veja-se Elevar/rebaixar Seções: @raisesections e @lowersections).

Costumava ser convencional envolucrar o nó @top em um condicional @ifnottex, de forma que ele não aparecesse em saída impressa (veja-se Texto Condicionalmente Visível). Assim, um nó Top frequentemente se parecia com isto: 

@ifnottex
@node Top
@top título-teu-manual

sumário-altíssimo-nível
@end ifnottex

Isso não mais é necessário, pois o nó ‘Top’ agora nunca é gerado para saída impressa. O nó ‘Top’ também não é gerado para DocBook.
