22 Gerando HTML ¶

texi2any gera saída Info por padrão, mas dada a opção --html, ele gerará HTML, para navegadores da web e outros programas. Este capítulo fornece alguns detalhes acerca dessa saída HTML.

texi2any tem muitas variáveis de personalização definidas pelo(a) usuário(a) com as quais você consegue influenciar a saída HTML. Veja-se Personalização da Saída Gerada HTML. Em particular, existe suporte para realçamento de sintaxe no @example (veja-se Realçamento de Sintaxe de Exemplos de Códigos no HTML). Você também pode escrever os assim chamados arquivos de inicialização, ou arquivos init para abreviar, para modificar quase todos os aspectos da saída gerada HTML. Os arquivos de inicialização contêm código e são carregados por --init-file (veja-se Invocando texi2any a partir de um Shell).

Alguns arquivos de inicialização são mantidos com o Texinfo e instalados no caso padrão. Por exemplo, chm.pm produz os arquivos comprimidos intermediários no formato Help do HTML que podem ser posteriormente convertidos para o formato CHM.

A documentação da adaptação da saída HTML do texi2any usando arquivos de personalização está em um manual separado. Veja-se Personalização da Saída do texi2any do GNU Texinfo.
