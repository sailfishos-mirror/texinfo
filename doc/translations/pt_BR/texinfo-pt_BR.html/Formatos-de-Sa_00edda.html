1.2 Formatos de Saída ¶

Aqui está uma visão geral dos formatos de saída atualmente suportados por Texinfo.

Info ¶

(Gerado via texi2any). O formato Info é em sua maior parte transliteração de texto plano do fonte Texinfo. Ele adiciona uns poucos caracteres de controle para fornecer informação de navegação para referências cruzadas, índices, e assim por diante. O subsistema Emacs Info (veja-se Info), e o programa autônomo info (veja-se GNU Info), entre outros, conseguem ler esses arquivos. Veja-se Arquivos do Info e Criando e Instalando Arquivos Info.

Texto simples ¶

(Gerado via texi2any --plaintext). Essa é quase a mesma que a saída Info com os caracteres de controle de navegação omitidos.

HTML ¶

(Gerado via texi2any --html). HTML, que significa Hyper Text Markup Language, é a linguagem para escrever documentos na World Wide Web. Os navegadores da Web conseguem renderizar essa linguagem online. Existem muitas versões de HTML, tanto diferentes usos mais comuns quanto variações específicas de navegador. texi2any usa um subconjunto da linguagem que consegue ser interpretado por qualquer navegador comum, intencionalmente não usando muitas etiquetas mais novas ou menos amplamente suportadas. Embora a saída nativa seja, portanto, bastante simples, ela pode ser personalizada em vários níveis, se desejado. Veja-se Gerando HTML.

EPUB 3 ¶

(Gerada via texi2any --epub3). EPUB é um formato projetado para leitura de livros eletrônicos em dispositivos portáteis. É um derivado do HTML. O formato foi desenvolvido pelo International Digital Publishing Forum (IDPF), que agora faz parte do World Wide Web Consortium (W3C). A mais recente grande revisão, EPUB 3, data de 2011.

DVI ¶

(Gerada via texi2dvi). O formato binário DeVIce Independent é liberado pelo programa tipográfico TeX (http://tug.org). Essa é então lida por um ‘controlador’ DVI, o qual conhece os atuais comandos específicos de dispositivo que podem ser visualizados ou impressos, notadamente Dvips para tradução para PostScript (veja-se Dvips) e Xdvi para visualização em uma tela do X (http://sourceforge.net/projects/xdvi/). Veja-se Formatando e Imprimindo com TeX. (Esteja ciente de que a linguagem do Texinfo é muito diferente das linguagens usuais do TeX: TeX simples, LaTeX, ConTeXt, entre outras).

PostScript ¶

(Gerada via texi2dvi --ps). PostScript é uma linguagem de descrição de página que se tornou amplamente usada por volta de 1985 e ainda é usada hoje em dia. https://en.wikipedia.org/wiki/PostScript dá uma descrição básica e mais preferências. Por padrão, Texinfo usa o programa dvips para converter a saída DVI do TeX para PostScript. Veja-se Dvips.

PDF ¶

(Gerada via texi2dvi --pdf ou texi2pdf). Esse formato foi desenvolvido pela Adobe Systems para intercâmbio de documento portável, baseado na linguagem PostScript prévia deles. Ele consegue representar a exata aparência de um documento, incluindo fontes e gráficos, e suportar escalonamento arbitrário. Ele é entendido como sendo independente de plataforma e facilmente visualizável, entre outros objetivos de projeto; https://en.wikipedia.org/wiki/Portable_Document_Format e http://tug.org/TUGboat/tb22-3/tb72beebe-pdf.pdf tem algum conhecimento. Por padrão, Texinfo usa o programa pdftex, uma extensão de TeX, para gerar PDF; veja-se http://tug.org/applications/pdftex. Veja-se Saída PDF.

LaTeX ¶

(Gerada via texi2any --latex). Esse é um sistema de tipografia construído sobre o TeX. Foi lançado originalmente por Leslie Lamport em 1984. O LaTeX adiciona mais definições para aquelas do TeX e tem uma ampla gama de pacotes construídos sobre ele. O LaTeX é onipresente na literatura acadêmica. A versão atual do LaTeX está sob desenvolvimento ativo; mais informações estão disponíveis online em https://www.latex-project.org/.

A saída do LaTeX pode ser processada posteriormente em DVI, PostScript ou PDF. Em teoria, a saída do LaTeX deveria permitir muito mais personalização da saída do que seria possível com a implementação TeX simples do Texinfo.

DocBook ¶

(Gerada via texi2any --docbook). Esse é um formato baseado em XML, primariamente para documentação técnica. Ele, por conseguinte, assume alguma semelhança, em linhas gerais, com Texinfo. Veja-se http://www.docbook.org. Vários conversores de DocBook para Texinfo também foram desenvolvidos; vejam-se as páginas web do Texinfo.

XML ¶

(Gerada via texi2any --xml). A saída XML do texi2any, diferente de todos os outros formatos de saída, é uma transliteração do fonte do Texinfo, em vez de uma saída finalizada. Os arquivos XML do Texinfo não podem ser visualizados em navegadores da web ou outros programas.

XML é uma especificação genérica de sintaxe usável para qualquer tipo de conteúdo. (Uma referência está em http://www.w3.org/XML). O propósito da saída XML do Texinfo é o de permitir processamento posterior por ferramentas XML. A sintaxe de saída é definida em um DTD de XML, que está contido em um arquivo texinfo.dtd incluído na distribuição do fonte do Texinfo.

A distribuição do fonte do Texinfo inclui um script utilitário txixml2texi para fazer uma transformação reversa para recriar o conteúdo Texinfo original (exceto para macros e condicionais do Texinfo).
