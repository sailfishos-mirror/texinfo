11.7.6 @euro (€): Símbolo da Moeda Euro ¶

Use o comando @euro{} para gerar ‘€’. Onde possível, esse é o símbolo para a moeda Euro. Caso contrário, a palavra ‘Euro’ é usada.

O símbolo do Euro não existe nas fontes padrão do TeX (que foram projetadas antes da existência jurídica do Euro). Portanto, o TeX usa uma fonte adicional, chamada feymr10 (junto com outras variáveis). Ela está disponível livremente, é claro; você consegue baixá-la a partir de http://ctan.org/pkg/eurosym, entre outros lugares. A distribuição inclui instruções de instalação.
