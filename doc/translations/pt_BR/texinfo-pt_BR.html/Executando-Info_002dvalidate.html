D.10.4 Encontrando Nós Mal Referenciados ¶

Você consegue usar o comando Info-validate para verificar se quaisquer de ‘Próximo’, ‘Anterior’, ‘Acima’ ou outros ponteiros de nó falham ao apontar para um nó. Esse comando verifica se cada ponteiro de nó aponta para um nó existente. O comando Info-validate funciona somente sobre arquivos do Info, não sobre arquivos do Texinfo.

O programa texi2any valida ponteiros automaticamente, de modo que você não precisa usar o comando Info-validate se estiver usando texi2any. Com a variável de personalização CHECK_NORMAL_MENU_STRUCTURE configurada, texi2any também avisará se os ponteiros dos nós (ou configurados explícita ou automaticamente) não estiverem consistentes com a ordem das entradas do menu dos nós. texi2any não verifica se cada ponteiro ‘Próximo’ está correspondido por um ‘Anterior’ (no nó para onde o ‘Próximo’ aponta) que aponte para trás, pois possivelmente seja correto para uma estrutura de documento não padrão.

Você possivelmente necessite usar Info-validate somente se estiver inapto(a) para executar texi2any e, em vez disso, precise criar um arquivo do Info usando texinfo-format-region ou texinfo-format-buffer, ou se escrever um arquivo do Info a partir do zero.
