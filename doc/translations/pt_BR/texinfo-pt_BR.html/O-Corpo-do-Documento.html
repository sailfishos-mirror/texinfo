2.11 O Corpo do Documento ¶

O segmento do corpo contém todo o texto do documento. Um manual é dividido em um ou mais nós (veja-se Nós). O exemplo ilustra um capítulo feito de três nós, um para material introdutório no capítulo e duas seções. O material introdutório contém uma lista enumerada. 

@node Primeiro Capítulo
@chapter Primeiro Capítulo

@cindex capítulo, primeiro
Este é o primeiro capítulo.
@cindex entrada de índice, outra

Aqui está uma lista numerada.

@enumerate
@item
Este é o primeiro item.

@item
Este é o segundo item.
@end enumerate


@node Primeira Seção
@section Primeira Seção

Primeira seção do primeiro capítulo.


@node Segunda Seção
@section Segunda Seção

Segunda seção do primeiro capítulo.

Na saída Info, o nó ‘Primeiro Capítulo’ conterá um menu listando as duas seções no capítulo. Da mesma forma, quando esse nó for gerado no próprio arquivo HTML, ele conterá um sumário para o capítulo.

Aqui está com o que o conteúdo desse capítulo se parecerá:


1. Primeiro Capítulo ¶

Este é o primeiro capítulo

Aqui está uma lista numerada.

  1. Este é o primeiro item
  2. Este é o segundo item

1.1 Primeira Seção ¶

Primeira seção do primeiro capítulo.

1.2 Segunda Seção ¶

Segunda seção do primeiro capítulo.

(Na saída Info e HTML, o capítulo também seria dividido em nós).
