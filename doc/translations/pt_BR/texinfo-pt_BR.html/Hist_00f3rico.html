1.5 Histórico ¶

Richard M. Stallman inventou o formato Texinfo, escreveu os processadores iniciais e criou a Edição 1.0 deste manual. Robert J. Chassell revisou e estendeu muito o manual, começando com a Edição 1.1. Brian Fox foi responsável pela distribuição autônoma do Texinfo até a versão 3.8. Karl Berry continuou a manutenção a partir do Texinfo 3.8 (edição do manual 2.22), e Gavin Smith continuou a manutenção desde o Texinfo 6.0.

Começo ¶

Richard Stallman incluiu um sistema de ajuda de hipertexto online chamado Info na implementação original do Emacs (em 1975/6). Stallman foi inspirado depois de ver uma apresentação alguns anos antes acerca do sistema de hipertexto “NLS” de Douglas Engelbart.

Em outro desenvolvimento, na década de 1970 na CMU, Brian Reid desenvolveu um programa e formato chamado Scribe para marcar documentos para impressão. Ele usava o caractere @ para introduzir comandos, como o Texinfo faz. Muito mais consequentemente, ele se esforçou para descrever o conteúdo do documento em vez da formatação, uma ideia adotada de todo o coração pelo Texinfo.

Enquanto isso, pessoas no MIT desenvolveram outro formato chamado Bolio. Richard Stallman (RMS) trabalhou na conversão do Bolio para usar TeX como a linguagem dele de tipografia, resultando no BoTeX. A versão mais antiga do BoTeX parece ter sido 0.02 em 31 de outubro de 1984.

O BoTeX só podia ser usado como uma linguagem de marcação para documentos a serem impressos, não para documentos online. RMS combinou o BoTeX e o Info para criar o Texinfo, uma linguagem de marcação para texto que se destina a ser lido online e como cópia impressa.

O tradutor original para criar o Info foi escrito (principalmente por RMS e Bob Chassell) em Emacs Lisp, ou seja, o texinfo-format-buffer e outras funções. No início da década de 1990, Brian Fox reimplementou o programa de conversão em C, agora chamado makeinfo, bem como o programa autônomo info.

Reimplementando em Perl ¶

Em 2012, o makeinfo do C foi ele próprio substituído por uma implementação Perl genericamente chamada texi2any. Essa versão foi inicialmente baseada no texi2html, um programa independente escrito originalmente por Lionel Cons, mais tarde com trabalho substancial de muitos(as) outros(as). Os recursos necessários para tornar texi2html um substituto para makeinfo foram implementados por Patrice Dumas. Esse programa, no entanto, nunca foi lançado.

A atual implementação (também escrita por Patrice Dumas) herdou o projeto de personalização e outros recursos do texi2html (para mais acerca da compatibilidade do texi2html, veja-se texi2html: Ancestral do texi2any). No entanto, o texi2any foi uma reimplementação completa: diferente do texi2html, ele constrói uma representação baseada em árvore do documento de entrada para todas as estruturas de retaguarda trabalharem.

O novo programa Perl pretendia ter as seguintes vantagens sobre o antigo programa C:

  • Personalização do HTML. Muitos pacotes GNU e outros softwares livres têm sido felizes no uso dos recursos de personalização de HTML no texi2html por anos. Assim, na verdade, duas implementações independentes da linguagem Texinfo foram desenvolvidas, e mantê-las em sincronia não era simples. Adicionar a possibilidade de personalização de HTML no texi2html a um programa C teria sido um esforço enorme na época.
  • Unicode e suporte multilíngue em geral, especialmente de idiomas do leste asiático. Naquela época, fazer isso em C teria sido equivalente a reescrever o programa inteiro.
  • Estruturas adicionais de retaguarda. O código do makeinfo se tornou complicado até o ponto onde adicionar-se uma nova estrutura de retaguarda era bastante complexo, exigindo interações complexas com estruturas de retaguarda existentes. Em contraste, a nova implementação fornece uma representação limpa baseada em árvore para todas as estruturas de retaguarda trabalharem. Pessoas têm solicitado numerosas estruturas de retaguarda (LaTeX, o mais recente (X)HTML, …); essa mudança as tornou muito mais viáveis de implementar.
  • texi2any foi concebido para ser uma implementação de referência que define partes da linguagem não totalmente especificadas pelo manual e para fornecer uma referência para opções de linha de comando para qualquer outro programa que possa processar o Texinfo no futuro.

Na época, o novo programa Perl era muito mais lento que o antigo programa C. Desde então, o analisador, parte do conversor Info e o conversor HTML como um todo foram traduzidos para C, levando a importantes ganhos de velocidade comparado com a implementação Perl pura do texi2any. O programa principal também foi traduzido para C. A implementação C do texi2any embute um interpretador Perl para as partes que exigem Perl.
