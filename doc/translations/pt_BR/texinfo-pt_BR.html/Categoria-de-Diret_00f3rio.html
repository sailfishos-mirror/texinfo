2.6 Categoria de Diretório ¶

Use o comando @dircategory para especificar uma categoria para o manual.

Comandos @dircategory geralmente são seguidos por blocos @direntry, que são usados pelo install-info. Veja-se Instalando Arquivos de Diretório Info, para um exemplo de como esses comandos são usados.

O primeiro comando @dircategory em um manual é a categoria para o manual inteiro. Usos subsequentes de @dircategory configuram a categoria somente para blocos @direntry seguintes.

Não existe consistência no uso de categorias de diretório entre manuais, e é improvável que alguma vez exista, já que os(as) autores(as) trabalham na documentação do Texinfo independentemente, sem nenhuma coordenação central que resultaria em tal consistência.

É possível para usuários(as) ou para distribuições de sistemas operacionais editarem categorias em arquivos do Info ou do Texinfo, se uma organização lógica dentro de arquivos dir for algo que eles(as) valorizem.

Autores(as) de manuais podem considerar usar algumas das seguintes categorias para manuais. Para um pacote que instale muitos manuais (como o Emacs), pode ser uma boa ideia usar categoria específica de pacote, ou categorias, para agrupar os manuais dele.
