21.3 Perguntas Frequentes do Formato Info ¶

Aqui estão algumas perguntas que tem sido feitas frequentemente nas listas de discussão e em outros lugares.

Por que quando executo ‘info foo’ eu obtenho a mesma saída que ‘man foo’?

Verifique se os manuais do Info estão instalados. Nem todas as distribuições GNU/Linux instalam todos os manuais do Info por padrão. Isso é lamentável, pois frequentemente o manual do Info fornece mais informações que a página de manual fornecida.

Por que não usar HTML em vez do Info?

Manuais raramente são escritos no próprio formato Info, mas são gerados a partir do fonte Texinfo pelo programa texi2any. texi2any consegue gerar HTML e também Info a partir do fonte Texinfo. Você também consegue acessar e baixar manuais em HTML a partir do sítio web do GNU (https://www.gnu.org/manual/manual.html). Além disso, algumas distribuições GNU/Linux fornecem pacotes para a instalação de manuais HTML.

Info ainda tem algumas vantagens sobre HTML para documentação instalada localmente. Os navegadores do Info suportam pesquisa de índice e suportam linques entre manuais instalados localmente em vários locais. É importante ter-se documentação instalada localmente em tua máquina em vez de depender da Internet; isso torna o acesso à documentação mais confiável e garante que ela corresponda às versões instaladas dos pacotes. Espera-se que o suporte para navegar na documentação do Texinfo instalada localmente em alguma forma de HTML possa ser melhorado no futuro.

Por que fornecer o programa de linha de comando info quando o leitor Info do Emacs é melhor?

O leitor Info do Emacs consegue exibir imagens e suporta completamente usar um mouse. Não existem muitas diferenças entre os leitores Info além disso. info de linha de comando pode ser configurado para mudar as combinações padrão de teclas, bem como mudar a cor de referências cruzadas e de resultados de pesquisa, e para habilitar suporte à rolagem do mouse. Você não deveria precisar ter experiência com o editor Emacs para usar info. (Alguns(mas) recomendam outro programa chamado pinfo, mas esse carece de recursos importantes como pesquisa de índice).

Alguns(mas) preferem poder percorrer o manual inteiro de uma vez (como acontece com páginas de manual), em vez de ficarem limitados(as) a um ‘nó’ de conteúdo por vez. É claro que não existe consideração pelo gosto, mas um bloco de texto não estruturado torna-se mais estranho à medida que um manual se torna mais longo e mais complicado. (No entanto, se realmente quiser, você consegue visualizar um manual Info de uma só vez no paginador less com ‘info foo | less’).

Por que eu tenho ‘veja-se’ aparecendo em frente de todos os meus linques?

Por padrão, o modo Info do Emacs ou muda o marcador ‘*note’ para referências cruzadas para ‘veja-se’ ou o oculta completamente. info de linha de comando faz o mesmo se hide-note-references estiver configurado. Infelizmente, não existe maneira de fazer isso confiavelmente, já que ambos os comandos @pxref e @ref no Texinfo geram esse marcador na saída Info, e o texto ‘veja-se’ é apropriado somente para @pxref.

Sim, mas como eu obtenho um linque simples, sem marcações extras?

Você não pode. Info é um formato de texto simples que é exibido principalmente como está nos visualizadores e sem o texto ‘*note’ não existiria nada para marcar o texto como um linque.

Para formatos de saída como HTML, você pode usar o comando @link para produzir um linque simples. Veja-se @link: Simples, hiperlink desadornado. No entanto, isso não produz uma referência cruzada funcional na saída Info ou em uma cópia impressa do manual.

Por que linhas contendo linques parecem misteriosamente curtas?

Isso se deve ao Emacs (ou info com hide-note-references configurado como ‘On’) ocultando sequências de caracteres ‘*note’, conforme mencionado acima.

Pode o formato Info ser estendido para suportar fontes, cores ou texto refluível?

Qualquer extensão seria incompatível com programas de visualização do Info existentes. Marcações extras adicionadas aos arquivos Info seriam exibidas para o(a) usuário(a), tornando os arquivos feios e ilegíveis.

Quando arquivos Texinfo são processados em arquivos Info, as informações acerca de quais comandos do Texinfo foram usados para marcar o texto são perdidas. Além disso, não é possível detectar com segurança se o texto consegue ser refluído (por exemplo um parágrafo de prosa) ou se as quebras de linha deveriam ser mantidas (por exemplo uma amostra de código ou um poema).

O propósito central do Info é o de exibir documentação em terminais de texto. Se você quiser mais, é recomendável usar a saída HTML proveniente do texi2any.
