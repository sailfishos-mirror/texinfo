20 texi2any: O Tradutor para Texinfo ¶

texi2any é o tradutor genérico para o Texinfo que consegue produzir formatos de saída diferentes e é altamente personalizável. Ele suporta estes formatos: 

Info (por padrão, ou com --info),
HTML (com --html),
EPUB 3 (com --epub3),
texto simples(com --plaintext),
LaTeX (com --latex),
DocBook (com --docbook),
Texinfo XML (com --xml).

makeinfo é um apelido para texi2any. Por padrão, texi2any e makeinfo geram saída Info; de fato, não existem diferenças de comportamento baseadas no nome.

Além desses formatos padrão, as opções de linha de comando para texi2any podem mudar muitos aspectos da saída gerada. Além disso, os arquivos de inicialização fornecem ainda mais controle sobre a saída final—quase tudo o que não esteja especificado no arquivo de entrada do Texinfo. Os arquivos de inicialização são escritos em Perl, e qualquer coisa que possa ser especificada na linha de comando também pode ser especificada em um arquivo de inicialização.

Duas implementações funcionalmente equivalentes do texi2any podem ser construídas no GNU Texinfo, uma em Perl e outra em código nativo compilado (em C). A implementação de código nativo ainda é experimental. O programa Perl pode usar módulos de extensão Perl em código nativo compilado, enquanto o programa de código nativo embute um interpretador Perl para as partes que exigem Perl.

No caso padrão, a implementação Perl é instalada. Você consegue selecionar a implementação experimental C ao tempo da construção, passando a opção --enable-using-c-texi2any para configure.
