22.7.2 Expansão de Nome de Nó de Referência Cruzada do HTML ¶

Conforme mencionado na seção anterior, a parte chave do algoritmo de referência cruzada do HTML é a conversão de nomes de nós no fonte do Texinfo em sequências de caracteres adequadas para identificadores do XHTML e nomes de arquivos. As restrições são semelhantes para cada um: letras ASCII simples, números e os caracteres ‘-’ e ‘_’ são tudo o que pode ser usado. (Embora âncoras do HTML possam conter a maioria dos caracteres, XHTML é mais restritivo).

Referências cruzadas no Texinfo podem referir-se ou a nós, ou a âncoras (veja-se @anchor: Definindo Alvos Arbitrários de Referências Cruzadas) ou rótulos flutuantes (veja-se @float [tipo][,rótulo]: Material Flutuante). Entretanto, âncoras e rótulos flutuantes são tratados identicamente aos nós nesse contexto, de modo que nós continuaremos a dizer nomes de “nós” para simplicidade.

Uma exceção especial: o nó Top (veja-se O Nó ‘Top’) é sempre mapeado para o arquivo index.html, para corresponder ao software do servidor web. No entanto, o alvo do HTML é ‘Top’. Assim (no caso dividido): 

@xref{Top,,, emacs, O Manual do GNU Emacs}.
⇒ <a href="../emacs_html/index.html#Top">
  1. As letras ASCII padrão (a-z e A-Z) não são modificadas. Todos os outros caracteres podem ser mudados conforme especificado abaixo.
  2. Os números ASCII padrão (0-9) não são modificados, exceto quando um número for o primeiro caractere do nome do nó. Nesse caso, veja-se abaixo.
  3. Vários caracteres consecutivos de espaço, tabulação e nova linha serão transformados em apenas um espaço.
  4. Espaços iniciais e finais serão removidos.
  5. Depois que o acima tiver sido aplicado, cada caractere de espaço restante será convertido em um caractere ‘-’.
  6. Outros caracteres ASCII de 7 bits serão transformados em ‘_00xx’, onde xx é o código do caractere ASCII em hexadecimal (minúsculas). Isso inclui ‘_’, o qual é mapeado para ‘_005f’.
  7. Se o nome do nó não começar com uma letra, a sequência de caracteres literal ‘g_t’ será prefixada ao resultado. (Devido às regras acima, essa sequência de caracteres nunca pode ocorrer de outra forma; é uma escolha arbitrária, significando “GNU Texinfo”). Isso é necessário porque o XHTML exige que identificadores comecem com uma letra.

Por exemplo: 

@node Um  nó --- com _'%
⇒ Um-no-_002d_002d_002d-com-_005f_0027_0025

Traduções exemplo de caracteres comuns:

  • ‘_’ ⇒ ‘_005f’
  • ‘-’ ⇒ ‘_002d’
  • ‘Um nó’ ⇒ ‘Um-nó’

Em sistemas computacionais normalizantes de maiúsculas e minúsculas, nós que diferem somente por maiúsculas e minúsculas serão mapeados para o mesmo arquivo. Em particular, como mencionado acima, Top sempre mapeia para o arquivo index.html. Assim, em um sistema normalizante de maiúsculas e minúsculas, Top e um nó chamado ‘Index’ serão ambos escritos para index.html. Felizmente, os alvos servem para distinguir essas maiúsculas e minúsculas, uma vez que nomes de alvos do HTML são sempre sensíveis a maiúsculas e minúsculas, independentemente do sistema operacional.
