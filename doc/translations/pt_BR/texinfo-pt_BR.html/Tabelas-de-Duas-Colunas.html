8.4 Fazendo Uma Tabela de Duas Colunas ¶

@table é similar a @itemize (veja-se @itemize: Construindo Uma Lista de Itens), mas permite que você especifique um nome ou uma linha de título para cada item. O comando @table é usado para produzir tabelas de duas colunas, e é especialmente útil para glossários, exibições explicativas, e resumos de opções de linha de comando.
