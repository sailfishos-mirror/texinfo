13.5 @w{texto}: Impedir Quebras de Linha ¶

@w{texto} gera texto, ao mesmo tempo que proíbe quebras de linha dentro do texto.

Assim, você pode usar @w para produzir um espaço não quebrável, fixado na largura de um espaço normal interpalavras: 

@w{ } @w{ } @w{ } recuo.

produz: 

      recuo.

O espaço oriundo de @w{ }, além de ser não quebrável, também não esticará nem encolherá. Às vezes isso é o que você quer, por exemplo, se estiver fazendo recuo manual. No entanto, normalmente você quer um espaço normal interpalavra que estique e encolha (na saída impressa); para isso, veja-se o comando @tie na próxima seção.

Na saída impressa, você também pode usar o comando @w para impedir que um nome longo ou uma frase seja automaticamente hifenizada, por exemplo se acontecer perto do fim de uma linha.

Você também pode usar @w para evitar expansão indesejada de palavra-chave em sistemas de controle de fonte. Por exemplo, para escrever literalmente $Id$ em teu documento, use @w{$}Id$. Entretanto, esse truque não é eficaz para arquivos de saída em alguns formatos de saída.
