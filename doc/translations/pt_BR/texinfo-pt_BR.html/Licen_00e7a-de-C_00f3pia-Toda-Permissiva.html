C.3 Licença de Cópia Toda Permissiva ¶

Para manuais de software e outras documentações, é importante usar uma licença que permita redistribuição e atualização livres, de modo que quando um programa livre for mudado, a documentação também possa ser atualizada.

Por outro lado, para pequenos arquivos de suporte, manuais curtos (menos de 300 linhas) e documentação aproximada (arquivos README, arquivos INSTALL, entre outros), a Licença de Documentação Livre completa seria um exagero. Eles podem usar uma licença simples e totalmente permissiva.

Aqui está um texto de amostra para uma tal licença totalmente permissiva. Este é apenas o próprio texto da licença. Para um documento completo de amostra, vejam-se as seções anteriores. 

Copirraite @copyright{} 2026 Fundação do Software Livre, Inc.

A cópia e distribuição deste arquivo, com ou sem modificação, são
permitidas em qualquer meio sem royalties, desde que o aviso de copirraite e
este aviso sejam preservados.
