6.1.12 @dfn{termo} ¶

Use o comando @dfn para identificar o uso introdutório ou definidor de um termo técnico. Use o comando somente em passagens cujo propósito seja o de introduzir um termo que será usado novamente ou que o(a) leitor(a) deva saber. A mera menção de passagem de um termo pela primeira vez não merece @dfn. O comando seleciona uma fonte inclinada no manual impresso, e gera aspas duplas no arquivo Info. Por exemplo: 

Livrar-se de um arquivo é chamado @dfn{deletar} ele.

produz

Livrar-se de um arquivo é chamado deletar ele.

Como uma regra geral, uma frase contendo a ocorrência definidora de um termo deveria ser uma definição do termo. A frase não precisa dizer explicitamente que é uma definição, mas deveria conter a informação de uma definição—ela deveria tornar claro o significado.
