2.10 O Nó ‘Top’ ¶

O nó ‘Top’ é o nó no qual um(a) leitor(a) acessa um manual Info. Como tal, ele deveria conter uma descrição muito breve do manual (incluindo o número de versão). O conteúdo do nó ‘Top’ não aparece em saída impressa nem na saída DocBook.

É convencional escrever uma linha com um comando @top contendo o título do documento imediatamente depois da linha @node Top (veja-se O Comando de Seccionamento @top).

Nós repetimos a descrição curta desde o início do texto ‘@copying’, mas não existe necessidade de repetir as informações de direitos autorais, de forma que nós não usamos ‘@insertcopying’ aqui.

Na saída Info (e às vezes na saída HTML), o nó ‘Topo’ geralmente contém um menu de nível superior listando os capítulos, e possivelmente um menu detalhado listando todos os nós em todo o documento. Geralmente não é necessário fornecer tal menu no fonte do Texinfo, pois texi2any gera esses menus automaticamente. No entanto, o exemplo a seguir mostra como você usaria o comando @menu para fornecer um menu no nó ‘Topo’: 

@node Top
@top Amostra Curta

Esta é uma amostra curta do arquivo do Texinfo.


@menu
* Primeiro Capítulo:: O primeiro capítulo é o
                      único capítulo nesta amostra.
* Index::             Índice completo.
@end menu
