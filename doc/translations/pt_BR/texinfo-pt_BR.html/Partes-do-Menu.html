3.9.4 As Partes de um Menu ¶

Uma entrada de menu tem três partes, somente a segunda das quais é exigida:

  1. O nome de entrada de menu (opcional).
  2. O nome do nó (exigido).
  3. Uma descrição do item (opcional).

O modelo para uma entrada genérica de menu se parece com isto (porém, veja-se a próxima seção para mais uma possibilidade): 

* nome_de_entrada_de_menu: nome_de_nó.   descrição

Siga o nome de entrada de menu com dois pontos, e siga o nome de nó com tabulação, vírgula, nova linha ou os dois caracteres ponto e espaço (‘. ’).

A terceira parte de uma entrada de menu é uma frase descritiva ou sentença. Os nomes de entrada de menu e os nomes de nó frequentemente são curtos; a descrição explica para o(a) leitor(a) a respeito de que se trata o nó. Uma descrição útil complementa o nome de nó em vez de repeti-lo. A descrição, que é opcional, pode ser espraiada por várias linhas; se isso acontecer, alguns(mas) autores(as) preferem recuar a segunda linha enquanto outros(as) preferem alinhá-la com a primeira (e todas as outras). É completamente com você. Uma linha vazia, ou a próxima entrada de menu, finaliza a descrição.

Os caracteres de espaço em um menu são preservados como estão na saída Info; isso te permite formatar o menu como você desejar. Infelizmente, você precisa digitar os nomes de nó sem quaisquer espaços extras ou algumas versões de alguns leitores Info não encontrarão o nó (veja-se Exigências da Linha de @node).

texi2any alerta e protege nomes quando o texto de um item de menu (e nomes e referências cruzadas de nó) contiver uma construção problemática que puder interferir com a análise dele no Info. (Veja-se Restrições de Nomes de Nó do Info).
