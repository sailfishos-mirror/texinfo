4.1 Estrutura de Árvore das Seções ¶

Um arquivo Texinfo geralmente é estruturado como um livro com capítulos, seções, subseções, e afins. Essa estrutura pode ser visualizada como uma árvore (ou melhor, como uma árvore de cabeça para baixo) com a raiz no topo e os níveis correspondendo aos capítulos, seções, subseções e subsubseções.

Aqui está um diagrama que mostra um arquivo Texinfo com três capítulos, cada qual com duas seções. 

                         Top
                          |
        -------------------------------------
       |                  |                  |
    Capítulo 1         Capítulo 2         Capítulo 3
       |                  |                  |
    --------           --------           --------
   |        |         |        |         |        |
 Seção    Seção     Seção    Seção     Seção    Seção
  1.1      1.2       2.1      2.2       3.1      3.2

Em um arquivo Texinfo que tenha essa estrutura, o início do Capítulo 2 poderia ser escrito assim: 

@node    Capítulo 2
@chapter Capítulo 2

Para propósitos de exemplo, aqui está como poderia ser escrito com ponteiros explícitos de nó: 

@node    Capítulo 2,  Capítulo 3, Capítulo 1, Top
@chapter Capítulo 2

Os comandos de estruturamento de capítulo estão descritos nas seções que seguem; o comando @node está descrito no capítulo anterior (veja-se Nós).
