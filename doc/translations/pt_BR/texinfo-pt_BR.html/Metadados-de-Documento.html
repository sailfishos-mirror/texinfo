2.8.1 Metadados do Documento e o Comando @maketitle ¶

A maneira mais simples para definir metadados de documento usados para a página de título é a de usar-se o comando @documentinfo. Aqui está um modelo: 

@documentinfo
@title nome-do-manual-quando-impresso
@subtitle subtítulo-se-existir
@subtitle segundo-subtítulo
@author autor(a)
@end documentinfo

Você só deveria usar o comando @title uma vez dentro do bloco @documentinfo. Você pode usar o comando @subtitle mais que uma vez, e a ordem em que quaisquer comandos @subtitle aparecem no bloco é mantida quando o arquivo do Texinfo for processado. Da mesma forma, você pode usar @author mais que uma vez. (No entanto, a ordem dos comandos @title, @subtitle e @author em relação um ao outro não é significativa).

As informações para a página de copirraite aparecem dentro dos comandos @copying e @publication. Veja-se Permissões do Documento para mais discussão do @copying.

O comando @publication funciona muito similarmente a @copying. Os processadores de Texinfo salvam o conteúdo desse bloco quando o encontram no fonte de Texinfo. Você usa esse comando para fornecer informações acerca da publicação do documento, como o endereço do(a) editor(a) ou o ISBN. Você usa esse bloco para informações que seriam “impressas” ou “colofões” em um livro impresso.

Finalmente, para realmente gerar as páginas de título e de copirraite, você usa o comando @maketitle. Escreva esse comando sozinho em uma linha. Isso reúne as informações disponíveis para produzir essas duas páginas.

Esses comandos seriam usados assim: 

@copying
informações-cópia
@end copying
@publication
Publicado por nome-editor(a)
endereço-editor(a)
@end publication
@maketitle
