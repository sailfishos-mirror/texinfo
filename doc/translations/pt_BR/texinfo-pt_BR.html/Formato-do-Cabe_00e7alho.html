E.2.2 Formatos Padrão de Cabeçalho ¶

O Texinfo fornece dois formatos padrão de cabeçalho, um para manuais impressos em um lado de cada folha de papel e outro para manuais impressos em ambos os lados do papel.

O formato padrão para impressão em um lado consiste de uma linha de cabeçalho na qual a parte esquerda contém o nome do capítulo, a parte central fica em branco e a parte direita contém o número da página. Uma página de um lado se parece com isto: 

  _____________________________
 |                             |
 | capítulo   número da página |
 |                             |
 | Início do texto ...         |
 | ...                         |
 |                             |

No formato frente e verso padrão, a parte esquerda da página esquerda (número par) contém o número da página, a parte central fica em branco e a parte direita contém o título (especificado pelo comando @settitle). A parte esquerda da página direita (número ímpar) contém o nome do capítulo, a parte central fica em branco e a parte direita contém o número da página. Uma página par e uma página ímpar, lado a lado como em um livro aberto, se parecem com isto: 

  _____________________________     _____________________________
 |                             |   |                             |
 | número da página     título |   | número da página   capítulo |
 |                             |   |                             |
 | Início do texto...          |   | Mais texto...               |
 | ...                         |   | ...                         |
 |                             |   |                             |

O nome do capítulo é precedido pela palavra “Capítulo”, o número do capítulo e dois pontos. Isso torna mais fácil acompanhar onde você está no manual.

Observe que nas páginas onde um novo capítulo começa, algum texto pode ser omitido da linha do cabeçalho.

Por padrão, nada é especificado para o rodapé de um arquivo do Texinfo, de modo que o rodapé permanece em branco.
