9.1.3 @listoffloats: Sumários para Flutuadores ¶

Você pode escrever um comando @listoffloats para gerar uma lista de flutuações para um dado tipo de flutuação (veja-se @float [tipo][,rótulo]: Material Flutuante), análogo ao sumário geral do documento. Tipicamente, ele é escrito no nó @unnumbered dele próprio para fornecer um cabeçalho e estrutura, mais como @printindex (veja-se Imprimindo Índices e Menus).

@listoffloats recebe um argumento opcional, o tipo de flutuação. Aqui está exemplo: 

@node Lista de Figuras
@unnumbered Lista de Figuras
@listoffloats Figura

Sem nenhum argumento, @listoffloats gera uma lista de flutuações para os quais nenhum tipo de flutuação foi especificado, ou seja, nenhum primeiro argumento para o comando @float (veja-se @float [tipo][,rótulo]: Material Flutuante).

Aqui está com o que se parece a saída gerada a partir de @listoffloats, dada a figura de exemplo anterior neste capítulo:

Figure 9.1

Geralmente, cada linha na lista de flutuações contém o tipo de flutuação (se existir), o número da flutuação, e a legenda, se existir—o argumento @shortcaption, se foi especificado, do contrário o argumento @caption. O número da página também pode ser incluído, dependendo do formato da saída gerada.

Flutuadores não numerados (aquelas sem rótulos de referência cruzada) são omitidos da lista de flutuações.

A formatação de @listoffloats depende do formato da saída gerada. No Info, por exemplo, um @listoffloats é formatado como um menu.

Na saída LaTeX, \listoffigures é gerado para o tipo de flutuação ‘figure’ (sem distinção entre maiúsculas e minúsculas), \listoftables é gerado para o tipo de flutuação ‘table’ (sem distinção entre maiúsculas e minúsculas). Para outros tipos de flutuação, um comando \listof específico é gerado.
