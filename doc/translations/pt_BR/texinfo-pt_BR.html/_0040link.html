5.12 @link: Simples, hiperlink desadornado ¶

@link produz um hiperlink simples nos formatos de saída que o suportam, incluindo em HTML, DocBook, LaTeX e PDF online. O modelo é: 

@link{nome-nó, rótulo, nome-manual}

nome-nó é o nome do nó ou âncora alvo. Ou um ou ambos de rótulo e nome-manual podem ser omitidos. rótulo, se fornecido, é o texto a se usar para o link. nome-manual é o nome do manual externo em que o alvo aparece; Se não fornecido, a referência é para o manual atual.

@link tem saída gerada semelhante a @ref, exceto que ele não produz nenhum texto extra em torno do rótulo do linque no Info ou na saída impressa que o marcaria como uma referência cruzada.

Tenha cuidado ao usar @link para produzir linques que sejam necessários para um(a) usuário(a) se mover em um manual, pois esses linques não farão nada em alguns formatos de saída. @link é melhor usado para adicionar linques de conveniência que, no entanto, não são essenciais para um(a) leitor(a) entender o texto do manual. Por exemplo, você pode usar @link em uma amostra de código para referenciar documentação de um símbolo em uma biblioteca de programação.
