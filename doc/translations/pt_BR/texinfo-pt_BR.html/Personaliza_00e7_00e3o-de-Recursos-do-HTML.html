22.8.4 Personalização de Recursos do HTML ¶

Por padrão, o HTML é gerado, mas você consegue configurar USE_XML_SYNTAX para a finalidade de gerar código compatível com XML. A principal diferença é que ‘/>’ em vez de ‘>’ encerra etiquetas como <img> ou <link> que não têm uma etiqueta de fechamento (essas etiquetas criam os assim chamados elementos void).

Para configurar o DOCTYPE, configure a variável de personalização DOCTYPE. O padrão é o DOCTYPE simples sem DTD usado para HTML5.

Você consegue configurar um arquivo compatível com XML começando: 

texi2any --html meu_manual.texi -c USE_XML_SYNTAX \
   -c DOCTYPE='<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE html>'

Você também poderia configurar o DOCTYPE como HTML 4.01 Transitório: 

texi2any --html meu_manual.texi -c DOCTYPE=\
'<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN"
  "http://www.w3.org/TR/html4/loose.dtd">'

Por padrão, entidades são usadas para caracteres duplicados de aspas simples (veja-se Inserindo Aspas) e ‘---’ e ‘--’ (veja-se Convenções Sintáticas Gerais). Configure USE_ISO como ‘0’ no caso improvável de você querer uma saída mais simples. Por padrão, entidades textuais são usadas quando possível. Configure USE_NUMERIC_ENTITY para usar somente entidades numéricas. Configure OUTPUT_CHARACTERS para gerar caracteres acentuados baseados na codificação da saída gerada em vez de nas entidades.

Por padrão, um atributo personalizado, conforme permitido pelo padrão, é usado para fornecer o nome do manual alvo em referências cruzadas. Se não for desejável, por exemplo, gerar XHTML estrito, você pode configurar NO_CUSTOM_HTML_ATTRIBUTE para evitar atributos personalizados sendo gerados.

Linques copiáveis são gerados para alvos de linque para os comandos de definição (veja-se Comandos de Definição), comandos de tabela (veja-se Fazendo Uma Tabela de Duas Colunas) onde uma entrada de índice estiver definida e cabeçalhos. Um linque aparece como um sinal ‘¶’ que aparece quando você passa o ponteiro do mouse sobre o texto do título. Desconfigure COPIABLE_LINKS para evitar que linques copiáveis sejam gerados.
