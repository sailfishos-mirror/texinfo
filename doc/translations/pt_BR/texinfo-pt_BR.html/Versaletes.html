6.2.2 @sc{texto}: A Fonte de Versaletes ¶

Use o comando ‘@sc’ para configurar texto em UMA FONTE DE VERSALETES (onde possível). Escreva o texto que você quer que esteja em versaletes entre chaves e em letras minúsculas, como isto: 

Richard @sc{Stallman} a commencé le projet GNU.

Isso produz: 

Richard STALLMAN a commencé le projet GNU.

Como mostrado aqui, nós recomendamos reservar @sc para casos especiais onde você queira versalete tipográfica; nomes de família são um desses, especialmente em outros idiomas diferentes do Inglês, embora não existam regras rígidas acerca de tais coisas.

TeX tipografa quaisquer letras maiúsculas entre as chaves de um comando @sc em letras maiúsculas de tamanho real; somente letras minúsculas são impressas na fonte de versaletes. Na saída Info, o argumento para @sc é impresso todo em maiúsculas. Em HTML, o argumento é colocado em letras maiúsculas e a saída marcada com a etiqueta <small> para reduzir o tamanho da fonte, pois o HTML não consegue facilmente representar versaletes verdadeiras. No LaTeX, um comando configurando fontes de versaletes é gerado.

No geral, nós recomendamos usar letras padrão maiúsculas e minúsculas sempre que possível.
