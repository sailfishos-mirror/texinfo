22.1 Tradução do HTML ¶

O HTML gerado pelo texi2any gera saída HTML padrão. A saída gerada é intencionalmente bastante simples para máxima portabilidade e acessibilidade.

Você consegue personalizar a saída gerada via CSS (veja-se CSS do HTML) ou outros meios (veja-se Personalização da Saída Gerada HTML). Se você não conseguir realizar uma personalização razoável, sinta-se à vontade para informar isso.

Barra de navegação: Por padrão, uma barra de navegação é inserida no início de cada nó, análogo à saída gerada Info. Se a opção ‘--no-headers’ for usada, a barra de navegação só será inserida no início dos arquivos divididos. Elementos de cabeçalho <link> na saída dividida suportam navegação semelhante à Info com navegadores que implementem esse recurso.

HTML bruto: texi2any incluirá segmentos do fonte do Texinfo entre @ifhtml e @end ifhtml na saída gerada HTML (mas não qualquer dos outros condicionais, por padrão). Fonte entre @html e @end html é passado sem mudança para a saída gerada (ou seja, suprimindo a escapagem normal dos caracteres de entrada ‘<’, ‘>’ e ‘&’ os quais têm significância especial no HTML). Veja-se Comandos Condicionais.

Padrões: Não é nosso objetivo intencionalmente, e nem mesmo sempre possível, passar por cada teste de validação concebível sem quaisquer diagnósticos. Diferentes testes de validação têm objetivos diferentes, frequentemente acerca da imposição pedante de algum padrão ou de outro. Nosso objetivo primordial é o de ajudar usuários(as), não o de cumprir cegamente os padrões.

Por favor, informe a saída gerada proveniente de uma execução sem erros do texi2any que tenha problemas práticos de portabilidade do navegador ou do leitor de EPUB como um defeito (veja-se Informando Defeitos).

Na prática, o HTML produzido pelo texi2any é lentamente ajustado ao longo do tempo para o padrão HTML mais recente, enquanto também tenta manter compatibilidade com HTML produzido anteriormente. Nós usamos marcação de transição e tentamos ser lentos o suficiente para dar tempo para os diversos leitores de HTML se ajustarem (e para os padrões reincorporarem recursos úteis que foram eliminados…).
