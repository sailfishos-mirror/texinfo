20.4.5 Variáveis de Personalização do Info e de Texto Simples ¶

Esta tabela fornece as variáveis de personalização que se aplicam somente para formatos Info e Texto Simples.

ASCII_DASHES_AND_QUOTES ¶

Para saída gerada do Info, quando configurada, usar caracteres ASCII simples para representar aspas, hifens e travessões quando esses forem fornecidos no fonte do Texinfo como ‘-’, ‘--’, ‘---’, ‘`’, ‘``’, ‘'’ e ‘''’, em vez de aspas direcionais UTF-8, travessões, e assim por diante. Ligada por padrão.

ASCII_GLYPH ¶

Para saída gerada do Info, usar saída gerada ASCII para comandos de glifo, tais como o sinal de direito autoral (@copyright{}, tornando-se ‘(C)’) e o símbolo de marcador (@bullet{}, tornando-se ‘*’), em vez de outras sequências Unicode. Desligada por padrão.

ASCII_PUNCTUATION ¶

Evite quaisquer sequências UTF-8 e não-ASCII desnecessárias ou gratuitas na saída gerada. Implica ASCII_DASHES_AND_QUOTES e ASCII_GLYPH e, adicionalmente, afeta a saída gerada de comandos como @samp que geram aspas.

AUTO_MENU_DESCRIPTION_ALIGN_COLUMN ¶

Para saída gerada do Info, coluna na qual iniciar uma descrição de entrada de menu fornecida por @nodedescription ou @nodedescriptionblock. Indefinida por padrão, caso em que 45% do valor da coluna de preenchimento é usado (veja-se Invocando texi2any a partir de um Shell).

AUTO_MENU_MAX_WIDTH ¶

Número máximo de colunas em uma linha de entrada de menu no Info ao se adicionar uma descrição originária de @nodedescription ou @nodedescriptionblock. Indefinida por padrão, caso em que 10% a mais que o valor da coluna de preenchimento é usado (veja-se Invocando texi2any a partir de um Shell).

CLOSE_DOUBLE_QUOTE_SYMBOL ¶

Quando uma aspa dupla de fechamento for necessária, para ‘@dfn’ no Info, usar esse caractere. O padrão para Info é configurada da mesma forma que para OPEN_DOUBLE_QUOTE_SYMBOL, exceto que o código Unicode é uma aspa dupla de fechamento (veja-se abaixo).

INDEX_SPECIAL_CHARS_WARNING ¶

Se configurada, avisar acerca de ‘:’ na entrada do índice, pois nem todos os leitores Info podem processá-los. Somente para Info e texto simples. Padrão falso, porque os problemas de análise não impedem a navegação; os leitores ainda podem encontrar com relativa facilidade o caminho para o nó em questão.

INFO_MATH_IMAGES ¶

(Experimental). Se configurada, converter o conteúdo de @math e de @displaymath em imagens e referencie-os no arquivo Info produzido. Essa variável exige uma instalação funcional do TeX, o pacote ‘preview’ do LaTeX, bem como o programa dvipng. Pode ser adequado para documentos com muitas fórmulas matemáticas que provavelmente não serão visualizados em um terminal de texto.

Esse recurso é marcado como experimental, pois exigiria suporte extra em programas de visualização do Info (atualmente, somente o modo Info do Emacs) para visualizar as imagens corretamente. As imagens deveriam estar visíveis nas versões existentes do Emacs, mas podem ter o tamanho errado ou parecer desalinhadas com o texto ao redor. É possível que nós mudemos a saída gerada para essa opção com base em comentários adicionais. Veja-se Formato Info: Imagem para mais detalhes acerca de como as imagens são geradas atualmente com essa opção.

INFO_SPECIAL_CHARS_QUOTE ¶

Se configurada, sempre que existirem caracteres problemáticos para saída Info em locais como nomes de nós ou itens de menu, envolver a parte da construção onde eles aparecerem com caracteres de aspas, conforme descrito em Especificação do Formato Info. O padrão é configurada para Info e desconfigurada para texto simples. Veja-se Exigências da Linha de @node.

INFO_SPECIAL_CHARS_WARNING ¶

Se configurada, avisar acerca de construções problemáticas para saída Info (tais como a sequência de caracteres ‘::’) em nomes de nós, itens de menu e referências cruzadas. Se não configurada, configurar, a menos que INFO_SPECIAL_CHARS_QUOTE esteja configurada. O padrão é configurada para Info e não definida para texto simples. Avisos semelhantes em entradas de índice são abordados por INDEX_SPECIAL_CHARS_WARNING.

OPEN_DOUBLE_QUOTE_SYMBOL ¶

Quando uma aspa dupla de abertura for necessária, para saída gerada do ‘@dfn’ no Info, usar o caractere especificado. Se --disable-encoding estiver configurada ou a codificação do documento não for UTF-8, ‘"’ será usado. Caso contrário, a saída gerada do Info usará aspas duplas esquerdas do Unicode.
