15.1 @documentlanguage ll[_cc]: Configurar o Idioma do Documento ¶

O comando @documentlanguage declara a localidade atual do documento. Escreva-o em uma linha dedicada, perto do começo do arquivo. 

@documentlanguage ll[_cc]

Inclua um código de idioma ISO 639-2 de duas letras (ou de três letras) (ll) seguindo o nome do comando, opcionalmente seguido por um sublinhado e código de país ISO 3166 de duas letras ou de três letras (cc). Se você tiver um documento multi idioma, a intenção é a de poder usar esse comando várias vezes para declarar cada mudança de idioma.

Assim como com GNU Gettext (veja-se Gettext), se o código do país for omitido, o dialeto principal é assumido onde possível. Por exemplo, de é equivalente a de_DE (alemão como falado na Alemanha).

Esse comando muda a tradução de várias sequências de caracteres de documento, tais como “veja-se” em referências cruzadas (veja-se Referências cruzadas), “Função” em defuns (veja-se Comandos de Definição), e assim por diante. Opcionalmente, esse comando possivelmente afete como texi2any ordena índices (veja-se Variáveis Globais de Personalização, sob DOCUMENTLANGUAGE_COLLATION). Se o idioma do documento não estiver especificado, as sequências padrão de caracteres de documento em inglês serão geradas como estiverem.

Observe que na saída Info, algumas sequências de caracteres, como “Node:”, “Next:”, “Menu:”, entre outras, são palavras-chave e portanto não são traduzidas.

Na saída gerada DocBook, @documentlanguage configura o idioma para as seções seguintes.

Para LaTeX, esse comando faz com que o código carregue o pacote ‘babel’ para ser gerado no preâmbulo e \selectlanguage para ser gerado.

Para TeX, esse comando faz com que um arquivo txi-localidade.tex seja lido (se ele existir). Se o argumento @documentlanguage contiver o sufixo opcional ‘_cc’, esse será tentado primeiro. Por exemplo, com @documentlanguage de_DE, TeX primeiro procura por txi-de_DE.tex, depois por txi-de.tex.

Esse arquivo txi-* é destinado a redefinir as várias palavras em inglês usadas na saída do TeX, como ‘Chapter’, ‘See’ e assim por diante. Nós estamos cientes de que palavras individuais como essas nem sempre podem ser traduzidas isoladamente, e que uma estratégia muito diferente seria exigida para sequências de caracteres ideográficos (entre outros). Ajuda para melhorar o suporte a idiomas do Texinfo é bem-vinda.

@documentlanguage também muda os padrões atuais de hifenização do TeX, se o programa TeX sendo executado tiver o suporte necessário incluído. Isso geralmente não será o caso para tex em si, mas geralmente será o caso para distribuições atualizadas dos programas TeX estendidos etex (saída DVI) e pdftex (saída PDF). texi2dvi usará os TeXs estendidos se estiverem disponíveis (veja-se Formatar com texi2dvi).

Como as listas de códigos de idioma e códigos de país são atualizadas com relativa frequência, nós não tentamos listá-los aqui. Os códigos válidos de idioma estão na página inicial oficial do ISO 639, http://www.loc.gov/standards/iso639-2/. Os códigos de país e o sítio oficial do ISO 3166 podem ser encontrados via http://en.wikipedia.org/wiki/ISO_3166.
