18.2 Arquivo de Amostra com @include ¶

Aqui está um exemplo de um arquivo externo do Texinfo com arquivos @include dentro dele: 

\input texinfo @c -*-texinfo-*-

@settitle Exemplo de Inclusão




@node Top
@top Exemplo de Inclusão



@include foo.texi
@include bar.texi
@include indice-conceitos.texi
@bye

Um arquivo incluído, como foo.texi, pode se parecer com isto: 

@node Primeiro
@chapter Primeiro Capítulo

Conteúdo do primeiro capítulo ...

O conteúdo completo de indice-conceitos.texi pode ser tão simples quanto isto: 

@node Índice de Conceito
@unnumbered Índice de Conceito

@printindex cp

O arquivo fonte externo do Texinfo para O Manual de Referência da Lisp do GNU Emacs é chamado elisp.texi. Esse arquivo externo já conteve um menu mestre com 417 entradas e uma lista de 41 arquivos @include.
