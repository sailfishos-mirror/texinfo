7.3 @indentedblock: Blocos recuados de texto ¶

O ambiente @indentedblock é semelhante ao @quotation, exceto que o texto somente é recuado à esquerda (e não existe argumento opcional para um(a) autor(a)). Assim, a fonte do texto permanece inalterada, e o texto é reunido e preenchido como de costume, mas a margem esquerda é aumentada. Por exemplo:

Este é um exemplo de texto escrito entre um comando @indentedblock e um comando @end indentedblock. O ambiente @indentedblock pode conter qualquer texto ou outros comandos desejados.

Isso é escrito no fonte do Texinfo como: 

@indentedblock
Este é um exemplo ...
@end indentedblock
