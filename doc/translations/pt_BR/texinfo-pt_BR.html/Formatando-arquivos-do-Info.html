D.9 Formatação Direta de arquivos do Info ¶

Em geral, não existe necessidade de editar ou de processar arquivos do Info. A maior parte do conteúdo do arquivo do Info é texto simples, mas as tabelas de etiquetas exigem computar-se deslocamentos para nós e para arquivos indiretos (veja-se Arquivos de Etiqueta e Arquivos Divididos), o que é impraticável. Os processadores do Texinfo produzem Info bem formatados a partir da entrada Texinfo. Além disso, muitas informações originárias do fonte do Texinfo são perdidas no arquivo do Info. O fonte do Texinfo é portanto mais adequado para analisar um manual, seja para informe de erros, para estatísticas, ou para configurar traduções.

Ainda assim, especialmente com arquivos do Info escritos manualmente, existem algumas situações em que pode ser interessante processar arquivos do Info diretamente, em particular para computar deslocamentos de nós dos arquivos do Info e para computar deslocamentos de arquivo dos arquivos divididos do Info. Dois comandos do Emacs fazem isso. Info-tagify adiciona uma tabela de etiquetas para um arquivo não dividido carecendo de uma. Essa função também é útil para validação de arquivo do Info (veja-se Encontrando Nós Mal Referenciados). Também é possível dividir um arquivo não dividido do Info com Info-split.
