11.7.9 @minus (−): Inserindo um Sinal de Menos ¶

Use o comando @minus{} para gerar um sinal de menos. Onde a codificação de caractere e a fonte usada na saída gerada permitirem, o símbolo tem o comprimento habitual para um sinal de menos—um pouco mais longo que um hífen, mais curto que um travessão: 

‘−’ é um sinal de menos gerado com ‘@minus{}’,

‘-’ é um hífen gerado com o caractere ‘-’,

‘—’ é um travessão para texto.

Se você realmente quiser tipografar alguma matemática que faça uma subtração, é melhor usar @math, como em @math{a-b} (veja-se Formatando Expressões Matemáticas).
