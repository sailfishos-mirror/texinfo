4.6 @section: Seções Abaixo de Capítulos ¶

Um comando @section identifica uma seção dentro de uma unidade de capítulo, seja ela criada com @chapter, @unnumbered, ou @appendix, seguindo o esquema de numeração do comando de nível de capítulo. Assim, dentro de um capítulo @chapter numerado ‘1’, as seções são numeradas ‘1.1’, ‘1.2’, etc.; dentro de um “capítulo” @appendix rotulado ‘A’, as seções são numeradas ‘A.1’, ‘A.2’, etc.; dentro de um capítulo @unnumbered, a seção não é numerada.

Para criar uma seção, escreva o comando @section no início de uma linha e siga-o, na mesma linha, pelo título da seção. Por exemplo: 

@section Isto é uma seção

Títulos de seção são listados no sumário.
