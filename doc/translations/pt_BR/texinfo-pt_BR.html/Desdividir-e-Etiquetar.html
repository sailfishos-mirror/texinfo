D.10.4.2 Criando um Arquivo Desdividido e Adicionando uma Tabela de Etiquetas ¶

Você consegue executar Info-validate somente sobre um arquivo do Info que tenha uma tabela de etiquetas. O comando não funcionará sobre os subarquivos indiretos que forem gerados quando um arquivo mestre for dividido. Se tiver um arquivo grande (mais que 300.000 bytes ou mais), você necessita executar o comando texinfo-format-buffer, ou o makeinfo-buffer, de tal maneira que ele não crie subarquivos indiretos. Você também precisará criar uma tabela de etiquetas para o arquivo do Info. Depois que tiver feito isso, você pode executar Info-validate e procurar nós mal referenciados.

A primeira etapa é a de criar um arquivo do Info não dividido. Para evitar que texinfo-format-buffer divida um arquivo do Texinfo em arquivos do Info menores, forneça um prefixo para o comando M-x texinfo-format-buffer: 

C-u M-x texinfo-format-buffer

ou então 

C-u C-c C-e C-b

Quando você fizer isso, texinfo-format-buffer não dividirá o arquivo e não criará uma tabela de etiquetas para ele.

Depois de criar um arquivo do Info não dividido, você precisa criar uma tabela de etiquetas para ele (veja-se Etiquetando um Arquivo). Visite o arquivo do Info não dividido criado pelo texinfo-format-buffer e digite: 

M-x Info-tagify

A terceira etapa é a de validar o arquivo do Info: 

M-x Info-validate

(Observe o ‘I’ maiúsculo no Info-validate). Resumidamente, as etapas são: 

C-u M-x texinfo-format-buffer
M-x Info-tagify
M-x Info-validate

Depois que tiver validado a estrutura do nó, você pode reexecutar texinfo-format-buffer da maneira normal, de modo que ele construa uma tabela de etiquetas e divida o arquivo automaticamente, ou você pode criar a tabela de etiquetas e dividir o arquivo manualmente (veja-se Dividindo um Arquivo Manualmente).
