2.4 Amostra Curta ¶

Aqui está um arquivo curto de amostra do Texinfo. 

\input texinfo
@settitle Manual do Sample 1.0

@copying
Este é um exemplo curto de um arquivo completo do Texinfo.

Copyright @copyright{} 2026 Free Software Foundation, Inc.
@end copying
@documentinfo
@title Sample Title
@end documentinfo
@maketitle

@contents

@node Top
@top GNU Sample

Este manual é para GNU Sample
(versão @value{VERSION}, @value{UPDATED}).

@node Primeiro Capítulo
@nodedescription O primeiro capítulo é o único capítulo nesta amostra.
@chapter Primeiro Capítulo

@cindex capítulo, primeiro
Este é o primeiro capítulo.
@cindex entrada de índice, outra


Aqui está uma lista numerada.

@enumerate
@item
Este é o primeiro item.

@item
Este é o segundo item.
@end enumerate



@node Primeira Seção
@section Primeira Seção

Primeira seção do primeiro capítulo.


@node Segunda Seção
@section Segunda Seção

Segunda seção do primeiro capítulo.


@node Index
@nodedescription Complete Index
@unnumbered Index

@printindex cp

@bye
