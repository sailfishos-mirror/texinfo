3.7 Ilustração de Nó e Menu ¶

Aqui está um diagrama que ilustra um arquivo texinfo com três capítulos, cada um dos quais contém duas seções.

A “raiz” está no topo do diagrama e as “folhas” estão na parte inferior. É assim que esse diagrama é desenhado convencionalmente; ele ilustra uma árvore de cabeça para baixo. Por esse motivo, o nó raiz é chamado de nó ‘Top’ e os ponteiros do nó ‘Acima’ levam você mais perto da raiz. 

                         Top
                          |
        -------------------------------------
       |                  |                  |
    Capítulo 1         Capítulo 2         Capítulo 3
       |                  |                  |
    --------           --------           --------
   |        |         |        |         |        |
 Seção    Seção     Seção    Seção     Seção    Seção
  1.1      1.2       2.1      2.2       3.1      3.2

Usando-se ponteiros explícitos (não recomendados, mas mostrados para fins do exemplo), o comando totalmente escrito para iniciar o Capítulo 2 seria o este: 

@node     Capítulo 2,  Capítulo 3, Capítulo 1, Top
@comment  nome-nó,     próximo,    anterior,   acima

Essa linha @node diz que o nome desse nó é “Capítulo 2”, o nome do nó ‘Próximo’ é “Capítulo 3”, o nome do nó ‘Anterior’ é “Capítulo 1” e o nome do nó ‘Acima’ é “Top”. Você pode (e deveria) omitir escrever esses nomes de nós se teu documento estiver hierarquicamente organizado, mas os relacionamentos do ponteiro ainda obtém.

Para ir para as seções 2.1 e 2.2 usando Info, você precisa de um menu dentro do Capítulo 2. (Veja-se Menus). Você escreveria o menu pouco antes do início da Seção 2.1, como este: 

   @menu
   * Sect. 2.1::    Descrição desta seção.
   * Sect. 2.2::    Descrição.
   @end menu

Os ponteiros automáticos para o nó para Sect. 2.1 correspondem a: 

@node     Sect. 2.1, Sect. 2.2, ,         Capítulo 2
@comment  nome-nó,   próximo,   anterior, acima

Observe que nenhum ponteiro ‘Anterior’ é gerado, pois não existe outro nó no mesmo nível hierárquico antes de Sect. 2.1.

Usando ponteiros explícitos, o nó para Sect. 2.1 poderia ser escrito assim: 

@node     Sect. 2.1, Sect. 2.2, Capítulo 2, Capítulo 2
@comment  nome-nó,   próximo,   anterior,   acima

Com ponteiros automáticos, os ponteiros ‘Próximo’ e ‘Anterior’ de um nó levam a outros nós no mesmo nível—de capítulo para capítulo ou de seção para seção. Como mostrado, ao usar-se ponteiros explícitos, os ponteiros também podem liderar em outro lugar, aqui, por exemplo, o ponteiro ‘Anterior’ aponta para cima. Um ponteiro ‘Acima’ geralmente leva a um nó no nível acima (mais próximo do nó ‘Top’; e um ‘Menu’ leva a nós em um nível abaixo (mais próximo das ‘folhas’). (Uma referência cruzada pode apontar para um nó em qualquer nível; veja-se Referências cruzadas).

Tecnicamente, os ponteiros explícitos de nós podem te levar a qualquer nó, independentemente da estrutura do documento; mesmo para nós em um arquivo Info diferente. No entanto, seria muito confuso para leitores ter ponteiros ‘Próximo’, ‘Anterior’ e ‘Acima’ levando a nós que não correspondem, mesmo vagamente, ao nó próximo, anterior e acima.

Um comando @node e um comando de estruturamento de capítulo são usados convencionalmente juntos, nessa ordem, geralmente seguidos por comandos de indexação. (Como mostrado no exemplo acima, você pode seguir a linha @node com uma linha de comentários, por exemplo, para mostrar qual ponteiro é qual se ponteiros explícitos forem usados). Os processadores Texinfo usam esse construto para determinar as relações entre nós e comandos de seccionamento.

Aqui está o começo do capítulo neste manual chamado “Finalizando um Arquivo Texinfo”. Isso mostra uma linha @node seguida por uma linha @chapter e, em seguida, por linhas de indexação. 

@node Finalizando um Arquivo
@chapter Finalizando um Arquivo Texinfo
@cindex Finalizando um arquivo Texinfo
@cindex Finalização de arquivo Texinfo
@cindex Finalização de arquivo
