E.2.1 O Comando @headings ¶

O comando @headings raramente é usado. Ele especifica quais tipos de cabeçalhos e rodapés de página imprimir em cada página. Normalmente, isso é controlado pelo comando @setchapternewpage. Você precisará do comando @headings somente se o comando @setchapternewpage não fizer o que você quiser.

Você consegue usar @headings conforme segue:

@headings off

Desativar impressão dos cabeçalhos das páginas.

@headings single

Ativar cabeçalhos de página apropriados para impressão em um lado.

@headings double

Ativar cabeçalhos de página apropriados para impressão frente e verso.

@headings singleafter
@headings doubleafter

Ativar cabeçalhos single ou double, respectivamente, depois que a página atual for gerada.

@headings on

Ativar os cabeçalhos das páginas: single se ‘@setchapternewpage on’, double caso contrário.

Por exemplo, suponha que você escreva @setchapternewpage off antes do comando @titlepage para iniciar um novo capítulo na mesma página do final do último capítulo. Esse comando também faz com que os cabeçalhos das páginas sejam tipografados para impressão em um lado. Para fazer com que os cabeçalhos das páginas sejam tipografados para impressão frente e verso, escreva @headings double.

Você consegue impedir que quaisquer cabeçalhos de página sejam gerados escrevendo @headings off em uma linha própria, como esta: 

@headings off
