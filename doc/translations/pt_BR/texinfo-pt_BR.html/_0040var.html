6.1.7 @var{variável-metassintática} ¶

Use o comando @var para indicar variáveis metassintáticas. Uma variável metassintática é algo que representa outro pedaço de texto. Por exemplo, você deveria usar uma variável metassintática na documentação de uma função para descrever os argumentos que sejam passados para aquela função.

Não use @var para os nomes de variáveis normais em programas de computador. Esses são nomes específicos, de forma que @code é correto para eles. Por exemplo, a variável texinfo-tex-command da Emacs Lisp não é uma variável metassintática; ela é formatada adequadamente usando-se @code.

Tampouco use @var para variáveis de ambiente; @env é correto para elas (veja-se a próxima seção).

O efeito de @var no arquivo Info é o de mudar a escrita do argumento para letras todas maiúsculas. No manual impresso, o argumento é gerado em tipo inclinado. 4

Por exemplo, 

Para deletar o arquivo @var{nomearquivo},
digite @samp{rm @var{nomearquivo}}.

produz

Para deletar o arquivo nomearquivo, digite ‘rm nomearquivo’.

(Observe que @var pode aparecer dentro de @code, @samp, @file, etc).

Escreva uma variável metassintática toda em letras minúsculas e sem espaços, e use hifens para torná-la mais legível. Assim, o fonte do Texinfo para a ilustração de como iniciar um manual Texinfo se parece com isto: 

\input texinfo
@@settitle @var{nome-do-manual}

Isso produz: 

\input texinfo
@settitle nome-do-manual

Em alguns estilos de documentação, as variáveis metassintáticas são mostradas com colchetes angulares, por exemplo: 

..., digite rm <nomearquivo>

Entretanto, esse não é o estilo que Texinfo usa.

Notas de Rodapé

(4)

Na saída gerada do TeX, @var usa uma fonte inclinada de máquina de escrever em contextos de código como @code ou @example. Para usar uma fonte romana, inclinada e de largura variável, em todos os contextos, especifique ‘@clear txicodevaristt’ (veja-se @set e @value). Observe que esse sinalizador não faz nada na saída gerada do LaTeX.
