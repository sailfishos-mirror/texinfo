5.14.1 Exemplos @url ¶

Primeiro, aqui está um exemplo da forma mais simples de @url, com apenas um argumento. A URL fornecida é tanto o alvo quanto o texto visível do link: 

O sítio FTP GNU oficial é @url{https://ftp.gnu.org/gnu}.

produz: 

O sítio FTP GNU oficial é https://ftp.gnu.org/gnu.

Forma de dois argumentos de @url ¶

Aqui está um exemplo da forma de dois argumentos: 

O @url{https://ftp.gnu.org/gnu, sítio FTP GNU oficial}
mantém programas e textos.

o que produz: 

O sítio FTP GNU oficial
mantém programas e textos.

A saída HTML é esta: 

O <a href="https://ftp.gnu.org/gnu">sítio FTP GNU oficial</a>
mantém programas e textos.

Em outros formatos, a saída gerada é semelhante a isto: 

O sítio FTP GNU oficial (https://ftp.gnu.org/gnu)
mantém programas e textos.

Forma de três argumentos de @url ¶

Finalmente, um exemplo da forma de três argumentos: 

O programa @url{/man.cgi/1/ls,,ls} ...

o que, exceto para HTML, produz: 

O programa ls ...

porém com HTML: 

O programa <a href="/man.cgi/1/ls">ls</a> ...

A propósito, algumas pessoas preferem exibir URLs no inequívoco formato: 

<URL:http://dispositivo/caminho>

Você pode usar essa forma no arquivo de entrada de desejar. Nós sentimos que não é necessário incluir o ‘<URL:’ e ‘>’ na saída gerada, pois, para ser útil, qualquer software que tente detectar URLs em texto já tem de detectá-las sem o ‘<URL:’.
