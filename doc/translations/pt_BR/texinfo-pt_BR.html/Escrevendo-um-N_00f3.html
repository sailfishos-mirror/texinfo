3.1 Escrevendo uma Linha de @node ¶

Escreva @node no início de uma linha seguida pelo nome do nó, como isto: 

@node nome-do-nó

Depois de se ter inserido uma linha @node, você deveria imediatamente escrever um comando @ para o capítulo ou seção associado (se existir) e inserir o nome desse(a).

Você pode opcionalmente seguir o argumento de nome de nó para @node com até três argumentos opcionais no restante da mesma linha, separando os argumentos com vírgulas. Esses são os nomes dos ponteiros ‘Próximo’, ‘Anterior’, e ‘Acima’, nessa ordem. Assim, o modelo para uma linha de nó completamente preenchida com os ponteiros ‘Próximo’, ‘Anterior’, e ‘Acima’ se parece com isto: 

@node nome_do_nó, next, previous, up

O argumento nome_do_nó precisa estar presente, porém os outros são opcionais. Se você desejar especificar algum, porém não outros, apenas insira vírgulas conforme necessário, como em: ‘@node meu_nó,,,nó_superior’. Entretanto, se teu documento Texinfo for hierarquicamente organizado, como virtualmente todos são, nós recomendamos deixar desligados todos os ponteiros e permitir que texi2any os determine.

O programa texi2any automaticamente determina ponteiros de nó para um documento hierarquicamente organizado. Para ele fazer isso, cada comando @node deveria ser seguido imediatamente por um comando de seccionamento, como @chapter ou @section (exceto que linhas de comentários podem entrevir). Finalmente, você precisa seguir a linha @node do ‘Top’ com uma linha iniciando com @top para marcar o nó de nível superior no arquivo. Veja-se O Comando de Seccionamento @top.

Mesmo quando especificar explicitamente todos os ponteiros, você não pode escrever os nós no arquivo fonte do Texinfo em uma ordem arbitrária. Você precisa escrever os nós na ordem que deseja que eles apareçam na saída gerada. Para o formato Info, alguém pode imaginar que a ordem possivelmente não importe, mas importa para os outros formatos.

Na maioria dos casos, você desejará tirar vantagem do recurso de criação de ponteiros e não redundantemente especificar ponteiros de nó que os programas possam determinar. Entretanto, não são exigidos que documentos Texinfo estejam organizados hierarquicamente ou, de fato, contenham comandos de seccionamento (por exemplo, se você nunca pretender que o documento seja impresso), de forma que os ponteiros de nó ainda podem ser especificados explicitamente, em completa generalidade.

Se você estiver usando o GNU Emacs e quiser ponteiros explícitos, poderá usar os comandos de atualização de nós fornecidos pelo modo Texinfo para inserir os nomes dos ponteiros. (Veja-se Atualizando Nós e Menus).

Alternativamente, você pode inserir você mesmo(a) os ponteiros ‘Próximo’, ‘Anterior’ e ’Acima’. Se você fizer isso no Emacs, poderá achar útil usar o comando de teclado do modo Texinfo C-c C-c n. Esse comando insere ‘@node’ e uma linha de comentários listando os nomes dos ponteiros na ordem apropriada deles. A linha de comentários ajuda você a acompanhar quais argumentos são para quais ponteiros.
