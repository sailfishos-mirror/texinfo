17.6 @definfoenclose: Realçamento Personalizado ¶

Um comando @definfoenclose pode ser usado para definir um comando de realçamento para formatos de saída em linha. Um comando definido usando @definfoenclose marca o texto circundando-o em sequências de caracteres que precedem e seguem o texto.

Na prática, existe pouco uso para esse comando e nós não recomendamos o uso dele. O suporte para @definfoenclose possivelmente seja removido em lançamentos futuros do Texinfo.

Escreva um comando @definfoenclose no início de uma linha seguido por três argumentos separados por vírgula. O primeiro argumento para @definfoenclose é o nome do comando @ (sem o @); o segundo argumento é a sequência de caracteres delimitadora inicial; e o terceiro argumento é a sequência de caracteres delimitadora final. Os dois últimos argumentos circundam o texto realçado na saída.

Uma sequência de caracteres delimitadora pode conter espaços. Nem o delimitador inicial nem o final são exigidos. Se você não quiser um delimitador inicial, mas quiser um delimitador final, você precisa seguir o nome do comando com duas vírgulas em uma linha; do contrário, a sequência de caracteres delimitadora final que você pretendia será naturalmente (mal)interpretada como a sequência de caracteres delimitadora inicial.

Um comando de circundação definido dessa maneira recebe um argumento entre chaves, pois é destinado para novos comandos de marcação (veja-se Marcação de Texto, Palavras e Frases).

Por exemplo, você pode escrever: 

@definfoenclose phoo,//,\\

perto do início de um arquivo do Texinfo para definir @phoo como um comando do Info e do HTML que insira ‘//’ antes e ‘\\’ depois do argumento para @phoo. Você pode então escrever @phoo{bar} onde quiser ‘//bar\\’ realçado no Info e no HTML.

Para formatação do TeX, você poderia escrever 

@iftex
@alias phoo = i
@end iftex

para definir @phoo como um comando que faz com que o TeX tipografe o argumento para @phoo em itálico.

Cada definição se aplica ao próprio formatador dela: uma para TeX, o outra para formatos em linha. As definições do TeX precisam estar em ‘@iftex’. O comando @definfoenclose não precisa estar em ‘@ifinfo’, a menos que você queira usar definições diferentes para diferentes formatos de saída em linha. Comandos definidos do @definfoenclose não tem efeito na saída DocBook e LaTeX; os argumentos deles são gerados como são. Um @alias também poderia ser usado para esses formatos.

Definições de ‘@definfoenclose’ precisam não serem recursivas, direta ou indiretamente.
