2.8.2.1 @title, @subtitle e @author ¶

Uma maneira de se usar @titlepage é a de se usar os comandos @title, @subtitle e @author dentro do bloco do @titlepage. Com esse método, você não especifica nenhuma formatação real da página de título. Você especifica o texto que quiser e o Texinfo faz a formatação. A formatação usual consiste de riscos pretos sob as linhas do título e do autor e o texto do subtítulo definido alinhado para o lado direito da página.

Você consegue usar os comandos @title, @subtitle, e @author para criar uma página de título na qual o espaçamento vertical e horizontal seja feito para você automaticamente.

Escreva os comandos @title, @subtitle, ou @author no início de uma linha seguido pelo título, subtítulo, ou autor. O comando @author pode ser usado para uma citação em um bloco @quotation (veja-se @quotation: Citações de Bloco); exceto para isso, é um erro usar quaisquer desses comandos fora de @titlepage.

O comando @title normalmente produz uma linha na qual o título é configurado rente ao lado esquerdo da página em uma fonte mais larga que a normal. O título é sublinhado com uma linha preta. O título deve necessariamente ser dado em uma linha no arquivo fonte; ele será quebrado em múltiplas linhas de saída se necessário.

Para títulos longos, o comando @* pode ser usado para especificar as quebras de linha em títulos longos se as quebras automáticas não servirem. Tais quebras explícitas de linha geralmente são refletidas em todos os formatos de saída; se você quiser somente especificá-las para a saída impressa, use um condicional (veja-se Texto Condicionalmente Visível). Por exemplo: 

@title Este Título Longo@inlinefmt{tex,@*} É Quebrado no @TeX{}

O comando @subtitle normalmente configura subtítulos em uma fonte de tamanho normal rente ao lado direito da página.

O comando @author normalmente configura os nomes do(a) autor(a) ou autores(as) em uma fonte de tamanho médio rente ao lado esquerdo da página em uma linha próxima ao pé da página de título. Os nomes são seguidos por uma linha preta que é mais fina que a linha que normalmente sublinha o título.

Existem duas maneiras de se usar o comando @author: você consegue escrever o nome ou nomes na parte restante da linha que inicia com um comando @author: 

@author por Jane Smith e John Doe

ou você pode escrever os nomes um acima do outro, usando múltiplos comandos @author: 

@author Jane Smith
@author John Doe

Um modelo para esse método se parece com isto: 

@titlepage
@title nome-do-manual-quando-impresso
@subtitle subtítulo-se-algum
@subtitle segundo-subtítulo
@author autor
@page
...
@end titlepage
