7.8 @format: Exemplos Usando a Largura Total da Linha ¶

O comando @format é similar a @display, exceto que deixa o texto sem recuo. Como @display, ele não seleciona a fonte de largura fixa. Assim, 

@format
Este é um exemplo de texto escrito entre um comando @code{@@format}
e um comando @code{@@end format}.   Como você pode ver
a partir deste exemplo,
o comando @code{@@format} não preenche o texto.
@end format
