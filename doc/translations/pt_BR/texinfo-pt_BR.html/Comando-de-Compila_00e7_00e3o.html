D.7.2 Usando a Lista de Variáveis Locais ¶

Outra maneira de aplicar o comando de formatação do TeX a um arquivo do Texinfo é a de colocar esse comando em uma lista de variáveis locais no final do arquivo do Texinfo. Você consegue então especificar os comandos tex ou texi2dvi como um compile-command e fazer com que o Emacs execute-o digitando M-x compile. Isso cria um shell especial chamado o buffer do *compilation* no qual o Emacs executa o comando de compilação. Por exemplo, no final do arquivo gdb.texi, depois do @bye, você poderia colocar o seguinte: 

Variáveis locais:
compile-command: "texi2dvi gdb.texi"
Fim:

Essa técnica é mais frequentemente usada por programadores(as) que também compilam programas dessa maneira; veja-se Compilação em O Manual do GNU Emacs.
