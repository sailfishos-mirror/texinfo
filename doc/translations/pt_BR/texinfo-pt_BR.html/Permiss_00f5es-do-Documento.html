2.7 Permissões do Documento ¶

Este segmento descreve o documento e contém o aviso de direitos autorais e permissões de cópia. Isso é feito com o comando @copying. Um manual real inclui mais texto aqui, de acordo com a licença sob a qual ele é distribuído. 

@copying
Este é um exemplo curto de um arquivo completo do Texinfo, versão 1.0.

Copyright @copyright{} 2026 Free Software Foundation, Inc.
@end copying

O aviso de direitos autorais e as permissões de cópia para um documento precisam aparecer em vários lugares nos vários formatos da saída gerada do Texinfo. Portanto, o Texinfo fornece um comando (@copying) para declarar esse texto uma vez, e outro comando (@insertcopying) para inserir o texto nos pontos apropriados.

Para saída de texto simples, você precisa inserir explicitamente as informações de copirraite se quiser que elas apareçam, pois de outra forma não seriam exibidas. Por exemplo, você poderia ter o seguinte próximo ao início do arquivo Texinfo: 

@ifplaintext
@insertcopying
@end ifplaintext

Você poderia incluir outras informações semelhantes as de título para a saída de texto simples no mesmo lugar.

Se o documento for um manual de software, o software tipicamente está sob uma licença diferente—para GNU e muitos outros pacotes de software livre, o software geralmente é lançado sob a GNU GPL, e os manuais são lançados sob a GNU FDL. É útil declarar a licença do software do manual, mas fornecer o texto completo da licença do software não é necessariamente exigido.

  • @copying: Declarar Permissões de Cópia
  • @insertcopying: Incluir Texto de Permissões
