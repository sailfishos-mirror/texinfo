19.4 Preparando para TeX ¶

TeX precisa encontrar o arquivo texinfo.tex que o comando ‘\input texinfo’ na primeira linha lê. O arquivo texinfo.tex informa ao TeX como lidar com comandos @; Está incluído em todas as distribuições padrão do GNU. A versão mais recente lançada para uso geral está disponível a partir dos servidores GNU usuais e espelhos: 

https://ftp.gnu.org/gnu/texinfo/texinfo.tex
https://ftpmirror.gnu.org/texinfo/texinfo.tex

A versão mais recente de desenvolvimento está disponível a partir do repositório de fonte do Texinfo: 

https://git.savannah.gnu.org/cgit/texinfo.git/plain/doc/texinfo.tex

texinfo.tex essencialmente é um arquivo independente; portanto, se você precisar ou quiser tentar uma versão mais recente do que a que veio com o teu sistema, quase sempre basta baixá-la e colocá-la em algum lugar onde o TeX a encontre. Você consegue substituir qualquer texinfo.tex existente por uma versão mais recente (certamente salvando a original em caso de desastre).

Além disso, você deveria instalar o epsf.tex, se ele já não estiver instalado, originário em outra distribuição. Mais detalhes estão no final da descrição do comando @image (veja-se Inserindo Imagens).

Para usar aspas diferentes daquelas usadas em inglês, você precisará ter as fontes European Computer Modern (por exemplo, ecrm1000) e (para saída em PDF) as fontes CM-Super (veja-se Inserindo Aspas).

Para usar o comando @euro, você precisará das fontes ‘feym*’ (por exemplo, feymr10). Veja-se @euro (€): Símbolo da Moeda Euro.

Todos os arquivos acima deveriam estar instalados por padrão em uma instalação razoável do TeX.

Opcionalmente, você pode criar um arquivo texinfo.cnf para configuração do sítio. Ao processar um arquivo do Texinfo, TeX procura esse arquivo no caminho dele de pesquisa, que inclui o diretório atual e os diretórios padrão de instalação. Você pode usar esse arquivo para convenções locais. Por exemplo, se texinfo.cnf contiver a linha ‘@afourpaper’ (veja-se Imprimir em Papel A4), então todos os documentos do Texinfo serão processados com esse tamanho de página em vigor. Se você não tiver nada para colocar no texinfo.cnf, não precisará criá -lo.

Você pode configurar a variável de ambiente TEXINPUTS para permitir que o TeX encontre texinfo.cnf. (Isso também funciona para texinfo.tex e qualquer outro arquivo que o TeX possa ler). Por exemplo, se você estiver usando um shell compatível com shell Bourne (sh, bash, ksh, …), teu arquivo .profile poderia conter as linhas: 

TEXINPUTS=.:/home/eu/minhabiblioteca:
export TEXINPUTS

Essas configurações fariam com que o TeX primeiro procurasse por um arquivo \input no diretório atual, indicado pelo ‘.’, então um diretório minhabiblioteca de um(a) usuário(a) hipotético(a) ‘eu’ e finalmente nos diretórios do sistema. (Um ‘:’ à esquerda, à direita ou duplo indica a pesquisa nos diretórios do sistema nesse ponto).
