5.1 Diferentes Comandos de Referência Cruzada ¶

Existem três comandos de referência cruzada:

@xref

Usado para iniciar uma frase com uma referência cruzada do Info dizendo ‘*Observe nome: nó.’ ou com ‘Veja-se …’ em outros formatos de saída.

@ref

Usado dentro de, ou mais frequentemente, ao final de uma frase; produz uma referência cruzada do Info dizendo ‘*observação nome: nó.’, e apenas a referência em outros formatos de saída, sem o precedente ‘Veja-se’.

@pxref

Usado dentro de parênteses, ao final de uma frase, ou, do contrário, antes de pontuação, para fazer uma referência. A saída gerada dele inicia com um ‘*observação’ em letras minúsculas no Info, e com um ‘veja-se’ em outros formatos de saída. (‘p’ é para ‘parênteses’).

Adicionalmente, existem comandos para produzir referências para documentos fora do sistema Texinfo. O comando @cite é usado para fazer referências para livros e manuais. @url produz um URL, por exemplo uma referência para uma página na Rede Mundial de Computadores.
