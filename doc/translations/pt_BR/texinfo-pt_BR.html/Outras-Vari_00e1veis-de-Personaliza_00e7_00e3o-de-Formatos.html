20.4.7 Outras Variáveis de Personalização de Formatos ¶

Esta tabela fornece a personalização que se aplica somente para formatos específicos, para formatos sem seção separada de descrição de variáveis de personalização.

TXI_MARKUP_NO_SECTION_EXTENT ¶

Para XML. Não incluir comandos de seccionamento de nível inferior dentro de marcações de comando de seccionamento de nível superior. Padrão falso.

TEXI2DVI ¶

Nome do comando usado para produzir PostScript, PDF e DVI; padrão ‘texi2dvi’. Veja-se Saída Impressa do texi2any.

TEXTCONTENT_COMMENT ¶

Para saída de conteúdo de texto despojado (ou seja, quando TEXINFO_OUTPUT_FORMAT estiver configurada como textcontent). Se configurada, também gera comentários. Padrão falso.

TEXINFO_DTD_VERSION ¶

Para XML. Versão do DTD usado no preâmbulo da saída gerada XML. O padrão é configurada baseada em uma variável no configure.ac.
