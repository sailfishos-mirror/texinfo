3.9.2 Um Exemplo de Menu ¶

Um menu se parece com isto no Texinfo: 

@menu
* nome de entrada de menu: Nome de nó. Uma descrição curta.
* Nome de nó::                         Essa forma é preferida.
@end menu

Isso produz: 

* Menu:

* nome de entrada de menu: Nome de nó. Uma descrição curta.
* Nome de nó::                         Essa forma é preferida.

Aqui está um exemplo como você pode vê-lo em um arquivo Texinfo: 

@menu
Unidades Maiores de Texto

* Arquivos::                    Tudo acerca de manuseio de arquivos.
* Múltiplos: Buffers.           Múltiplos buffers; editando
                                 vários arquivos de uma vez.
@end menu

Isso produz: 

* Menu:
Unidades Maiores de Texto

* Arquivos::                   Tudo acerca do manuseio de arquivos.
* Múltiplos: Buffers.          Múltiplos buffers; editando
                                vários arquivos de uma vez.

Nesse exemplo, o menu tem duas entradas. ‘Arquivos’ tanto é um nome de entrada de menu quanto o nome do nó referenciado por esse nome. ‘Múltiplos’ é o nome de entrada de menu; ele se refere ao nó chamado ‘Buffers’. A linha ‘Unidades Maiores de Texto’ é um comentário; ela aparece no menu, porém não é uma entrada.

Como nenhum nome de arquivo está especificado nem com ‘Arquivos’ nem com ‘Buffers’, eles precisam ser os nomes de nós no mesmo arquivo Info (veja-se Referenciando Outros Arquivos do Info).
