7.7 @display: Exemplos Usando a Fonte de Texto ¶

O comando @display inicia outro tipo de ambiente, onde a fonte é deixada inalterada, não comutada para máquina de escrever como com @example. Cada linha da entrada ainda produz uma linha de saída, e a saída gerada ainda é recuada.
