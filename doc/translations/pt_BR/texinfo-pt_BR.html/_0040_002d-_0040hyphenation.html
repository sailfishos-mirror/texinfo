13.3 @- e @hyphenation: Hifenização em Saída Impressa ¶

Embora o algoritmo de hifenização do TeX geralmente seja muito bom, ele perde pontos de hifenização úteis de vez em quando. (Ou, muito mais raramente, insere uma hifenização incorreta). Então, para documentos com um vocabulário incomum ou ao fazer ajustes finos para uma edição impressa, você possivelmente deseje especificar pontos de hifenização explicitamente. Texinfo suporta dois comandos para isso:

@-

Insere um hífen discricionário, ou seja, um lugar onde uma palavra possa ser quebrada entre linhas com um hífen. Isso é especialmente útil quando você perceber que um hbox cheio demais é devido ao TeX carecer de uma hifenização (veja-se “hboxes” lotados). TeX não inserirá ele próprio quaisquer pontos de hifenização em uma palavra contendo @-.

@hyphenation{palavras hi-fe-na-das}

Fornece pontos de hifenização para certas palavras. Por exemplo: 

@hyphenation{man-u-scrito man-u-scritos}

Conforme mostrado, você coloca um ‘-’ em cada ponto de hifenização. TeX usa somente os pontos de hifenização especificados quando as palavras corresponderem exatamente, portanto forneça todas as variantes necessárias, tais como plurais.

Saídas não impressas não são hifenizadas, de forma que nenhum desses comandos tem qualquer efeito em outros formatos de saída.
