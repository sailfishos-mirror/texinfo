5.7 Referenciamento para um Manual como um Todo ¶

Normalmente, você sempre precisa nomear um nó em uma referência cruzada. Entretanto, não é incomum querer se referir a outro manual como um todo, em vez de uma seção em particular dentro dele. Nesse caso, dar-se algum nome de seção é uma distração desnecessária.

Assim, com referências cruzadas para outros manuais (veja-se @xref com Quatro e Cinco Argumentos), se o primeiro argumento for ou ‘Top’ (primeira letra maiúscula exatamente dessa maneira) ou inteiramente omitido, e o terceiro argumento for omitido, a saída impressa não incluirá nome de nó ou de seção. (A saída Info incluirá ‘Top’ se foi fornecido). Por exemplo, 

@xref{Top,,, make, O Manual do GNU Make}.

produz 

*Observe (make)Top::.

e

Veja-se O Manual do GNU Make.

Leitores Info irão para o nó Top do manual se o nó ‘Top’ estiver explicitamente especificado ou não.

Também é possível (e é prática histórica) referenciar um manual inteiro especificando-se o nó ‘Top’ e uma entrada apropriada para o terceiro argumento para o comando @xref. Usando esse dialeto, para fazer uma referência cruzada para O Manual do GNU Make, você poderia escrever: 

@xref{Top,, Visão Geral, make, O Manual do GNU Make}.

que produz: 

*Observe Visão Geral: (make)Top.

no Info e

Veja-se seção “Visão Geral” in O Manual do GNU Make.

em um manual impresso.

Nesse exemplo, ‘Top’ é o nome do primeiro nó e ‘Visão Geral’ é o nome da primeira seção do manual. Não existe convenção amplamente usada para nomear a primeira seção em um manual impresso; isso é apenas o que o manual do Make usa. Essa arbitrariedade do primeiro nome é a razão principal pela qual é preferível omitir-se o terceiro argumento em referências cruzadas de manual inteiro.
