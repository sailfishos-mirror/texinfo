11.8.3 @expansion{} (→): Indicando uma Expansão ¶

Quando uma expressão for uma chamada de macro, ela se expande para uma nova expressão. Você pode indicar o resultado da expansão com o comando @expansion{}.

O comando @expansion{} é exibido como ‘→’, ou uma seta longa com uma base plana ou (quando essa não estiver disponível) como a sequência ASCII ‘==>’.

Por exemplo, o seguinte 

@example lisp
(third '(a b c))
    @expansion{} (car (cdr (cdr '(a b c))))
    @result{} c
@end example

produz 

(third '(a b c))
    → (car (cdr (cdr '(a b c))))
    ⇒ c

que pode ser lido como:

(third '(a b c)) expande para (car (cdr (cdr '(a b c)))); o resultado da avaliação da expressão é c.

Frequentemente, como nesse caso, um exemplo aparenta melhor se os comandos @expansion{} e @result{} forem recuados.
