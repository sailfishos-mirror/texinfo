22.8.9 Lista de Variáveis de Personalização do HTML ¶

Esta tabela lista as variáveis de personalização que se aplicam para saída gerada HTML.

AFTER_BODY_OPEN

Texto adicionado no início de cada arquivo HTML; padrão desconfigurada.

AFTER_SHORT_TOC_LINES
AFTER_TOC_LINES

Texto gerado depois do sumaríssimo para AFTER_SHORT_TOC_LINES e depois do sumário para AFTER_TOC_LINES se configurada; caso contrário, uma sequência padrão de caracteres será usada. Ao tempo desta escrita, um elemento </div> estava fechado.

Em geral, você deveria configurar BEFORE_SHORT_TOC_LINES se AFTER_SHORT_TOC_LINES estiver configurada, e você deveria configurar BEFORE_TOC_LINES se AFTER_TOC_LINES estiver configurada.

BASEFILENAME_LENGTH

O comprimento máximo de um nome de arquivo base para referências cruzadas internas; padrão 245.

BEFORE_SHORT_TOC_LINES
BEFORE_TOC_LINES

Se configurada, o texto gerado antes do sumaríssimo para BEFORE_SHORT_TOC_LINES e antes do sumário para BEFORE_TOC_LINES, caso contrário, uma sequência padrão de caracteres será usada. Ao tempo desta escrita, um elemento <div ...> está aberto.

Em geral, você deveria configurar AFTER_SHORT_TOC_LINES se BEFORE_SHORT_TOC_LINES estiver configurada, e você deveria configurar AFTER_TOC_LINES se BEFORE_TOC_LINES estiver configurada.

BIG_RULE

Regra usada antes e depois do elemento superior e antes dos elementos especiais, mas não para rodapés e cabeçalhos; padrão

BODY_ELEMENT_ATTRIBUTES ¶

O texto de atributos do <body>. Por padrão, configura o atributo lang do HTML para o idioma do documento (veja-se @documentlanguage ll[_cc]: Configurar o Idioma do Documento).

CASE_INSENSITIVE_FILENAMES

Construa nomes de arquivos de saída como se o sistema de arquivos não diferenciasse maiúsculas de minúsculas (veja-se Dividindo HTML); padrão falso.

CHAPTER_HEADER_LEVEL

Nível de formatação de cabeçalho usado para comandos de seccionamento em nível de capítulo; padrão ‘2’.

CHECK_HTMLXREF

Verificar se os manuais que são o alvo de referências cruzadas externas (veja-se @xref com Quatro e Cinco Argumentos) estão presentes em htmlxref.cnf ou em htmlxref.d/*.cnf (veja-se Configuração de Referência Cruzada do HTML); padrão verdadeiro.

CONTENTS_OUTPUT_LOCATION

Se configurada como ‘after_top’, produzir o conteúdo no final da seção @top. Se configurada como ‘inline’, produzir o conteúdo onde o @contents e comandos @ semelhantes estão localizados. Se configurada como ‘separate_element’ produzir o conteúdo em elementos separados, ou no final do documento, se não dividido, ou em um arquivo separado. Se configurada como ‘after_title’ os índices serão produzidos depois do título; padrão ‘after_top’.

CONVERT_TO_LATEX_IN_MATH

Se configurada, tentar converter quaisquer comandos @ do Texinfo dentro de @math e de @displaymath para LaTeX, antes de converter o @math ou o @displaymath para HTML. Padrão undef. Se indefinida, configurar se HTML_MATH estiver configurada.

COPIABLE_LINKS

Se configurada, produzir linques copiáveis para os comandos de definição (veja-se Comandos de Definição), comandos de tabela (veja-se Fazendo Uma Tabela de Duas Colunas) onde uma entrada de índice estiver definida e cabeçalhos. Um linque aparece como um sinal ‘¶’ que aparece quando você passa o ponteiro do mouse sobre o texto do cabeçalho.

DATE_IN_HEADER

Colocar a data de geração do documento no cabeçalho; desligado por padrão.

DEF_TABLE

Se configurada, uma construção <table> para @deffn e comandos @ semelhantes será usada (parecendo mais com a saída gerada do TeX), em vez de listas de definição; padrão falso.

DEFAULT_RULE

Regra usada entre elementos, exceto antes e depois do elemento superior, e antes de elementos especiais, e para rodapés e cabeçalhos; padrão <hr>.

DO_ABOUT

Se configurada como 0, nunca fazer um elemento especial Sobre; se configurada como 1, sempre fazer um elemento especial Sobre; padrão 0.

EPUB_CREATE_CONTAINER_FILE

Se configurada como 0, não gera o arquivo de saída EPUB. O padrão é configurada como 1.

EPUB_KEEP_CONTAINER_FOLDER

Se configurada, mantém o diretório contendo os diretórios e arquivos necessários para EPUB. O arquivo de saída EPUB é um arquivamento ZIP desse diretório. O padrão é não definida. Configurada se não definida e TEST ou DEBUG estiver configurada. Veja-se Diretório do Contêiner e Arquivos da Saída Gerada.

EXTERNAL_CROSSREF_SPLIT

Para referências cruzadas para outros manuais, isso determina se o outro manual é considerado dividido ou monolítico. Por padrão, ela é configurada baseada no valor de SPLIT. Veja-se Referências Cruzadas do HTML e veja-se Configuração de Referência Cruzada do HTML.

EXTERNAL_DIR

Diretório base para manuais externos; padrão nenhum. É melhor usar o mecanismo geral de referência cruzada externa (veja-se Configuração de Referência Cruzada do HTML) do que essa variável.

EXTERNAL_CROSSREF_EXTENSION

Extensão de arquivo para referências cruzadas para outros manuais.

EXTRA_HEAD

Texto adicional aparecendo em <head>; padrão desconfigurada.

FOOTNOTE_END_HEADER_LEVEL

Nível de formatação de cabeçalho usado para o cabeçalho das notas de rodapé com o estilo de nota de rodapé ‘end’; padrão ‘4’. Veja-se Estilos de Notas de Rodapé.

FOOTNOTE_SEPARATE_HEADER_LEVEL

Nível de formatação de cabeçalho usado para o cabeçalho das notas de rodapé com o estilo de nota de rodapé ‘separate’; padrão ‘4’. Veja-se Estilos de Notas de Rodapé.

HEADER_IN_TABLE

Usar tabelas para formatação de cabeçalho em vez de um simples elemento <div>; padrão falso.

HIGHLIGHT_SYNTAX

Se configurada, blocos @example com informações de idioma como primeiro argumento serão realçados na saída gerada HTML. Também é possível especificar um padrão para o idioma com HIGHLIGHT_SYNTAX_DEFAULT_LANGUAGE. O realce de sintaxe exige um programa externo para gerar o HTML realçado. O valor de HIGHLIGHT_SYNTAX permite selecionar um programa específico. As possibilidades são source-highlight, highlight, pygments, com qualquer outro valor sendo concatenado para o idioma para gerar a linha de comando para o programa externo (veja-se Realçamento de Sintaxe de Exemplos de Códigos no HTML).

HIGHLIGHT_SYNTAX_DEFAULT_LANGUAGE

O idioma padrão usado para realce de sintaxe quando não existir informações de idioma.

HTML_MATH

Método a usar-se para renderizar @math (veja-se Personalização do HTML para Matemática). Isso pode ser desconfigurada, configurada como ‘mathjax’ (veja-se Variáveis de Personalização da MathJax), configurada como ‘l2h’, que usa latex2html (veja-se Variáveis de Personalização do latex2html), ou configurada como ‘t4h’, que usa tex4ht (veja-se Variáveis de Personalização do tex4ht). Por padrão, configurar-se HTML_MATH também configura CONVERT_TO_LATEX_IN_MATH.

HTML_ROOT_ELEMENT_ATTRIBUTES

Usar essa string para o elemento raiz <html> do documento HTML. Padrão indefinido.

HTMLXREF_FILE

Configurar o nome do arquivo usado para referências cruzadas para outros manuais. Se não definida, htmlxref.cnf será usado (veja-se Configuração de Referência Cruzada do HTML). Não definida no caso padrão. Se TEST estiver configurada, HTMLXREF_MODE estiver configurada para o padrão e HTMLXREF_FILE não estiver definida, informações acerca de referências cruzadas para outros manuais não serão usadas.

Se HTMLXREF_MODE estiver configurada como ‘file’, o nome do arquivo será usado diretamente como a fonte de informação; caso contrário, o nome do arquivo será pesquisado em diretórios e todos os arquivos encontrados serão usados (veja-se Configuração de Referência Cruzada do HTML). Arquivos htmlxref.d/*.cnf também serão usados nesse caso.

HTMLXREF_MODE

Como informações de referências cruzadas para outros manuais são determinadas. Se configurada como ‘none’, nenhuma informação será usada. Se configurada como ‘file’, as informações serão determinadas a partir de um caminho de arquivo, htmlxref.cnf no caso padrão, ou o valor de HTMLXREF_FILE. Se não definida (o padrão) ou configurada para qualquer outro valor, pesquisar pelo nome do arquivo HTMLXREF_FILE e pelo diretório htmlxref.d nos diretórios e usar todos os arquivos HTMLXREF_FILE e arquivos no diretório htmlxref.d com a extensão .cnf (veja-se Configuração de Referência Cruzada do HTML).

ICONS

Usar ícones para o painel de navegação; padrão falso.

IMAGE_LINK_PREFIX

Se configurada, o valor associado será preposto aos linques do arquivo de imagem; padrão desconfigurada.

INDENTED_BLOCK_COMMANDS_IN_TABLE

Se configurada, usar tabelas para recuo de comandos de blocos recuados; padrão falso.

INDEX_ENTRY_COLON

Símbolo usado entre a entrada de índice e o nó, ou seção, associado; padrão é uma sequência vazia de caracteres.

INFO_JS_DIR

(Experimental). Adicionar uma interface de navegação JavaScript ao manual. O valor da variável é o diretório para colocar o código para essa interface, de forma que você executaria o programa como por exemplo ‘texi2any --html -c INFO_JS_DIR=js manual.texi’ para colocar arquivos em um diretório ‘js’ sob a saída gerada. Isso fornece algumas das funcionalidades dos navegadores Info em um navegador da Web, como navegação por teclado e pesquisa de índice. Isso funciona somente com saída HTML não dividida.

A interface deveria fornecer uma funcionalidade alternativa aceitável se JavaScript ou recursos do navegador da Web não estiverem disponíveis. No entanto, por favor, seja cuidadoso(a) ao usar essa opção, caso você torne tua documentação mais difícil de acessar para alguns dos teus usuários(as).

IGNORE_REF_TO_TOP_NODE_UP

Ignorar referências para TOP_NODE_UP, o nó acima para o nó Top.

INLINE_CSS_STYLE

Colocar CSS diretamente nos elementos HTML, em vez de no início da saída gerada; padrão falso.

JS_WEBLABELS
JS_WEBLABELS_FILE

Especificar como usar uma página rótulos web de licença JavaScript para fornecer informações de licenciamento e código-fonte para qualquer JavaScript usado nos arquivos HTML para o manual. (Veja-se https://www.gnu.org/licenses/javascript-labels.html).

Com o valor ‘generate’ (o padrão), gerar uma página de rótulos em JS_WEBLABELS_FILE e lincar a ela nos arquivos de saída HTML. Fazer isso somente se realmente referenciar arquivos JavaScript (ou com HTML_MATH configurada como ‘mathjax’ ou ao usar a interface experimental de navegação JS quando INFO_JS_DIR estiver configurada). Com essa configuração, JS_WEBLABELS_FILE precisa ser um nome relativo de arquivo.

Com o valor ‘reference’, lincar para o arquivo de rótulos fornecido por JS_WEBLABELS_FILE na saída gerada e não gerar um arquivo de rótulos. Essa configuração é útil se você mantiver separadamente um arquivo de rótulos para um sítio maior que inclua teu manual.

Com ‘omit’, nem gerar nem lincar para um arquivo de rótulos.

MAX_HEADER_LEVEL

Nível máximo de formatação de cabeçalho usado (números mais altos de níveis de formatação de cabeçalho correspondem a níveis mais baixos de seccionamento); padrão ‘4’.

MENU_ENTRY_COLON

Símbolo usado entre a entrada do menu e a descrição; padrão ‘:’.

MENU_SYMBOL

Símbolo usado em frente das entradas de menu quando nomes de nós forem usados para formatação de entradas de menu; o padrão é indefinido e configurada como &bull; se USE_NUMERIC_ENTITY não estiver configurada, e como &#8217; se configurada.

MONOLITHIC

Produzir somente um arquivo incluindo o sumário. Configurada por padrão, mas relevante somente quando a saída gerada não for dividida.

NO_CSS

Não usar CSS; padrão falso. Veja-se CSS do HTML.

NO_CUSTOM_HTML_ATTRIBUTE

Não produzir HTML com atributos personalizados em elementos; padrão falso.

NO_NUMBER_FOOTNOTE_SYMBOL

Símbolo usado para notas de rodapé se NUMBER_FOOTNOTES for falso. O padrão é *.

NODE_NAME_IN_INDEX

Se verdadeiro, usar nomes de nós nas entradas de índice; caso contrário, preferir nomes de seções. Se indefinida, usar valor de USE_NODES no HTML. O padrão é indefinida.

NODE_NAME_IN_MENU

Se configurada, usar nomes de nós nas entradas de menu; caso contrário, preferir nomes de seção; padrão verdadeiro.

PRE_BODY_CLOSE

Se configurada, o texto fornecido aparecerá no rodapé de cada arquivo HTML; padrão desconfigurada.

PROGRAM_NAME_IN_ABOUT

Usada quando um elemento Sobre for gerado. Se configurada, produzir o nome do programa e diversas informações relacionadas no elemento especial Sobre; padrão falso.

PROGRAM_NAME_IN_FOOTER

Se configurada, gerar o nome do programa e diversas informações relacionadas nos rodapés das páginas; padrão falso.

SECTION_NAME_IN_TITLE

Se configurada, quando a saída gerada for dividida, usar o argumento do comando de estruturação do capítulo (por exemplo, @chapter ou @section) no <title> em vez do argumento para @node.

SHORT_TOC_LINK_TO_TOC

Se configurada, as referências cruzadas no sumário curto se lincam às entradas correspondentes do Sumário, se um Sumário for gerado; padrão verdadeiro.

SHOW_BUILTIN_CSS_RULES

Produzir as regras CSS padrão integradas na saída padrão e sair.

SHOW_TITLE

Se configurada, gerar o título no início do documento; padrão ‘undef’. Se configurada como ‘undef’, configurar-se NO_TOP_NODE_OUTPUT também configura SHOW_TITLE para HTML.

TEXI2HTML ¶

Gerar HTML e tentar ser o mais compatível possível com texi2html; padrão falso.

TOC_LINKS

Se configurada, linques de títulos para entradas de índice serão criados; padrão falso.

TOP_FILE

Esse nome de arquivo pode ser usado para o arquivo de nível superior. A extensão é configurada apropriadamente, se necessário. Isso é usado para substituir o padrão e, em geral, só é levado em consideração quando a saída gerada for dividida e para HTML.

TOP_NODE_FILE_TARGET

Nome do arquivo usado para o nó Top em referências cruzadas; o padrão é index.html.

TOP_NODE_UP_URL

Uma URL usada para nó Topo que Acima referencia; o padrão é undef; nesse caso, nenhuma referência Acima de nó Topo é gerada. Para substituir o nome do ponteiro Acima no caso de TOP_NODE_UP_URL estiver configurada e para outros formatos, veja-se TOP_NODE_UP em Variáveis de Personalização para Múltiplos Formatos. Veja-se Personalização de Nomes de Arquivo e de Linques para HTML. Para mais acerca dos ponteiros do nó Topo, veja-se O Primeiro Nó.

USE_ACCESSKEY ¶

Usar accesskey em referências cruzadas; padrão undef. Se undef, configurar se a saída gerada for dividida.

USE_ISO

Usar entidades para caracteres de aspas simples duplicadas (veja-se Inserindo Aspas) e ‘---’ e ‘--’ (veja-se Convenções Sintáticas Gerais); padrão verdadeiro.

USE_LINKS ¶

Gerar elementos <link> na saída <head> do HTML; padrão verdadeiro.

USE_NODE_DIRECTIONS

Se verdadeiro, usar nós para determinar para onde lincar próximo, acima e anterior nos cabeçalhos dos nós. Se falso, usar seções. Se indefinida, usar valor de USE_NODES. O padrão é indefinida. Observe que essa configuração não determina a sequência de caracteres do linque, somente para onde os linques apontam; veja-se xrefautomaticsectiontitle para a personalização da sequência de caracteres do linque. Se nós e seções estiverem sistematicamente associados, essa personalização não terá efeito prático.

USE_TITLEPAGE_FOR_TITLE

Usar o @titlepage completo (ou saída proveniente de @maketitle) como o título, não uma simples sequência de caracteres de título; padrão verdadeiro. Relevante somente se SHOW_TITLE estiver configurada.

USE_XML_SYNTAX

Usar sintaxe compatível com XML/XHTML

VERTICAL_HEAD_NAVIGATION

Se configurada, um painel vertical de navegação é usado; padrão falso.

WORDS_IN_PAGE ¶

Quando a saída é dividida por nós, especifica o comprimento mínimo aproximado da página em que um painel de navegação é colocado na parte inferior de uma página. Para evitar que os botões de navegação fiquem na parte inferior de uma página, configure isso para um número suficientemente grande. O padrão é 200.

XREF_USE_FLOAT_LABEL

Se configurada, para o nome flutuante em referências cruzadas, usar o rótulo flutuante em vez do tipo seguido pelo número flutuante (veja-se @float [tipo][,rótulo]: Material Flutuante). O padrão é desligado.

XREF_USE_NODE_NAME_ARG

Relevante somente para comandos de referência cruzada sem nome de referência cruzada (segundo argumento). Se configurada como 1, usar o argumento (primeiro) do nome do nó em comandos @ de referência cruzada para o texto exibido como o hiperlinque. Se configurada como 0, usar o nome do nó se USE_NODES estiver configurada; caso contrário, o nome da seção. Se configurada como ‘undef’, usar o primeiro argumento em ambientes pré-formatados; caso contrário, usar o nome do nó ou o nome da seção, dependendo de USE_NODES. O padrão é ‘undef’.
