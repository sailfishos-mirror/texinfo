22.7 Referências Cruzadas do HTML ¶

Referências cruzadas entre manuais do Texinfo em formato HTML tornam-se linques <a> padrão do HTML. Esta seção descreve o algoritmo usado, de modo que o Texinfo consiga cooperar com outros programas, como texi2html, escrevendo arquivos HTML mutuamente compatíveis.

Este algoritmo pode ou não ser usado para linques dentro de saída HTML para um arquivo do Texinfo. Como não surgem problemas de compatibilidade em tais casos, nós não precisamos especificar isso.

Nós tentamos suportar referências para tais manuais “externos” em ambas as formas, monolítica e dividida. Um manual monolítico (mono) está inteiramente contido em um arquivo, e um manual dividido tem um arquivo para cada nó. (Veja-se Dividindo HTML).

O algoritmo foi desenvolvido principalmente por Patrice Dumas em 2003–04.
