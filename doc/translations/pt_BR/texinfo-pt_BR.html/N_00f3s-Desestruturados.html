4.13 Nós Desestruturados ¶

Todos os exemplos de nós neste capítulo até agora usaram uma linha @node seguida por um comando de estruturação (como @chapter).

No entanto, você também pode criar nós sem usar um comando de estruturação. Você pode achar isso útil se não quiser que teu manual (ou partes de um manual) tenha uma estrutura hierárquica, com capítulos superiores às seções, seções superiores às subseções e assim por diante.

Para fazer isso, siga a linha @node com um dos comandos de cabeçalho. Por exemplo: 

@node Tópico
@heading Tudo acerca do Tópico
...

O argumento para o comando de cabeçalho será impresso normalmente. Quando o sinalizador xrefautomaticsectiontitle estiver ativado (veja-se xrefautomaticsectiontitle), esse argumento também será usado como o texto para quaisquer referências cruzadas para o nó.

Esses nós não são parte de uma estrutura hierárquica de documento. Isso significa que eles não estão listados em nenhum sumário e os ponteiros automáticos de direção do nó (‘Próximo’, ‘Anterior’ ou ‘Acima’; veja-se Escrevendo uma Linha de @node) não lincam para ou a partir desses nós.

Se desejar criar um nó não estruturado sem imprimir um cabeçalho no início, você pode usar o comando @xrefname no lugar do comando de cabeçalho. Por exemplo: 

@node Tópico
@xrefname Tudo acerca do Tópico
...

O comando @xrefname fornece o texto para referências cruzadas para o nó quando o sinalizador xrefautomaticsectiontitle está ativado, de modo que ‘@xref{Tópico}’ produziria uma saída como “Veja-se ‘Tudo acerca do Tópico’”.
