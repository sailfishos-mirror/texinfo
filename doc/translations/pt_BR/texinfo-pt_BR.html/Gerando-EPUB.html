22.5 Gerando EPUB ¶

EPUB é um formato projetado para leitura de livros eletrônicos em dispositivos portáteis. texi2any gerava EPUB 3.3 em 2024. Um arquivo EPUB é um contêiner de arquivamento ZIP, contendo arquivos informativos, bem como o manual renderizado em HTML.

A geração do arquivo EPUB depende do módulo Perl Archive::Zip estar instalado. Essa dependência é verificada em tempo de execução. Por padrão, tentar gerar EPUB sem essa dependência levanta um erro. Porém, se o arquivo de saída EPUB não for gerado, com a variável de personalização EPUB_CREATE_CONTAINER_FILE configurada como 0, não será um erro se Archive::Zip não estiver instalado.

Os testes do texi2any relacionados à geração de EPUB não exigem a instalação do Archive::Zip, pois eles configuram EPUB_CREATE_CONTAINER_FILE como 0 e mantêm o diretório contendo os arquivos e diretórios necessários para o arquivo EPUB configurando a variável de personalização EPUB_KEEP_CONTAINER_FOLDER como 1.
