12 Formatando Expressões Matemáticas ¶

Você consegue escrever uma expressão matemática, equação ou fórmula usando o comando @math. Escreva a notação matemática do TeX entre chaves, assim: 

@math{\partial_\alpha \partial^\alpha A^\beta = \mu_0 J^\beta}

@math é formatado em linha quando usado dentro de um parágrafo, como \partial_\alpha \partial^\alpha A^\beta = \mu_0 J^\beta nesse exemplo.

Por padrão, o comando @math não tem nenhum efeito especial na saída Info, meramente gerando o conteúdo literalmente. Você pode usar a variável experimental INFO_MATH_IMAGES para produzir imagens; veja-se Variáveis de Personalização do Info e de Texto Simples.

Para saída impressa, @math comuta para o “modo matemático” do TeX. Nesse contexto, ‘\’ precisa ser usada em vez de ‘@’ para sequências de controle matemático simples do TeX para símbolos, funções e assim por diante.

Por padrão, a saída HTML é apenas enfatizada. texi2any fornece três opções para exibir expressões matemáticas formatadas corretamente para HTML. Você consegue selecioná-las com a variável HTML_MATH (veja-se Personalização do HTML para Matemática). Com HTML_MATH configurada para ‘l2h’, texi2any tenta usar o programa latex2html para produzir arquivos de imagem para material matemático. Com a configuração ‘t4h’, texi2any tenta usar o programa tex4ht. Com a configuração ‘mathjax’, texi2any insere referências nos arquivos da saída gerada para conjuntos de comandos sequenciados MathJax para formatar o material. A opção MathJax exige que JavaScript esteja habilitado no navegador para funcionar. Veja-se também Variáveis de Personalização da MathJax, Variáveis de Personalização do latex2html e Variáveis de Personalização do tex4ht.

Para equações exibidas, você pode o comando @displaymath. Exemplo: 

@displaymath
f(x) = {1\over\sigma\sqrt{2\pi}}
e^{-{1\over2}\left({x-\mu\over\sigma}\right)^2}
@end displaymath

o que produz: 

f(x) = {1\over\sigma\sqrt{2\pi}}
e^{-{1\over2}\left({x-\mu\over\sigma}\right)^2}

Em geral, o conteúdo de @math ou de @displaymath deveria ser somente TeX simples, sem comandos Texinfo intercalados. Se usar quaisquer comandos do Texinfo, então você deveria marcá-los com ‘@’, como de costume, em vez de ‘\’ (por exemplo, ‘@var’ em vez de ‘\var’), mas nós não garantimos quais comandos do Texinfo funcionarão.

Embora @sub e @sup possam funcionar dentro do modo matemático em alguns contextos, é melhor usar os caracteres ‘_’ e ‘^’ do TeX para denotar subscritos e sobrescritos dentro de expressões matemáticas.

O código específico do LaTeX só funcionará quando o formato de saída for LaTeX e com as opções da HTML_MATH (embora tex4ht precise que T4H_MATH_CONVERSION seja configurada para ‘latex’; veja-se Variáveis de Personalização do tex4ht).

Devido ao conflito com o comando @sup do Texinfo, você pode acessar o comando \sup do TeX simples como \mathopsup, na improvável ocorrência de querer fazer isso (mas somente ao processar com TeX, não ao gerar LaTeX nem com qualquer das opções da HTML_MATH).
