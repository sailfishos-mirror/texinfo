11.8.2 @result{} (⇒): Resultado de uma Expressão ¶

Use o comando @result{} para indicar o resultado da avaliação de uma expressão.

O comando @result{} é exibido como ‘⇒’, ou uma seta com haste dupla ou (quando essa não estiver disponível) como a sequência ASCII ‘=>’.

Assim, o seguinte, 

(cdr '(1 2 3))
    ⇒ (2 3)

pode ser lido como “(cdr '(1 2 3)) avalia para (2 3)”.
