2.5 Cabeçalho do Arquivo do Texinfo ¶

Arquivos do Texinfo iniciam com a linha: 

\input texinfo

A linha ‘\input texinfo’ diz ao TeX para usar o arquivo texinfo.tex, que diz ao TeX como traduzir os comandos @ do Texinfo para comandos de tipografia do TeX. (Observe o uso da barra invertida, ‘\’; isso é correto para o TeX).

Faz sentido incluir qualquer comando que afete a formatação do documento como um todo no cabeçalho. A linha @settitle geralmente está presente no começo do cabeçalho: 

@settitle Manual do Sample 1.0

A linha @settitle especifica um título para os cabeçalhos de página (ou rodapés) do manual impresso, e o título padrão e a descrição do documento para ‘<head>’ em HTML. @synindex (veja-se @synindex: Combinando Índices), por exemplo, é outro comando frequentemente incluído no cabeçalho.

O início do arquivo do Texinfo até o primeiro conteúdo que é gerado como parte do corpo principal do documento é o preâmbulo. Ele inclui o cabeçalho, Permissões do Documento e a especificação Páginas de Título e de Direitos Autorais. É importante para o formato de saída do LaTeX, pois o fim do preâmbulo é onde a linha \begin{document} é gerada. Em outros formatos de saída, ele pode ser usado para determinar como alguma saída especial é formatada, por exemplo, a saída @copying: Declarar Permissões de Cópia como um comentário no início dos arquivos de saída ou o idioma usado nos cabeçalhos de arquivo.
