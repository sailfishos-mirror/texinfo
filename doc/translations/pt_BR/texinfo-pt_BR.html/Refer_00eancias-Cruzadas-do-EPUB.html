22.5.2 Referências Cruzadas do EPUB ¶

O formato EPUB não suporta referências a partir de um arquivo EPUB para outro arquivo EPUB. Portanto quaisquer referências para manuais “externos” do Texinfo deveriam ser resolvidas para uma URL externa. texi2any produz esses linques com configuração de referência cruzada do HTML (veja-se Configuração de Referência Cruzada do HTML). Como os linques no EPUB resultante estarão incorretos se nenhuma informação for encontrada para as referências cruzadas, texi2any emitirá um aviso por padrão para ausência de informações de referências cruzadas. Se esses avisos forem indesejados, configure CHECK_HTMLXREF como 0.
