5.14.3 @url Formato de Saída PDF ¶

Se o propósito final de um PDF for somente para ser visto online, talvez similar a HTML de alguma maneira incipiente, você pode não querer que as URLs sejam incluídas no texto visível (exatamente como as URLs não são visíveis para leitores(as) de páginas da web). Texinfo fornece uma opção específica de PDF para isso, a qual precisa ser usada dentro de @tex: 

@tex
\global\urefurlonlylinktrue
@end tex

O resultado é que @url{https://www.gnu.org, GNU} tem a saída gerada visível de apenas ‘GNU’, com um alvo de linque de https://www.gnu.org. Normalmente, a saída gerada visível incluiria tanto o rótulo quanto a URL: ‘GNU (https://www.gnu.org)’.

Essa opção somente tem efeito quando a saída PDF for produzida com o programa pdfTeX, não com outras maneiras de se obter de Texinfo para PDF (por exemplo, TeX para DVI para PDF). Consequentemente, está certo se especificar essa opção incondicionalmente dentro de @tex, conforme mostrado acima. Ela é ignorada quando DVI está sendo produzido.
