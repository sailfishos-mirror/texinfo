22.3 CSS do HTML ¶

Folhas de Estilo em Cascata (CSS) é um padrão da Internet para influenciar a exibição de documentos HTML veja-se http://www.w3.org/Style/CSS/.

Por padrão, algum código CSS é incluído para implementar melhor a aparência de alguns ambientes do Texinfo. Por exemplo: 

pre.display { font-family:inherit }

O acima diz ao navegador da web para usar a mesma fonte do documento principal dentro de elementos ‘<pre>’ usados para ambientes @display. Por padrão, o comando ‘<pre>’ do HTML usa uma fonte monoespaçada.

Por favor, veja-se a referência acima para uma explicação completa do CSS.

Você consegue influenciar o CSS na saída HTML com duas opções do texi2any: --css-include=arquivo e --css-ref=url.

A opção --css-ref=url adiciona para cada arquivo de saída HTML uma etiqueta ‘<link>’ referenciando um CSS no url fornecido. Isso permite usar-se folhas de estilo externas.

A opção --css-include=arquivo inclui o conteúdo de arquivo na saída HTML, como você esperaria. No entanto, os detalhes são um tanto complicados, conforme descrito a seguir, para fornecer flexibilidade máxima.

A primeira linha do arquivo CSS possivelmente seja uma diretiva ‘@charset’. Se presente, essa diretiva será usada para determinar a codificação do arquivo CSS. A linha não será copiada na saída gerada.

O arquivo CSS possivelmente comece com as assim chamadas diretivas ‘@import’, as quais lincam especificações externas CSS para navegadores usarem ao interpretarem o documento. Novamente, uma descrição completa está além do nosso escopo aqui, mas nós descreveremos como elas funcionam sintaticamente, de modo que consigamos explicar como são manuseadas.

Pode existir mais que uma ‘@import’, mas elas tem de vir primeiro no arquivo, somente com espaços em branco e comentários intercalados, sem definições normais. Comentários em arquivos CSS são delimitados por ‘/* ... */’, como na C. Uma diretiva ‘@import’ precisa estar em uma destas duas formas: 

@import url(http://exemplo.org/foo.css);
@import "http://exemplo.net/bar.css";

Os caracteres cruciais são o ‘@’ no início e o ponto e vírgula terminando a diretiva. Ao ler o arquivo CSS, quaisquer das tais diretivas ‘@’ simplesmente serão copiadas na saída gerada, conforme segue:

  • Se arquivo contiver somente declarações normais CSS, ele será incluído depois do CSS padrão, portanto substituindo-o.
  • Se arquivo iniciar com especificações ‘@import’ (veja-se abaixo), então as ‘import’ serão incluídas primeiro (elas têm de vir primeiro, de acordo com o padrão), e então o CSS padrão será incluído. Se precisar substituir o CSS padrão a partir de uma ‘@import’, você consegue fazer isso com o constructo ‘! important’ do CSS, como em: 
    pre.example { font-size: inherit ! important }
  • Se arquivo contiver ambos, ‘@import’ e CSS inline especificações, as ‘@import’ serão incluídas primeiro, então CSS padrão e, por último, o CSS inline proveniente de arquivo.
  • Qualquer outra diretiva @ diferente de ‘@import’ e de ‘@charset’ será tratada como uma declaração CSS, significando que o CSS padrão será incluído e a seguir o restante do arquivo será preposto.

Se o arquivo CSS estiver malformado ou incorreto, a saída gerada será inespecificada. O significado do arquivo CSS não será interpretado de maneira alguma; os caracteres especiais ‘@’ e ‘;’ serão procurados para que o texto seja copiado cegamente na saída gerada. Comentários no arquivo CSS podem ou não serem incluídos na saída gerada.

Por padrão, classes são adicionadas aos elementos HTML e regras CSS para essas classes são geradas no início de cada arquivo HTML. Configure a variável de personalização NO_CSS para evitar classes sendo adicionadas e CSS sendo usado. Configure INLINE_CSS_STYLE para ter código CSS colocado em elementos HTML no atributo style em vez de no início da saída gerada.

Como texi2any insere somente código CSS necessário para o HTML realmente gerado, a lista completa do código CSS potencialmente inserido não é visível no documento da saída gerada. Para obter a lista completa de regras CSS, chame texi2any com a variável de personalização SHOW_BUILTIN_CSS_RULES configurada para gerar, na saída padrão, as regras CSS padrão integradas e sair, como: 

texi2any -c SHOW_BUILTIN_CSS_RULES=1
