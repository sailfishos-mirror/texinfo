21.1.2 Listando um Novo Arquivo Info ¶

Para adicionar um novo arquivo Info ao teu sistema, você precisa escrever uma entrada de menu para adicionar ao menu no arquivo dir no diretório info. Por exemplo, se estivesse adicionando documentação para o GDB, você escreveria a seguinte nova entrada: 

* GDB: (gdb).           O depurador C de nível de fonte.

A primeira parte da entrada do menu é o nome da entrada do menu, seguido por dois pontos. A segunda parte é o nome do arquivo Info, entre parênteses, seguido de um ponto final. A terceira parte é a descrição.

O nome de um arquivo Info frequentemente tem uma extensão .info. Assim, o arquivo Info para GDB pode ser chamado ou de gdb ou de gdb.info. Os programas leitores do Info tentam automaticamente o nome do arquivo com e sem .info10; então é melhor evitar confusão e não escrever ‘.info’ explicitamente na entrada do menu. Por exemplo, a entrada do menu GDB deveria usar somente ‘gdb’ para o nome do arquivo, não ‘gdb.info’.

Notas de Rodapé

(10)

Em sistemas MS-DOS/MS-Windows, o Info também tentará a extensão .inf.
