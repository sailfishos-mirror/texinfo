7.9 @exdent: Desfazendo o Recuo de Uma Linha ¶

O comando @exdent remove qualquer recuo que uma linha possa ter. O comando é escrito no início de uma linha e se aplica somente ao texto que segue o comando que esteja na mesma linha. Não use chaves em volta do texto. O texto em uma linha @exdent também é impresso na fonte romana onde o formato da saída gerada permitir isso.

@exdent normalmente é usado dentro de exemplos. Assim, 

@example
Esta linha segue um comando @@example.
@exdent Esta linha está desrecuada.
Esta linha segue a linha desrecuada.
O @@end example vem na próxima linha.
@end example

produz 

Esta linha segue um comando @example.

Esta linha está desrecuada.

Esta linha segue a linha desrecuada.
O @end example vem na próxima linha.

Na prática, o comando @exdent raramente é usado. Geralmente, você desrecua texto finalizando o exemplo e retornando a página para a largura normal dela.

@exdent não tem efeito em todos os formatos de saída.
