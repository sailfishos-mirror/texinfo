6.1.8 @env{variável-ambiente} ¶

Use o comando @env para indicar variáveis de ambiente, conforme usadas por muitos sistemas operacionais, incluindo GNU. Não a use para variáveis metassintáticas; use @var para essas (veja-se a seção anterior).

@env é equivalente a @code nos efeitos dele. Por exemplo: 

A variável de ambiente @env{PATH} ...

produz

A variável de ambiente PATH …
