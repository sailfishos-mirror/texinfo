19 Formatando e Imprimindo com TeX ¶

Executar o comando texi2dvi ou texi2pdf é a maneira mais simples de criar uma saída imprimível. Esses comandos são instalados como parte do pacote do Texinfo.

Em mais detalhes, tipografar e imprimir um arquivo do Texinfo é um processo de várias etapas no qual você usa o programa TeX para criar um arquivo para impressão (chamado de arquivo DVI ou PDF) e então imprime o arquivo. Opcionalmente, você também pode criar índices usando o comando texindex depois da primeira execução do TeX; e então você precisa executar o TeX novamente. texi2dvi se encarrega de tudo isso, executando TeX e texindex conforme necessário (veja-se Formatar com texi2dvi).

Ao usar os comandos do shell, você pode trabalhar diretamente no shell do sistema operacional ou dentro de um shell dentro do GNU Emacs (ou algum outro ambiente computacional). Você pode fornecer comandos de formatação e impressão a partir de um shell dentro do GNU Emacs, assim como qualquer outro comando de shell. Para criar um shell dentro do Emacs, digite M-x shell (veja-se Shell em O Manual do GNU Emacs). Se estiver usando o GNU Emacs, você também pode usar comandos fornecidos pelo modo Texinfo em vez de comandos de shell. Veja-se Formatando e Imprimindo com o Emacs.

Para especificar detalhes da saída impressa, como tamanho do papel, veja-se Comandos Globais de Documento.
