5.2 Partes de Uma Referência Cruzada ¶

Um comando de referência cruzada exige somente um argumento, que é o nome do nó para o qual ele se refere. Um comando de referência cruzada pode conter até quatro argumentos adicionais. O modelo para uma referência cruzada completa de cinco argumentos se parece com isto: 

@xref{nome-nó, rótulo-online, rótulo-impresso,
nome-manual, título-manual-impresso}

Os cinco possíveis argumentos para uma referência cruzada são:

  1. O nome do nó ou da âncora. Isso é o local para onde a referência cruzada leva você. Em um documento impresso, o local do nó fornece a referência de página somente para referências dentro do mesmo documento. Use @node para definir o nó (veja-se Escrevendo uma Linha de @node), @anchor (veja-se @anchor: Definindo Alvos Arbitrários de Referências Cruzadas), ou @float (veja-se @float [tipo][,rótulo]: Material Flutuante) com um rótulo. Esse argumento é exigido (exceto para referência para manuais inteiros).

    Escreva um nome de nó em uma referência cruzada exatamente da mesma maneira que na linha @node, incluindo a mesma capitalização; caso contrário, os processadores possivelmente não encontrem a referência.

  2. Um rótulo para saída online. Geralmente ele é omitido; então a descrição do tópico (terceiro argumento) será usada se for especificada; Se isso também foi omitido, o nome do nó será usado.
  3. Um rótulo para saída impressa. Frequentemente, esse é o título ou tópico da seção. Isso é usado como o nome da referência no manual impresso. Se omitido, o nome do nó será usado.
  4. O nome do manual para o qual a referência se refere, se estiver fora do manual atual, em um arquivo Texinfo diferente.
  5. O título do manual impresso para o qual a referência se refere, a partir de um arquivo Texinfo diferente.

O espaço em branco antes e depois das vírgulas separando esses argumentos é ignorado. Para incluir uma vírgula em um dos argumentos, use @comma{} (veja-se Inserindo ‘,’ com @comma{}).

Referências cruzadas com um, dois, três, quatro e cinco argumentos estão descritas separadamente em seções seguintes.

Quando do processamento com TeX, uma vírgula automaticamente é inserida depois do número da página para referências cruzadas para dentro do mesmo manual, a menos que a chave de fechamento do argumento não seja seguida por espaços em branco (como uma vírgula ou um ponto). Isso te dá a escolha de quando ter uma vírgula lá em outros formatos de saída. Por exemplo, 

@xref{Outra Seção} para mais informações

com TeX produz ‘Veja-se Outra Seção, página ppp, para mais informações’, e na saída Info produz ‘*Observe Outra Seção:: para mais informações’.

Se uma vírgula indesejada for adicionada, siga o argumento com um comando como ‘@:’. Por exemplo, ‘@xref{Furacões}@: --- para os detalhes’ produz

Veja-se Furacões, página ppp — para os detalhes

em vez de ‘Veja-se Furacões, página ppp, — para os detalhes’.

texi2any alerta e protege nomes quando o texto de uma referência cruzada (e nomes de nó e itens de menu) contiver uma construção problemática que poderia interferir com a análise dele no Info. Veja-se Restrições de Nomes de Nó do Info.
