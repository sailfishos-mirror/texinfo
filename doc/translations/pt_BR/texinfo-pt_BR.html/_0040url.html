5.14 @url, @uref{url[, texto][, substituição]} ¶

@url produz uma referência para um Localizador Uniforme de Recursos (URL). Ele recebe um argumento obrigatório, a URL, e dois argumentos opcionais que controlam o texto que é exibido. Em saída HTML e PDF, @url produz um linque que você consegue seguir. (Para meramente indicar uma URL sem criar um linque que as pessoas possam seguir, use @indicateurl, veja-se @indicateurl{localizador-uniforme-de-recurso}).

@uref é um sinônimo para @url. (Originalmente, @url tinha o significado de @indicateurl e @uref era obrigado a produzir um linque funcional, porém, na prática, @url quase sempre era mal usado. Então, nós mudamos o significado).

O segundo argumento, se especificado, é o texto a exibir (o padrão é a URL em si); em formatos de saída diferentes de HTML, a URL é gerada em adição a esse texto.

O terceiro argumento, se especificado, é o texto a exibir, mas nesse caso a URL não é gerada em nenhum formato. Isso é útil quando o texto já é suficientemente referencial, como em uma página de manual. Além disso, se o terceiro argumento for fornecido, o segundo argumento será ignorado.
