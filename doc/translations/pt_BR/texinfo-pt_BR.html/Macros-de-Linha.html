17.5 Macros de Linha ¶

Você também pode definir uma macro usando o comando ‘@linemacro’. A sintaxe para definições de macros de linha é semelhante àquela para @macro.

No entanto, a sintaxe para usar uma macro definida dessa maneira é diferente. A chamada de macro usa o restante da linha, com argumentos separados por espaços. O recurso de macro de linha é destinado principalmente para permitir que você defina comandos que operem semelhantemente aos comandos internos para fornecer definições (veja-se Comandos de Definição).

Por exemplo: 

@linemacro defbuiltin {nome, argumentos}
@defline {Builtin} \nome\ \argumentos\
@end linemacro

A macro acima pode ser usada como 

@defblock
@defbuiltin foo (bar)
Explicação
@end defblock

Isso produz o seguinte resultado:

Builtin: foo (bar) Explicação

Aqui, o primeiro argumento é ‘foo’ e é substituído onde ‘\nome\’ aparecer no corpo da macro. Da mesma forma, ‘(bar)’ é substituído por ‘\argumentos\’.

Você consegue incluir espaços em um argumento de macro envolvendo o argumento entre chaves. Qualquer par de chaves circundando um argumento é removido antes da substituição. Quaisquer argumentos vazios (incluindo o último) precisam ser fornecidos como ‘{}’. Além disso, espaços não iniciais podem aparecer no argumento final na lista de argumentos sem chaves envolventes (como no exemplo abaixo).

Se uma linha de argumento para uma macro de linha terminar com um caractere ‘@’, então esse caractere, juntamente com a nova linha subsequente, será incluído em um argumento de macro, e a linha seguinte no arquivo de entrada também será usada para obter os argumentos para a macro. Observe que qualquer substituição da sequência ‘@<nova linha>’ precisa estar em um contexto válido, como uma linha de definição (veja-se Linhas de Continuação de Comando de Definição).

Outro exemplo: 

@linemacro deffunc {tipo, nome, argumentos}
@findex \nome\
@deftypeline {Func} {\tipo\} \nome\ \argumentos\
@end linemacro

@defblock
@deffunc {long int} F (int @var{um}, int @var{dois}, @
int @var{três}, int @var{quatro}, int @var{cinco})
Explicação
@end defblock

Observe como chaves são necessárias em torno de ‘\tipo\’ no corpo da macro caso o argumento de tipo contenha um espaço. Esse exemplo produz a saída abaixo e insere uma entrada de índice para F.

Func: long int F (int um, int dois,  int três, int

quatro, int cinco) Explicação

Macros de linha produzem um número inteiro de linhas de saída na expansão delas. Pode existir melhor compatibilidade entre os processadores Texinfo (texi2any e TeX com texinfo.tex) para macros definidas com @linemacro que para aquelas definidas com @macro.
