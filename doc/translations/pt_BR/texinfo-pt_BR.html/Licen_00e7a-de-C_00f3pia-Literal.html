C.2 Licença de Cópia Literal ¶

Para manuais de software e outras documentações, é fundamental usar uma licença que permita redistribuição e atualização livres, de modo que quando um programa livre for mudado, a documentação também possa ser atualizada.

Por outro lado, para documentos que expressem tuas opiniões, sentimentos ou experiências pessoais, é mais apropriado usar uma licença que permita somente cópia literal.

Aqui está um texto de amostra para tal licença, permitindo somente cópia literal. Este é apenas o próprio texto da licença. Para um documento completo de amostra, vejam-se as seções anteriores. 

@copying
Este documento é uma amostra para permissão somente de cópia literal.

Copirraite @copyright{} 2026 Fundação do Software Livre, Inc.

@quotation
É concedida permissão para fazer e distribuir cópias literais
de todo este documento sem royalties, desde que o aviso de
copirraite e este aviso de permissão sejam preservados.
@end quotation
@end copying
