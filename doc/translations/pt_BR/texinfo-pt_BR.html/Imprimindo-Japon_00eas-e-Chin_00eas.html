19.6 Imprimindo Japonês e Chinês ¶

Texinfo vem com arquivos de suporte para processamento de entrada nos idiomas japonês e chinês.

Para japonês, você usa o arquivo texinfo-ja.tex. Teu arquivo de entrada principal deveria começar com uma linha ‘\input texinfo-ja’, em vez da padrão ‘\input texinfo’. Use a codificação de caracteres UTF-8 como de costume. Você precisa processar os arquivos ou com XeTeX ou com LuaTeX.

Para chinês, você usa o arquivo texinfo-zh.tex. Teu arquivo de entrada principal deveria começar com uma linha ‘\input texinfo-zh’, em vez da padrão ‘\input texinfo’. Use a codificação de caracteres UTF-8 como de costume. Você precisa processar os arquivos com XeTeX.

Por exemplo, você executaria ‘PDFTEX=xetex texi2pdf meu-arquivo-entrada.texi’ para usar XeTeX para produzir saída em PDF. Você possivelmente tenha que instalar o XeTeX (ou o LuaTeX), o pacote ‘zhspacing’ e(ou) pacotes de fontes.

Nem o japonês nem o chinês são suportados com o programa padrão TeX (ou o pdfTeX), pois ele não suporta as fontes e milhares de glifos necessários para esses idiomas.

A distribuição do Texinfo vem com alguns arquivos de amostra que você pode usar para testar o suporte para esses idiomas: ‘short-sample-ja.texi’ para japonês e ‘short-sample-zh.texi’ para chinês.

Para mais informações acerca dessas extensões para TeX, veja-se a página inicial do XeTeX e o site do LuaTeX.
