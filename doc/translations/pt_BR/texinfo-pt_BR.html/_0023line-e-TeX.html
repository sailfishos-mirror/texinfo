17.7.2 ‘#line’ e TeX ¶

Conforme mencionado, texi2any reconhece as diretivas ‘#line’ descritas na seção anterior. No entanto, texinfo.tex não reconhece e não consegue reconhecer. Portanto, tal linha será incorretamente tipografada literal se TeX a vir. A solução é a de usar as opções de expansão de macro do texi2any antes de se executar o TeX. Existem três abordagens:

  • Se você executar texi2dvi ou as variantes dele (veja-se Formatar com texi2dvi), poderá passar -E e texi2dvi executará texi2any primeiro para expandir macros e eliminar ‘#line’.
  • Se você executar texi2any, poderá especificar --no-ifinfo --iftex -E algumarquivo.out e, em seguida, fornecer algumarquivo.out para texi2dvi em um comando separado.
  • Ou você pode executar texi2any --dvi --Xopt -E. (Ou --pdf em vez de --dvi). texi2any então chamará texi2dvi -E.

Uma última ressalva relativa ao uso com TeX: como as diretivas #line não são reconhecidas, os números de linha emitidos pelo comando @errormsg{} (veja-se Comandos Condicionais), ou pelo próprio TeX, são os números de linha (incorretos) provenientes do arquivo derivado que o TeX estiver lendo, em vez dos números de linha especificados pelo preprocessador.
