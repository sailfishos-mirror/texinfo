9.1 Flutuadores ¶

Uma flutuação é uma exibição que é configurada a partir do texto principal. É tipicamente rotulada como sendo uma “Figura”, “Tabela”, “Exemplo” ou algum tipo similar.

Uma flutuação é assim nomeada porque, a princípio, ela pode ser movida para o final ou topo da página atual, ou para uma página seguinte, na saída impressa. (Flutuação não faz sentido em outros formatos de saída). Em cada formato de saída, exceto para LaTeX, no entanto, essa flutuação infelizmente ainda não está implementada. Em vez disso, o material flutuante simplesmente é gerado no local atual, mais ou menos como se fosse um @group (veja-se @group: Impedir Quebras de Página).

  • @float [tipo][,rótulo]: Material Flutuante
  • @caption e @shortcaption
  • @listoffloats: Sumários para Flutuadores
