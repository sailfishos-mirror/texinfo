9 Exibições Especiais ¶

Os comandos neste capítulo permitem que você escreva texto que seja especialmente exibido (permissão de formato de saída), fora do fluxo normal do documento.

Um conjunto de tais comandos é para criar “flutuações”, isto é, figuras, tabelas, e afins, configuradas a partir do texto principal, possivelmente numeradas, legendadas, e (ou) referenciadas a partir de outro lugar no documento. As imagens frequentemente são incluídas nessas exibições.

Outro grupo de comandos é para criar notas de rodapé no Texinfo.

  • Inserindo Imagens
  • Notas de Rodapé
