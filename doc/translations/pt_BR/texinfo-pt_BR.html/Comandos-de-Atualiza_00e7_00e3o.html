D.5.1 Os Comandos de Atualização ¶

Você consegue usar os comandos de atualização para:

  • inserir ou atualizar os ponteiros ‘Próximo’, ‘Anterior’ e ‘Acima’, de um nó,
  • inserir ou atualizar o menu para uma seção, e
  • criar um menu mestre para um arquivo fonte do Texinfo.

Você também consegue usar os comandos para atualizar todos os nós e menus em uma região ou em um arquivo inteiro do Texinfo.

Os comandos de atualização funcionam somente com arquivos convencionais do Texinfo, que sejam estruturados hierarquicamente como livros. Nesses arquivos, uma linha com um comando de estruturação precisa seguir logo depois de cada linha @node, exceto para a linha ‘Top’ do @node.

Você consegue escrever o comando de estruturação na linha que segue imediatamente depois de uma linha @node ou então na linha que segue depois de uma linha de @comment único ou de uma linha de @ifinfo único. Você não pode interpor mais que uma linha entre a linha @node e a linha do comando de estruturação; e você pode interpor somente uma linha @comment ou uma linha @ifinfo.

Comandos que funcionam sobre um buffer inteiro exigem que o nó ‘Top’ seja seguido por um nó com um @chapter ou comando de nível equivalente. Os comandos de atualização de menu não criarão um menu principal ou mestre para um arquivo do Texinfo que tenha somente nós de nível @chapter! Os comandos de atualização de menu criam somente nós de menus dentro para nós de nível inferior. Para criar um menu de capítulos, você precisa fornecer um nó ‘Top’.

Os comandos de atualização de menu removem entradas de menu que referenciem a outros arquivos do Info, uma vez que elas não referenciam a nós dentro do buffer atual. Isso é uma deficiência. Em vez de usar entradas de menu, você consegue usar referências cruzadas para referenciar a outros arquivos do Info. Nenhum dos comandos de atualização afeta referências cruzadas.

O modo Texinfo tem cinco comandos de atualização que são usados mais frequentemente: dois são para atualizar os ponteiros de nó ou menu de um nó único (ou região); dois são para atualizar cada ponteiro de nó e menu em um arquivo; e um, o comando texinfo-master-menu, é para criar um menu mestre para um arquivo completo e, opcionalmente, para atualizar cada nó e menu no arquivo inteiro do Texinfo.

O comando texinfo-master-menu é o comando primário:

C-c C-u m ¶
M-x texinfo-master-menu

Criar ou atualizar um menu mestre que inclua todos os outros menus (incorporando as descrições originárias de menus preexistentes, se existirem).

Com um argumento (argumento de prefixo, C-u, se interativo), primeiro criar ou atualizar todos os nós e todos os menus regulares no buffer antes de construir o menu mestre. (Veja-se O Nó Top e o Menu Mestre, para mais acerca de um menu mestre).

Para texinfo-master-menu funcionar, o arquivo do Texinfo precisa ter um nó ‘Top’ e pelo menos um nó subsequente.

Depois de editar extensivamente um arquivo do Texinfo, você pode digitar o seguinte: 

C-u M-x texinfo-master-menu

ou

C-u C-c C-u m

Isso atualiza todos os nós e menus completamente e de uma vez.

Os outros comandos principais de atualização realizam trabalhos menores e são projetados para a pessoa que atualiza nós e menus enquanto escreve um arquivo do Texinfo.

Os comandos são:

C-c C-u C-n ¶
M-x texinfo-update-node

Inserir os ponteiros ‘Próximo’, ‘Anterior’ e ‘Acima’ para o nó em que o ponto está (ou seja, para o ponto anterior da linha @node). Se a linha @node tiver ponteiros preexistentes ‘Próximo’, ‘Anterior’ ou ‘Acima’, os ponteiros antigos serão removidos e novos serão inseridos. Com um argumento (argumento de prefixo, C-u, se interativo), esse comando atualiza todas as linhas @node na região (que é o texto entre o ponto e a marca).

C-c C-u C-m ¶
M-x texinfo-make-menu

Criar ou atualizar o menu no nó em que o ponto está. Com um argumento (C-u como argumento de prefixo, se interativo), o comando cria ou atualiza menus para os nós que ou estejam dentro ou sejam uma parte da região.

Sempre que texinfo-make-menu atualizar um menu existente, as descrições originárias desse menu serão incorporadas no novo menu. Isso é feito copiando as descrições originárias do menu existente para as entradas no novo menu que tenham os mesmos nomes de nós. Se os nomes de nós forem diferentes, as descrições não serão copiadas para o novo menu.

C-c C-u C-e ¶
M-x texinfo-every-node-update

Inserir ou atualizar os ponteiros ‘Próximo’, ‘Anterior’ e ‘Acima’ para cada nó no buffer.

C-c C-u C-a ¶
M-x texinfo-all-menus-update

Criar ou atualizar todos os menus no buffer. Com um argumento (C-u como argumento de prefixo, se interativo), primeiro inserir ou atualizar todos os ponteiros de nó antes de trabalhar nos menus.

Se um menu mestre existir, o comando texinfo-all-menus-update o atualiza; mas o comando não cria um novo menu mestre se já não existir nenhum. (Usar o comando texinfo-master-menu para isso).

Ao trabalhar em um documento que não merece um menu mestre, você pode digitar o seguinte: 

C-u C-c C-u C-a

ou

C-u M-x texinfo-all-menus-update

Isso atualiza todos os nós e menus.

A variável texinfo-column-for-description especifica a coluna para a qual descrições de menu são recuadas. Por padrão, o valor é 32, embora possa ser útil reduzi-lo para 24. Você pode configurar a variável por meio de personalização (veja-se Personalização em O Manual do GNU Emacs) ou com o comando M-x set-variable (veja-se Examinando e Configurando Variáveis em O Manual do GNU Emacs).

Além disso, o comando texinfo-indent-menu-description pode ser usado para recuar descrições existentes de menu para uma coluna especificada. Finalmente, se desejar, você consegue usar o comando texinfo-insert-node-lines para inserir linhas @node ausentes em um arquivo. Em particular, você consegue ignorar completamente linhas @node em teu primeiro rascunho e então usar o comando texinfo-insert-node-lines para criar linhas @node para você. No entanto, nós não recomendamos essa prática. É melhor nominar o próprio nó ao mesmo tempo em que você escrever um segmento, de modo que consiga facilmente fazer referências cruzadas. Referências cruzadas úteis são um recurso especialmente importante de um bom manual do Texinfo. (Veja-se Outros Comandos de Atualização, para mais informações).
