5.15 @cite{referência} ¶

Use o comando @cite para o nome de um livro que careça de um arquivo complementar Info. Por exemplo, nós poderíamos referenciar Um Livro. O comando seleciona uma fonte inclinada no manual impresso e gera aspas no arquivo Info.

Se um livro for escrito em Texinfo, é melhor usar um comando de referência cruzada, pois um(a) leitor(a) consegue facilmente seguir tal referência no Info. Veja-se @xref.
