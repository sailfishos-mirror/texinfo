6.2.1 @emph{texto} e @strong{texto} ¶

Os comandos @emph e @strong são para ênfase; @strong é mais forte. Na saída impressa, @emph produz itálico e @strong produz negrito. Na saída Info, @emph envolve o texto com sublinhados (‘_’), e @strong coloca asteriscos em volta do texto.

Por exemplo, 

@strong{Cuidado:} @samp{rm * .[^.]*}
remove @emph{todos} os arquivos no diretório.

produz o seguinte:

Cuidado: ‘rm * .[^.]*’ remove todos os arquivos no diretório.

O comando @strong raramente é usado, exceto para marcar o que é, na verdade, um elemento tipográfico, como a palavra ‘Cuidado’ no exemplo precedente.

Cuidado: Não use @strong com a palavra ‘Observação’ seguida por um espaço; Info confundirá a combinação para uma referência cruzada. Use uma frase, como Por favor note ou Cuidado em vez disso, ou o argumento opcional para @quotation—‘Observação’ é permitido lá.
