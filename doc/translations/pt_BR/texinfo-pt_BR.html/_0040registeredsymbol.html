11.7.3 @registeredsymbol{} (®) ¶

Use o comando @registeredsymbol{} para gerar o símbolo de registrado(a), ‘®’. Onde possível, esse é um ‘R’ dentro de um círculo; do contrário, isso é ‘(R)’.
