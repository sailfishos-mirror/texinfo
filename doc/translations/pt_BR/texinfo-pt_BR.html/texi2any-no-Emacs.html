D.6.1 Executando texi2any/makeinfo no Emacs ¶

O programa texi2any fornece mensagens de erro melhores que qualquer um dos comandos de formatação do Emacs. Nós o recomendamos. O programa texi2any é independente do Emacs.

Você pode executar texi2any (ou makeinfo) no modo Texinfo do GNU Emacs usando ou o comando makeinfo-region ou o makeinfo-buffer. No modo Texinfo, os comandos estão vinculados a C-c C-m C-r e C-c C-m C-b por padrão.

C-c C-m C-r
M-x makeinfo-region

Formatar a região atual para Info.

C-c C-m C-b
M-x makeinfo-buffer

Formatar o buffer atual para Info.

Quando você invoca makeinfo-region a saída gerada vai para um buffer temporário. Quando você invoca makeinfo-buffer, a saída gerada vai para o arquivo configurado com @setfilename (veja-se @setfilename: Configure o Nome do Arquivo da Saída Gerada).

Os comandos makeinfo-region e makeinfo-buffer do Emacs executam o programa texi2any em um buffer temporário de shell. Se texi2any encontrar quaisquer erros, o Emacs exibe as mensagens de erro no buffer temporário.

Você pode analisar as mensagens de erro digitando C-x ` (next-error). Isso faz com que o Emacs vá e posicione o cursor na linha no fonte do Texinfo que texi2any acha que causou o erro. Veja-se Executando make ou Compiladores Geralmente em O Manual do GNU Emacs, para mais informações acerca de se usar o comando next-error.

Além disso, você consegue encerrar o shell no qual o comando texi2any estiver executando ou fazer o buffer do shell exibir a saída gerada mais recente dele.

C-c C-m C-k ¶
M-x makeinfo-kill-job

Terminar a atual tarefa texi2any (ou makeinfo) executando (a partir de makeinfo-region ou makeinfo-buffer).

C-c C-m C-l ¶
M-x makeinfo-recenter-output-buffer

Reexibir o buffer do shell do texi2any para exibir a saída gerada mais recente dele.

(Observe que os comandos paralelos para terminar e recentralizar uma tarefa do TeX são C-c C-t C-k e C-c C-t C-l. Veja-se Formatação e Impressão no Modo Texinfo).

Você pode especificar opções para texi2any configurando a variável makeinfo-options ou com o comando M-x customize ou com o M-x set-variable, ou configurando a variável em teu arquivo de inicialização .emacs.

Por exemplo, você poderia escrever o seguinte em teu arquivo .emacs: 

(setq makeinfo-options
     "--paragraph-indent=0 --no-split
      --fill-column=70 --verbose")

Para mais informações, veja-se
Interface de Fácil Personalização em O Manual do GNU Emacs,
Examinando e Configurando Variáveis em O Manual do GNU Emacs,
Arquivo de Iniciação em O Manual do GNU Emacs e
Opções do texi2any.
