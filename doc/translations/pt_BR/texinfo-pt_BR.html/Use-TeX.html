19.1 Use TeX ¶

O programa de tipografar chamado TeX é usado para formatar um documento do Texinfo para saída imprimível. TeX é um programa de tipografia muito poderoso e, quando usado corretamente, faz um trabalho excepcionalmente bom. Ele não está incluso no pacote do Texinfo, sendo uma vasta suíte de software em si.

TeX é um formatador de documento que é usado pela FSF para a documentação dela. É a maneira mais fácil de obter saída impressa (por exemplo, PDF e PostScript) para manuais do Texinfo. O TeX é redistribuível livremente e você pode obtê-lo pela Internet ou em mídia física. Veja-se http://tug.org/texlive.
