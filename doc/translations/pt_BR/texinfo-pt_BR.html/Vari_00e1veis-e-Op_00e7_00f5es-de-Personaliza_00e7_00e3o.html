20.4.2 Variáveis e Opções de Personalização ¶

A tabela a seguir fornece as variáveis de personalização associadas com algumas opções de linha de comando. Veja-se Invocando texi2any a partir de um Shell, para o significado das opções.

OptionVariável
--enable-encodingENABLE_ENCODING
--document-languagedocumentlanguage
--error-limitERROR_LIMIT
--fill-columnFILLCOLUMN
--footnote-stylefootnotestyle
--forceFORCE
--headersHEADERS, FORMAT_MENU
--internal-linksINTERNAL_LINKS
--macro-expandMACRO_EXPAND
--no-validatenovalidate
--no-warnNO_WARN
--node-filesNODE_FILES
--number-footnotesNUMBER_FOOTNOTES
--number-sectionsNUMBER_SECTIONS
--outputOUTFILE, SUBDIR
--paragraph-indentparagraphindent
--splitSPLIT
--split-sizeSPLIT_SIZE
--trace-includesTRACE_INCLUDES
--transliterate-file-namesTRANSLITERATE_FILE_NAMES
--verboseVERBOSE

Configurar tal variável de personalização para um valor ‘foo’ é essencialmente o mesmo que especificar --opt=foo se a opção receber um argumento, ou --opt se não.
