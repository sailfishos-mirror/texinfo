D.5 Atualizando Nós e Menus ¶

O comando texi2any criará um arquivo do Info para um arquivo do Texinfo organizado hierarquicamente que careça dos ponteiros ‘Próximo’, ‘Anterior’ e ‘Acima’ (veja-se Escrevendo uma Linha de @node). Assim, em geral, não existe necessidade para ponteiros explícitos ‘Próximo’, ‘Anterior’ e ‘Acima’. Nessa configuração, os menus serão adicionados automaticamente para nós sem um menu explícito. (Veja-se texi2any: O Tradutor para Texinfo, para mais informações acerca do texi2any).

Se você ainda quiser ponteiros explícitos, o modo Texinfo fornece comandos para criar ou atualizar automaticamente menus e ponteiros de nós. Os comandos são chamados de comandos de “atualização” porque o uso mais frequente deles é para atualizar um arquivo do Texinfo depois de você ter trabalhado nele; mas você consegue usá-los para inserir os ponteiros ‘Próximo’, ‘Anterior’ e ‘Acima’ em uma linha @node que não tenha nenhum e para criar menus em um arquivo que não tenha nenhum.
