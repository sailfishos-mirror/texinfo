4.4 @unnumbered, @appendix: Capítulos com Outra Rotulagem ¶

Use o comando @unnumbered para iniciar um elemento de nível de capítulo que aparece sem números de capítulos de qualquer tipo. Use o comando @appendix para iniciar um apêndice que é rotulado por letras (‘A’, ‘B’, …) em vez de números; apêndices também estão ao nível de estruturamento do capítulo.

Escreva um comando @appendix ou @unnumbered no início de uma linha e siga-o, na mesma linha, pelo título, exatamente como com @chapter.

Texinfo também fornece um comando @centerchap, o qual é análogo a @unnumbered, porém centraliza o argumento dele nas saídas impressa e HTML. Esse tipo de escolha estilística geralmente não é oferecida pelo Texinfo. Você está recomendado(a) a não usar esse comando, pois ele possivelmente seja removido em futuros lançamentos do Texinfo.

Com @unnumbered, se o nome do nó associado for uma destas palavras do Inglês (não diferencia maiúsculas de minúsculas): 

Acknowledgements  Colophon  Dedication  Preface

então a saída DocBook usará etiquetas especiais correspondentes (<preface>, entre outras) em vez da padrão <chapter>. O argumento para o próprio @unnumbered pode ser qualquer coisa, e é gerado como o elemento título como de costume.
