D.3 Inserindo Comandos Frequentemente Usados ¶

O modo Texinfo fornece comandos para inserir vários comandos @ frequentemente usados no buffer. Você consegue usar esses comandos para salvar as teclas digitadas.

Os comandos de inserção são invocados digitando-se C-c duas vezes e depois a primeira letra do comando @:

C-c C-c c ¶
M-x texinfo-insert-@code

Inserir @code{} e colocar o cursor entre as chaves.

C-c C-c d ¶
M-x texinfo-insert-@dfn

Inserir @dfn{} e colocar o cursor entre as chaves.

C-c C-c e ¶
M-x texinfo-insert-@end

Inserir @end e tentar inserir a palavra correta a seguir, como ‘exemplo’ ou ‘tabela’. (Esse comando não trata listas aninhadas corretamente, mas insere a palavra apropriada na lista imediatamente anterior).

C-c C-c i ¶
M-x texinfo-insert-@item

Inserir @item e colocar o cursor no início da próxima linha.

C-c C-c k ¶
M-x texinfo-insert-@kbd

Inserir @kbd{} e colocar o cursor entre as chaves.

C-c C-c n ¶
M-x texinfo-insert-@node

Inserir @node e uma linha de comentário listando a sequência para os nós ‘Próximo’, ‘Anterior’ e ‘Acima’. Deixar um ponto depois do @node.

C-c C-c o ¶
M-x texinfo-insert-@noindent

Inserir @noindent e colocar o cursor no início da próxima linha.

C-c C-c r ¶
M-x texinfo-insert-dwim-@ref

Essa função e ligação foram adicionadas no Emacs 27.1. Insere um de @pxref{}, @xref{} ou @ref{} baseado no texto ao redor do ponto; chamá-la perto de um parêntese aberto anterior não fechado resulta em @pxref{}, no início de uma frase ou em (point-min) produz @xref{}, qualquer outro local (inclusive dentro de uma palavra), resultará em @ref{}. Um argumento numérico diz quantas palavras as chaves deveriam envolver. Coloca o cursor entre as chaves.

C-c C-c s ¶
M-x texinfo-insert-@samp

Inserir @samp{} e colocar o cursor entre as chaves.

C-c C-c t ¶
M-x texinfo-insert-@table

Inserir @table seguido por um SPC e deixar o cursor depois de SPC.

C-c C-c v ¶
M-x texinfo-insert-@var

Inserir @var{} e colocar o cursor entre as chaves.

C-c C-c x ¶
M-x texinfo-insert-@example

Inserir @example e colocar o cursor no início da próxima linha.

C-c C-c { ¶
M-x texinfo-insert-braces

Inserir {} e colocar o cursor entre as chaves.

C-c } ¶
C-c ]
M-x up-list

Mover-se de entre um par de chaves em direção a depois da chave de fechamento. Digitar-se C-c ] é mais fácil que digitar C-c }, que é, no entanto, mais mnemônico; daí as duas combinações de teclas. (Além disso, você consegue sair de entre chaves digitando C-f).

Para colocar um comando como @code{…} em torno de uma palavra existente, posicionar o cursor em frente da palavra e digitar C-u 1 C-c C-c c. Isso facilita a edição de texto simples existente. O valor do argumento prefixo informa ao Emacs quantas palavras após o ponto incluir entre chaves—‘1’ para uma palavra, ‘2’ para duas palavras e assim por diante. Usar um argumento negativo para incluir a palavra, ou palavras, anterior. Se você não especificar um argumento de prefixo, o Emacs insere a sequência de caracteres do comando @ e posiciona o cursor entre as chaves. Esse recurso funciona somente para aqueles comandos @ que operam sobre uma palavra ou palavras dentro de uma linha, tais como @kbd e @var.

Este conjunto de comandos de inserção foi criado depois de se analisar a frequência com que diferentes comandos @ são usados no Manual do GNU Emacs e no Manual do GDB. Se desejar adicionar teus próprios comandos de inserção, você pode vincular uma macro de teclado a uma tecla, usar abreviações ou estender o código em texinfo.el.

C-c C-c C-d (texinfo-start-menu-description) é um comando de inserção que funciona diferentemente dos outros comandos de inserção. Ele insere uma seção de um nó ou título de capítulo no espaço para a descrição em uma linha de entrada de menu. (Uma entrada de menu tem três partes: o nome da entrada, o nome do nó e a descrição. Somente o nome do nó é exigido, mas uma descrição ajuda a explicar do que se trata o nó. Veja-se As Partes de um Menu).

Para usar texinfo-start-menu-description, posicionar o ponto em uma linha de entrada de menu e digitar C-c C-c C-d. O comando procura e copia o título que acompanha o nome do nó e insere o título como uma descrição; ele posiciona o ponto no início do texto inserido, de modo que você consiga editá-lo. A função não insere o título se a linha de entrada do menu já contiver uma descrição.

Esse comando é apenas uma ajuda para se escrever descrições; ele não faz todo o trabalho. Você precisa editar o texto inserido, pois um título tende a usar as mesmas palavras que um nome de nó, mas uma descrição útil usa palavras diferentes.
