11.1.6 Inserindo ‘&’ com @& e @ampchar{} ¶

Normalmente, um “e” comercial “&” é um caractere comum no Texinfo que pode ser simplesmente digitado na tua entrada, onde você precisar. O resultado é a tipografia do caractere “e” comercial.

No entanto, o caractere “e” comercial é tratado especialmente em apenas um contexto restrito. No argumento para um comando de definição (veja-se Comandos de Definição), um “e” comercial seguido por uma série de letras pode ser tipografado especialmente ao se processar com TeX7 (veja-se Convenções para Escrita de Definições). Por exemplo: 

@defun foo inteiro1 &optional inteiro2 &rest inteiros
@code{foo} descrito aqui.
@end defun

pode ter ‘&optional’ e ‘&rest’ formatados em negrito, mesmo sem nenhum comando @ envolvido.

Portanto, para a finalidade de tipografar um “e” comercial nesse contexto, é necessário usar @& ou alguma outra construção. Aqui está um exemplo de uma função C++ que recebe uma referência como parâmetro: 

@deftypefn Function int foo (const std::vector<int>@& @var{bar})
Documentação de @code{foo}.
@end deftypefn

Isso fornece a saída

Function: int foo (const std::vector<int>& bar) ¶

Documentação de foo.

Embora ‘@&’ e ‘@ampchar{}’ possam ser usados em quase qualquer lugar, não existe necessidade deles em nenhum lugar, exceto nesse caso incomum.

Notas de Rodapé

(7)

Essa sintaxe é usada para palavras-chave da Lisp do Emacs. Veja-se Uma Descrição de Função de Amostra em Manual de Referência da Lisp do GNU Emacs.
