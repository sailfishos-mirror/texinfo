E.3 @paragraphindent: Controlando Recuo do Parágrafo ¶

Os processadores do Texinfo podem inserir espaços em branco no início da primeira linha de cada parágrafo, recuando assim esse parágrafo. Você pode usar o comando @paragraphindent para especificar esse recuo. Escreva um comando @paragraphindent no início de uma linha seguido ou por ‘asis’ ou por um número: 

@paragraphindent recuo

O recuo fica de acordo com o valor de recuo:

asis

Não mude o recuo existente (não implementado na saída impressa).

none
0

Omita todo o recuo.

n

Recuar por n caracteres de espaço na saída Info, por n ems na saída impressa.

O valor padrão de recuo é 3. @paragraphindent é ignorado para saída HTML.

É melhor escrever o comando @paragraphindent antes da linha de fim do cabeçalho no início de um arquivo do Texinfo, de modo que os comandos de formatação de região recuem parágrafos conforme especificado. Veja-se Início do Cabeçalho.
