C.1 Textos GNU de Amostra ¶

A seguir está uma amostra de documento do Texinfo com os textos completos que deveriam ser usados (adaptados conforme necessário) nos manuais GNU.

Além dos textos jurídicos, também serve como exemplo prático de quantos elementos em um sistema GNU podem afetar o manual. Se você não estiver familiarizado(a) com todos esses diferentes elementos, não se preocupe. Eles não são obrigatórios e um manual perfeitamente bom pode ser escrito sem eles. No entanto, eles estão incluídos aqui porque muitos manuais se beneficiam (ou poderiam) deles.

Veja-se Amostra Curta, para um exemplo mínimo de um arquivo do Texinfo.

Aqui estão algumas observações acerca do exemplo:

  • O version.texi no comando @include é mantido automaticamente pelo Automake (veja-se Texinfo em GNU Automake). Ele configura os valores de ‘VERSION’, ‘UPDATED’ e ‘UPDATED-MONTH’ usados em outro lugar. Se tua distribuição não usar Automake, mas você usar Emacs, você pode achar o pacote time-stamp.el útil (veja-se Marcas Temporais em O Manual do GNU Emacs).
  • O comando @syncodeindex reflete a recomendação de usar apenas um índice sempre que possível, para facilitar para os(as) leitores(as) consultar as entradas do índice.
  • O @dircategory especifica uma categoria para o manual. Ele é usado para construir o diretório Info. Veja-se Categoria de Diretório, que inclui uma variedade de nomes recomendados de categorias. Veja-se Instalando Arquivos de Diretório Info.
  • O nó ‘Invocando’ é um padrão GNU para ajudar usuários(as) a encontrar informações básicas acerca do uso da linha de comando de um determinado programa. Veja-se Detalhes da Estrutura do Manual em Padrões GNU de Codificação.
  • Esta amostra mostra como incluir a Licença de Documentação Livre em um manual usando-se o comando @include. O arquivo fdl.texi está disponível no Texinfo e em outras distribuições do fonte GNU. Ele também está disponível no sítio web do GNU (em https://www.gnu.org/licenses/fdl-1.3.html) junto com orientações para usá-lo.
  • Se a Fundação do Software Livre não for a titular do copirraite, então usar o nome apropriado.
  • Para documentos que expressem tuas opiniões, sentimentos ou experiências pessoais, é mais apropriado usar uma licença que permita somente cópia literal, em vez da Licença de Documentação Livre. Veja-se Licença de Cópia Literal.

Aqui está um documento de amostra: 

\input texinfo   @c -*-texinfo-*-
@comment %**start of header
@include version-pt_BR.texi
@settitle Amostra GNU @value{VERSION}
@syncodeindex pg cp
@comment %**end of header
@copying
Este manual é para Amostra GNU (versão @value{VERSION}, @value{UPDATED}),
o qual é um exemplo na documentação do Texinfo.

Copirraite @copyright{} 2026 Fundação do Software Livre, Inc.

@quotation
É concedida permissão para copiar, distribuir e(ou) modificar este
documento sob os termos da Licença GNU de Documentação Livre, Versão 1.3
ou qualquer versão posterior publicada pela Fundação do Software Livre;
sem Seções Invariantes, sem Textos de Capa Frontal e sem Textos de
Contracapa. Uma cópia da licença está incluída na seção intitulada
``Licença GNU de Documentação Livre''.
@end quotation
@end copying

@dircategory Sistema de documentação Texinfo
@direntry
* amostra: (amostra)Invocando amostra.  amostra: (amostra)Invocando amostra
@end direntry

@documentinfo
@title Amostra GNU
@subtitle para versão @value{VERSION}, @value{UPDATED}
@author A.U. Thor (@email{bug-sample@@gnu.org})
@end documentinfo
@maketitle

@contents

@node Top
@top Amostra GNU

Este manual é para Amostra GNU (versão @value{VERSION}, @value{UPDATED}).

uso básico e opções de linha de comando dele aqui.
