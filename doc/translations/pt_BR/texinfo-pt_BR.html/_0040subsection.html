4.8 @subsection: Subseções Abaixo de Seções ¶

Subseções estão para seções como seções estão para capítulos; veja-se @section: Seções Abaixo de Capítulos. Por exemplo: 

@subsection Esta é uma subseção

Títulos de subseções são listados no sumário.
