F.6 Formato Info: Nós Regulares ¶

Nós regulares se parecem com isto: 

    <nó> =
<separador>
Arquivo: <fn>, Nó: <id1>, (Próximo: <id2>, )? (Anterior: <id3>, )? Acima:
<id4>

<texto geral, até o próximo ^_ ou final do arquivo>

Pelo menos um espaço ou tabulação precisa estar presente depois de cada dois pontos e vírgula, mas qualquer número de espaços será ignorado. Os identificadores de nó <id> têm o seguinte formato: 

    <id> = (<lparen><arquivoinfo><rparen>)?<especificações-nó>?
    <especificações-nó> = <nomenó> | <del><nomenó><del>
    <del> = ^?

Esse <nó> define <id1> no arquivo <fn>, o qual tipicamente é ‘nomemanual’ ou ‘nomemanual.info’. Nenhum componente <arquivoinfo> entre parênteses pode aparecer dentro de <id1>.

Cada um dos identificadores depois de Próximo, Anterior e Acima se refere a nós ou a âncoras dentro de um arquivo. Esses ponteiros normalmente se referem ao mesmo arquivo, mas ‘(dir)’ é frequentemente usado para apontar para o arquivo de diretório de nível superior. Se um componente <arquivoinfo> for usado, então o nome do nó poderá ser omitido; nesse caso, o identificador do nó se referirá ao nó ‘Topo’ dentro do arquivo referenciado.

Os ponteiros Próximo e Anterior são opcionais. O ponteiro Acima tecnicamente também é opcional, embora muito provavelmente indique um erro na estruturação do nó. Convencionalmente, os nós são organizados para formar uma árvore, mas isso não é uma exigência do formato.

Nomes de nós contendo pontos, vírgulas, dois pontos ou parênteses podem confundir leitores do Info. Se for necessário referir-se a um nó cujo nome contenha algum desses, o <nomenó> deveria ser envolvido por um par de caracteres DEL (‘CTRL-?’, caractere número 127). makeinfo adiciona esses caracteres quando necessário no caso padrão. Observe que nem todos os leitores do Info reconhecem essa sintaxe. Veja-se Restrições de Nomes de Nó do Info.

O <texto geral> do nó pode incluir os constructos especiais descritos a seguir.
