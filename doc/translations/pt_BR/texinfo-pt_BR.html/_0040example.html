7.4 @example: Texto de Exemplo ¶

O ambiente @example é usado para indicar entrada ou saída de computador que não seja parte do texto em execução. Se você quiser embutir fragmentos de código em frases, use o comando @code ou os parentes dele (veja-se @code{código-amostra}).

Escreva um comando @example sozinho no início de uma linha. Marque o final do bloco com @end example. Por exemplo, 

@example
cp foo @var{dest1}; \
 cp foo @var{dest2}
@end example

produz 

cp foo dest1; \
 cp foo dest2

A saída gerada usa uma fonte de largura fixa e é recuada. Cada linha no arquivo de entrada é uma linha na saída gerada; isto é, o texto fonte não é preenchido. Espaços extras e linhas em branco são significativos. Comandos do Texinfo são expandidos; se você quiser que a saída gerada seja a entrada literal, use o ambiente @verbatim em vez disso (veja-se @verbatim: Texto Literal).

Exemplos frequentemente estão, falando logicamente, “no meio” de um parágrafo, e o texto que continua após não deveria ser recuado, como no exemplo acima. O comando @noindent evita que um pedaço de texto seja recuado como se fosse um parágrafo novo (veja-se @noindent: Omitindo Recuo.

Se você desejar usar a fonte romana normal para um comentário de código, você pode usar o comando @r (veja-se Fontes para Impressão).

Você pode opcionalmente fornecer argumentos para o comando @example, separados por vírgulas, se existir mais que um. Na saída gerada HTML, quaisquer argumentos desse tipo são gerados como nomes de classe, prefixados pela sequência de caracteres ‘user-’. Isso pode ser útil para adicionar realce de sintaxe para manuais para amostras de código.

Nós recomendamos que, ao fornecer vários argumentos para @example, você use o primeiro argumento para especificar a linguagem do código (por exemplo ‘C’, ‘lisp’, ‘Cplusplus’). Você pode encontrar usos para outros argumentos, como fornecer uma dica de formatação ou marcar amostras de código para extração e processamento posterior, mas por enquanto nada definitivo é recomendado. Talvez isso mude em lançamentos futuros do Texinfo.

Cuidado: Não use tabulações nas linhas de um exemplo! (Ou em qualquer outro lugar no Texinfo, exceto em ambientes literais). TeX trata tabulações como espaços simples, e não é isso que elas parecem.
