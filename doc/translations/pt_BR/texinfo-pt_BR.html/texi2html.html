20.7 texi2html: Ancestral do texi2any ¶

Conceitualmente, o programa texi2html é o ancestral do programa texi2any atual. texi2html foi desenvolvido independentemente, originalmente por Lionel Cons em 1998; na época, makeinfo não conseguia gerar HTML. Muitas outras pessoas contribuíram para o texi2html ao longo dos anos.

O presente texi2any usa pouco do código real do texi2html e tem uma abordagem básica bastante diferente para a implementação (ou seja, analisar o documento Texinfo em uma árvore), mas ainda assim existe uma semelhança familiar.

Pelo projeto, o texi2any suporta quase todos os recursos do texi2html de alguma maneira. No entanto, nós não tentamos manter compatibilidade estrita, de forma que nenhum executável texi2html é instalado pelo pacote Texinfo. Uma aproximação pode ser executada com uma invocação como esta: 

texi2any --set-customization-variable TEXI2HTML=1 ...

porém, para enfatizar, isso não é um substituto imediato para o texi2html anterior. Aqui estão as maiores diferenças:

  • Mais descaradamente, as opções de linha de comando do texi2html agora são variáveis de personalização, em sua maior parte. Uma tabela de equivalentes aproximados é fornecida abaixo.
  • A API de personalização em nível de programa é muito diferente em texi2any.
  • Índices não podem ser divididos.

Nós não pretendemos reimplementar essas diferenças. Portanto, o caminho a seguir para autores(as) é o de alterar manuais e construir processos, conforme necessário, para usar os novos recursos e métodos do texi2any. Os(As) mantenedores(as) do texi2html (um dos quais é o autor principal do texi2any) não pretendem fazer novos lançamentos.
