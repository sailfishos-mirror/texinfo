6.1.1 Comandos de Realçamento são Úteis ¶

Os comandos servem a uma variedade de propósitos:

@code{código-modelo}

Indica texto que é um exemplo literal de um pedaço de um programa. Veja-se @code{código-amostra}.

@kbd{caracteres-de-teclado}

Indica entrada de teclado. Veja-se @kbd{caracteres-de-teclado}.

@key{nome-de-tecla}

Indica o nome convencional para uma tecla em um teclado. Veja-se @key{nome-tecla}.

@samp{texto}

Indica texto que é um exemplo literal de uma sequência de caracteres. Veja-se @samp{texto}.

@verb{texto}

Escreve uma sequência literal de caracteres. Veja-se @verb{chartextchar}.

@var{variável-metassintática}

Indica uma variável metassintática. Veja-se @var{variável-metassintática}.

@env{variável-de-ambiente}

Indica uma variável de ambiente. Veja-se @env{variável-ambiente}.

@file{nome-arquivo}

Indica o nome de um arquivo. Veja-se @file{nome-arquivo}.

@command{nome-comando}

Indica o nome de um comando. Veja-se @command{nome-comando}.

@option{opção}

Indica uma opção de linha de comando. Veja-se @option{nome-opção}.

@dfn{termo}

Indica o uso introdutório ou definidor de um termo. Veja-se @dfn{termo}.

@cite{referência}

Indica o nome de um livro. Veja-se @cite{referência}.

@abbr{abreviação}

Indica uma abreviação, como ‘Comput.’.

@acronym{sigla}

Indica uma sigla. Veja-se @acronym{sigla[, significado]}.

@indicateurl{localizador-uniforme-de-recurso}

Indica um exemplo (isto é, não funcional) de localizador uniforme de recurso. Veja-se @indicateurl{localizador-uniforme-de-recurso}. (Use @url (veja-se @url, @uref{url[, texto][, substituição]}) para URLs vivas).

@email{endereço-de-email[, texto-exibido]}

Indica um endereço de correio eletrônico. Veja-se @email{endereço-correio-eletrônico[, texto-exibido]}.
