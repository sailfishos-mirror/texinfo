5.11 @anchor: Definindo Alvos Arbitrários de Referências Cruzadas ¶

Talvez você deseje criar referências cruzadas para posições arbitrárias em um documento, não apenas para o início dos nós. O comando @anchor marca essa posição no teu documento, chamada âncora. Coloque um comando @anchor logo antes da posição que você deseja se referir. Por exemplo: 

Isso marca o ponto @anchor{x-spot}.
...
@xref{x-spot,,o ponto}.

Isso produz: 

Isso marca o ponto.
...
Veja-se [o ponto], página 1.

O argumento delimitado por chaves para @anchor, aqui ‘x-spot’, é o nome da âncora, que desempenha o mesmo papel que um nome de nó. O nome da âncora é usado para criar referências cruzadas para a âncora, como com um @xref ou com outro comando de referência cruzada, conforme mostrado (veja-se Referências cruzadas). Como você pode ver, o comando @anchor em si não produz saída.

Nomes de âncora compartilham as mesmas restrições que nós acerca de caracteres que podem ser incluídos (veja-se Restrições de Nomes de Nó do Info). Nomes de âncora, nomes de nós e rótulos de flutuadores não podem conflitar.

Você pode colocar o comando @anchor em uma linha própria se isso ajudar a legibilidade do fonte. Espaços em branco (incluindo novas linhas) são ignorados depois do @anchor.

Quando você deletar ou renomear um nó, geralmente é uma boa ideia definir um @anchor com o nome antigo. Dessa maneira, quaisquer linques para o nó antigo, sejam originários de outros manuais Texinfo ou de páginas web em geral, continuarão funcionando.

Por padrão, os linques para âncoras não são afetados pela configuração de xrefautomaticsectiontitle (veja-se xrefautomaticsectiontitle). Isso significa que o nome da âncora será usado como texto de rótulo na referência cruzada.

No entanto, você pode definir uma âncora nominada usando @namedanchor. O modelo é: 

@namedanchor{nome-âncora, nome-xref}

Use isso exatamente como faria com @anchor, exceto que o parâmetro adicional nome-xref fornece o texto para usar se xrefautomaticsectiontitle estiver ativado. Por exemplo: 

Isso marca o @namedanchor{x-spot, o ponto}ponto.
...
@set xrefautomaticsectiontitle on
@xref{x-spot}.

Isso produz: 

Isso marca o ponto.
...
Veja-se [o ponto], página 1.
