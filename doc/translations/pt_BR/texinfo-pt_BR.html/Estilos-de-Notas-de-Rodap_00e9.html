9.3.2 Estilos de Notas de Rodapé ¶

Formatos online tem dois estilos de nota de rodapé, que determinam onde o texto da nota de rodapé está localizado, o estilo de notas de rodapé ‘end’ e o ‘separate’.

‘end’ ¶

Para Info, no estilo de nó ‘end’, todas as notas de rodapé para um nó estão situadas no final desse nó. As notas de rodapé são separadas do resto do nó por uma linha de traços com a palavra ‘Notas de rodapé’ dentro dela. Cada nota de rodapé começa com uma marca de referência ‘(n)’.

Aqui está um exemplo da saída Info para uma nota de rodapé no estilo de fim de nó: 

--------- Notas de rodapé ---------

(1)  Aqui está uma nota de rodapé de amostra.

Em HTML, quando o estilo da nota de rodapé for ‘end’, ou se a saída não for dividida, as notas de rodapé são colocadas no final de cada arquivo de saída.

‘separate’ ¶

Para Info, no estilo de nó ‘separate’, todas as notas de rodapé para um nó são colocadas em um nó próprio construído automaticamente. Nesse estilo, uma “referência de nota de rodapé” segue cada marca de referência ‘(n)’ no corpo do nó. A referência da nota de rodapé é, na verdade, uma referência cruzada que você usa para atingir o nó da nota de rodapé.

O nome do nó com as notas de rodapé é construído pospondo-se ‘-Footnotes’ ao nome do nó que contém as notas de rodapé. (Consequentemente, o nó das notas de rodapé para o nó Footnotes é Footnotes-Footnotes)! O nó das notas de rodapé tem um ponteiro de nó ‘Acima’ que leva de volta para o nó ancestral dele.

Aqui está como a primeira nota de rodapé neste manual aparenta depois de ser formatada para o Info no estilo de nó separar: 

Arquivo: texinfo.info  Nó: Visão Geral-Notas de rodapé, Acima: Visão Geral

(1) A primeira sílaba de "Texinfo" é pronunciada como
"speck", não "hex". ...

Em HTML, quando o estilo da nota de rodapé for ‘separate’ e a saída for dividida, as notas de rodapé são colocadas em um arquivo separado.

A menos que teu documento tenha notas de rodapé longas e importantes (como em, por diga-se, Decline and Fall … de Gibbon), nós recomendamos o estilo ‘end’, pois ele é mais simples para leitores(as) seguirem.

Use o comando @footnotestyle para especificar o estilo de nota de rodapé. Escreva esse comando no início de uma linha seguido por um argumento, seja ‘end’ para o estilo de nó fim ou ‘separate’ para o estilo do nó separar.

Por exemplo, 

@footnotestyle end

ou 

@footnotestyle separate

Escreva um comando @footnotestyle no preâmbulo do arquivo Texinfo.
