6.1.15 @indicateurl{localizador-uniforme-de-recurso} ¶

Use o comando @indicateurl para indicar um localizador uniforme de recursos na Internet. Isso é puramente para propósitos de marcação e não produz um linque que você possa seguir (use o comando @url ou @uref para isso, veja-se @url, @uref{url[, texto][, substituição]}). @indicateurl é útil para URLs que não existem realmente. Por exemplo: 

Por exemplo, a URL poderia ser @indicateurl{http://exemplo.org/path}.

o que produz: 

Por exemplo, a URL poderia ser ‘http://exemplo.org/path’.

A saída oriunda de @indicateurl geralmente é semelhante àquela de @samp (veja-se @samp{texto}).
