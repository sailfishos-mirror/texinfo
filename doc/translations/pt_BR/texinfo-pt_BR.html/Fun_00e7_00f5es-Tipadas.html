14.6.2 Funções em Linguagens Tipadas ¶

O comando @deftypefn e as variantes dele são comandos genéricos para descrever funções. Eles são particularmente adequados para linguagens nas quais você precisa declarar tipos de variáveis e funções, como C e C++.

@deftypefn categoria tipo-dados nome argumentos… ¶

O comando @deftypefn é o comando geral de definição para funções e entidades similares que podem receber argumentos e que poderiam ser tipadas. O comando @deftypefn é escrito no início de uma linha e é seguido na mesma linha pela categoria da entidade sendo descrita, informações acerca do valor retornado, o nome dessa entidade específica e os argumentos dela, se existirem.

Por exemplo, 

@deftypefn {Função de Biblioteca} int foobar @
  (int @var{foo}, float @var{bar})
...
@end deftypefn

produz:

Função de Biblioteca: int foobar (int foo, float bar) ¶

…

Isso significa que foobar é uma “função de biblioteca” que retorna um int, e os argumentos dela são foo (um int) e bar (um float). ‘Função de Biblioteca’ tem de ser circundado por chaves para torná-lo um argumento unitário.

Ao usar o comando @deftypefn e variações, você deveria marcar os nomes dos parâmetros com @var para distingui-los dos nomes de tipos de dados, de palavras-chave e de outras partes da sintaxe literal da linguagem de programação.

Se você estiver descrevendo um procedimento em uma linguagem que tenha pacotes, como Ada, você pode considerar usar @deftypefn da seguinte maneira: 

@deftypefn pilhas privado push @
       (@var{s}:in out stack; @
       @var{n}:in integer)
...
@end deftypefn

(Nesses exemplos os argumentos de @deftypefn são mostrados usando-se continuações (veja-se Linhas de Continuação de Comando de Definição), mas poderiam estar em uma linha).

Nesse caso, o procedimento é classificado como pertencente ao pacote pilhas em vez de classificado como um ‘procedimento’ e o tipo de dados dele está descrito como privado. (O nome do procedimento é push, e os argumentos dele são s e n). Saída gerada:

pilhas: privado push (s:in out stack;  n:in integer) … ¶

@deftypefn e variantes poderiam ser usados quando for conveniente interpretar a lista de argumentos como código literal de computador, marcando os nomes dos argumentos com @var. Não é necessário para quaisquer nomes de tipo aparecer, e você pode fornecer um tipo de retorno vazio como ‘{}’.

As informações acerca dos valores de retorno podem ser usadas para nomear as variáveis de retorno. Por exemplo, na Perl, os escalares retornados podem receber os nomes $result e $status da seguinte maneira: 

@deftypefn {Sub} {(@var{$resultado}, @var{$situação}) =} @
                     process (@var{$entrada})
... Configurar @var{$situação} para 0 no caso de falha ...
@end deftypefn

para obter saída como

Sub: ($result, $status) = process ($input) ¶

… Set $status to 0 in case of failure …

@deftypefn cria uma entrada no índice de funções para nome.

@deftypefun tipo-dados nome argumentos… ¶

O comando @deftypefun é o comando especializado de definição para funções. O comando é equivalente a ‘@deftypefn Função …’.

@deftypefun cria uma entrada no índice de funções para nome.

Normalmente, o tipo de retorno é impresso na mesma linha que o nome da função e os argumentos, como mostrado acima. No código-fonte, o estilo GNU para funções tipadas é o de colocar o tipo de retorno em uma linha dedicada. Portanto, Texinfo fornece uma opção para fazer isso: @deftypefnnewline on.

Isso afeta somente funções genéricas—não funções não tipadas com argumentos simples, como @deffn, variáveis não tipadas, e outras coisas. Especificamente, afeta os comandos nesta seção e os comandos análogos para linguagens orientadas a objetos, ou seja, @deftypeop e @deftypemethod (veja-se Métodos Orientados a Objetos).

Especificar-se @deftypefnnewline off reverte para o padrão.
