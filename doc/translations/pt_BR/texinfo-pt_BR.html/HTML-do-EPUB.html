22.5.4 HTML Gerado para EPUB ¶

O HTML gerado para EPUB é compatível com XHTML, codificado em UTF-8 e formatado sem os habituais cabeçalhos e rodapés de navegação do HTML.

texi2any realiza isso internamente configurando variáveis de personalização, tais como USE_XML_SYNTAX, HEADERS ou OUTPUT_FILE_NAME_ENCODING. Alguns recursos da saída gerada impressa são usados no EPUB. Em particular, o nó Topo não aparece na saída gerada do EPUB, enquanto uma página de título é gerada. Isso é obtido configurando-se NO_TOP_NODE_OUTPUT. Veja-se Personalização da Saída Gerada HTML.

Os valores das variáveis de personalização OUTFILE e SUBDIR correspondem inicialmente ao contêiner do diretório EPUB e(ou) ao arquivo da saída EPUB (veja-se Diretório do Contêiner e Arquivos da Saída Gerada). Esses valores das variáveis de personalização são desdefinidos ou reconfigurados para os locais no diretório de contêiner onde os arquivos XHTML forem gerados para a geração de HTML.

Esse uso das variáveis de personalização pelo texi2any está mencionado aqui porque reconfigurar-se tais variáveis é incomum; no entanto, as variáveis reconfiguradas são usadas internamente para a conversão, e deveria não interagir com nenhuma personalização configurada pelo(a) usuário(a).
