2.10.1 Partes de um Menu Mestre ¶

Um menu mestre é o menu principal. É costumeiro incluir um menu detalhado listando todos os nós no documento nesse menu. Como qualquer outro menu, um menu mestre é envolvido em @menu e @end menu e não aparece na saída impressa nem na saída DocBook.

O menu mestre contém entradas para os principais nós no arquivo do Texinfo: os nós para os capítulos, seções do tipo capítulo e os apêndices, seguidos por nós para os índices.

Você pode escolher seguir essas entradas com um menu detalhado. Isso lista outros nós de nível inferior, frequentemente ordenados pelo capítulo. Esses itens podem ser uma conveniência para um inquérito que pode ir diretamente para um nó específico ao se procurar por informações específicas, em vez de se passar por um menu intermediário. Se você usar um menu detalhado no teu menu mestre, marque-o com o ambiente @detailmenu … @end detailmenu.

Cada seção no menu pode ser introduzida por uma linha descritiva. Contanto que a linha não se inicie com um asterisco, ela não será tratada como uma entrada de menu. (Veja-se Escrevendo um Menu, para mais informações).

Por exemplo, o menu mestre para este manual se parece com o seguinte (porém tem muito mais entradas): 

@menu
* Condições de Cópia:: Teus direitos.
* Visão Geral::        Texinfo em resumo.
...

* Índice de Variáveis::
* Índice Geral::



@detailmenu
--- A Listagem Detalhada do Nó ---

Visão geral do Texinfo

* Informando Defeitos:: ...
...



Iniciando um Arquivo do Texinfo

* Início de Amostra:: ...
...
@end detailmenu
@end menu
