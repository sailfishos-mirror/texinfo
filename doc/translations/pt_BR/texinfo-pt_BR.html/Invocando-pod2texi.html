20.6 Invocando pod2texi: Converter Pod para Texinfo ¶

O programa pod2texi traduz arquivo(s) de documentação Pod da Perl para Texinfo. Existem dois modos básicos de operação: gerar um manual independente a partir de cada Pod de entrada ou (se --base-level=1 ou superior for fornecido) gerar subarquivos Texinfo adequados para uso com @include.

O programa pod2texi pode ser útil fora do resto do Texinfo; assim, a invocação do pod2texi é documentada na linguagem Pod usando o formato de página de manual para seguir a convenção usada em programas autônomos da Perl, com uma versão na web https://www.gnu.org/software/texinfo/manual/pod2texi.html e uma versão incluída abaixo. A versão incluída no manual também é um exemplo de uso do pod2texi, pois ela é convertida a partir de Pod usando pod2texi.
