3.4 O Primeiro Nó ¶

O primeiro nó de um arquivo Texinfo é o nó Top, exceto em um arquivo incluído (veja-se Arquivos de Inclusão). O nó Top deveria conter um sumário curto e um menu mestre. Veja-se O Nó ‘Top’ para mais informações acerca do conteúdo e exemplos de nó Top. Texto reto antes do nó Top fora de qualquer nó deveria ser evitado. Tal texto, se presente, não é gerado para DocBook.

Aqui está uma descrição dos ponteiros de nó a serem usados no nó Top:

  • O nó Top (o qual precisa ser nomeado ‘top’ ou ‘Top’) deveria ter como nó dele ‘Acima’ o nome de um nó em outro arquivo, onde existe um menu que leva a esse arquivo. Especifique o nome de arquivo entre parênteses.

    Usualmente, todos os arquivos Info estão disponíveis por meio de uma árvore virtual única do Info, construída a partir de múltiplos diretórios. Nesse caso, use ‘(dir)’ como o ancestral do nó Top; isso especifica o nó de nível superior no arquivo dir, o qual contém o menu principal para o sistema Info como um todo. (Cada diretório com arquivos Info é destinado a conter um arquivo chamado dir).

    Isso está bom para Info, porém para saída HTML, alguém bem pode querer que o linque Acima oriundo do nó Top vá para algum lugar específico. Por exemplo, para GNU, o lugar natural seria https://www.gnu.org/manual/ (uma página da web que coleciona linques para a maioria dos manuais GNU), melhor especificada que apenas /manual/, se o manual será instalado em www.gnu.org. Isso pode ser especificado com a variável de personalização TOP_NODE_UP_URL (veja-se Personalização de Nomes de Arquivo e de Linques para HTML), como em 

    $ texi2any --html -c TOP_NODE_UP_URL=/manual/ ...
  • O nó ‘Anterior’ do nó Top é usualmente omitido.
  • O nó ‘Próximo’ do nó Top deveria ser o primeiro capítulo em teu documento.

Veja-se Instalando um Arquivo do Info, para mais informações acerca de instalar um arquivo Info no diretório info.

Geralmente, é melhor deixar os ponteiros completamente desligados e deixar que as ferramentas os definam implicitamente, com este resultado simples: 

@node Top
