21.1.4 Instalando Arquivos de Diretório Info ¶

Ao instalar um arquivo Info em teu sistema, você pode usar o programa install-info para atualizar o arquivo do diretório Info dir. Normalmente o makefile do pacote executa install-info, logo depois de copiar o arquivo Info para o local de instalação apropriado dele.

Para a finalidade de que o arquivo Info funcione com install-info, você inclui os comandos @dircategory e @direntry…@end direntry no arquivo fonte do Texinfo.

Usar @dircategory para especificar uma categoria para o manual, que determina em qual parte do diretório Info colocá-lo. (Veja-se Categoria de Diretório). Usar @direntry para especificar a entrada ou entradas de menu a serem adicionadas ao arquivo do diretório Info. Alguns manuais (como o manual que você está lendo agora, ou o do GNU Coreutils; veja-se GNU Coreutils) terão diversas entradas. É típico ter uma entrada de diretório para cada programa que um pacote instala, geralmente para o nó ‘Invocando’ do programa. Isso permite que os(as) usuários(as) encontrem facilmente a documentação para os diferentes programas que podem executar. Da mesma forma, um manual para uma biblioteca C pode instalar uma entrada de diretório para cada função que fornece.

Aqui está como esses comandos são usados neste manual: 

@dircategory Sistema de documentação do Texinfo
@direntry
* Texinfo: (texinfo).           O formato da documentação GNU.
* install-info: (texinfo)Invocando install-info. ...
...
@end direntry

Aqui está o que isso produz no arquivo Info: 

INFO-DIR-SECTION Sistema de documentação do Texinfo
START-INFO-DIR-ENTRY
* Texinfo: (texinfo).           O formato da documentação GNU.
* install-info: (texinfo)Invocando install-info. ...
...
END-INFO-DIR-ENTRY

O programa install-info vê essas linhas no arquivo Info e é assim que ele sabe o que fazer.

Sempre use os comandos @direntry e @dircategory próximos ao início da entrada do Texinfo, antes do primeiro comando @node. Se você usá-los posteriormente na entrada, install-info não os notará.

install-info automaticamente reformatará a descrição das entradas de menu que estiver adicionando. Por uma questão de convenção, a descrição da entrada principal (acima, ‘O formato da documentação GNU’) deveria começar na coluna 32, começando em zero (como em what-cursor-position no Emacs). Isso fará com que ele se alinhe com a maioria dos outros. É melhor que a descrição para utilitários individuais comece na coluna 48, sempre que possível. Para mais informações acerca de formatação, vejam-se as opções ‘--calign’, ‘--align’ e ‘--max-width’ em Invocando install-info.

Se você usar @dircategory mais de uma vez no fonte do Texinfo, cada uso especificará a categoria ‘atual’; quaisquer comandos @direntry subsequentes adicionarão a essa categoria.
