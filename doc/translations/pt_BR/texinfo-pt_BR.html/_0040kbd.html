6.1.3 @kbd{caracteres-de-teclado} ¶

Use o comando @kbd para caracteres de entrada a serem digitados por usuários(as). Por exemplo, para referenciar os caracteres M-a, escreva: 

@kbd{M-a}

e para referenciar os caracteres M-x shell, escreva: 

@kbd{M-x shell}

Por padrão, o comando @kbd produz uma fonte diferente (máquina de escrever inclinada em vez da de máquina de escrever normal, onde o formato da saída gerada permitir), de forma que os(as) usuários(as) consigam distinguir os caracteres que deveriam supostamente digitar a partir daqueles que o computador gera.

Dado que o uso de @kbd varia de manual para manual, você pode controlar a fonte comutando com o comando @kbdinputstyle. Esse comando não tem efeito sobre a saída Info. Escreva esse comando no início de uma linha com uma palavra como um argumento, uma das seguintes:

‘code’

Sempre use a mesma fonte para @kbd como @code.

‘example’

Use a fonte de distinção para @kbd somente em @example e ambientes similares.

‘distinct’

(o padrão) Sempre use a fonte de distinção para @kbd.

Você consegue embutir outro comando @ dentro das chaves de um comando @kbd. Aqui, por exemplo, está a maneira para descrever um comando que seria descrito mais detalhadamente como “pressione a tecla ‘r’ e então pressione a tecla RETURN”: 

@kbd{r @key{RET}}

Isso produz: r RET. (O presente manual usa o padrão para @kbdinputstyle).

Você também usa o comando @kbd se estiver soletrando as letras que digitar; por exemplo: 

Para dar o comando @code{logout},
digite os caracteres @kbd{l o g o u t @key{RET}}.

Isso produz:

Para dar o comando logout, digite os caracteres l o g o u t RET.

(Além disso, esse exemplo mostra que você pode adicionar espaços para maior clareza. Se você explicitamente quiser mencionar um caractere espaço como um dos caracteres da entrada, escreva @key{SPC} para ele).
