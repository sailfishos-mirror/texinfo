22.8.8 Interface e Licenças JavaScript ¶

Você pode adicionar uma interface de navegação JavaScript experimental à saída HTML configurando o valor de INFO_JS_DIR como o nome de um diretório no qual colocar o código para essa interface. Por exemplo, ‘texi2any --html -c INFO_JS_DIR=js manual.texi’ coloca arquivos em um diretório ‘js’ abaixo da saída gerada. Essa interface fornece algumas das funcionalidades dos navegadores Info em um navegador da Web, como navegação por teclado e pesquisa de índice. Isso funciona apenas com saída HTML não dividida.

Por padrão, uma página web de rótulos de licença JavaScript é configurada para fornecer informações de licenciamento e de código-fonte para qualquer JavaScript usado pela saída gerada HTML (veja-se https://www.gnu.org/licenses/javascript-labels.html). Para evitar gerar uma página web de rótulos de licença JavaScript, configure JS_WEBLABELS como ‘omit’. Com JS_WEBLABELS configurada como ‘generate’, o padrão, gerar uma página de rótulos em JS_WEBLABELS_FILE, js_licenses.html no caso padrão, e lincar a ela nos arquivos da saída gerada HTML. Com JS_WEBLABELS configurada como ‘reference’, lincar ao arquivo de rótulos fornecido por JS_WEBLABELS_FILE na saída gerada e não gerar um arquivo de rótulos. Essa última configuração é útil se você mantiver separadamente um arquivo de rótulos para um sítio web maior que inclua teu manual.

Arquivos de rótulos podem ser gerados se INFO_JS_DIR estiver configurada ou se HTML_MATH estiver configurada como ‘mathjax’ (veja-se Conjuntos de comandos sequenciados MathJax).
