D.10.4.1 Usando Info-validate ¶

Para usar Info-validate, visite o arquivo do Info que você desejar verificar e digite: 

M-x Info-validate

Observe que o comando Info-validate exige um ‘I’ maiúsculo. Você possivelmente necessite também criar uma tabela de etiquetas antes de executar Info-validate. Veja-se Etiquetando um Arquivo.

Se teu arquivo for válido, você receberá uma mensagem que diz “Arquivo parece válido”. No entanto, se você tiver um ponteiro que não apontar para um nó, mensagens de erro serão exibidas em um buffer chamado ‘*problems in info file*’.

Por exemplo, Info-validate foi executado sobre um arquivo de teste que continha somente o primeiro nó deste manual. Uma das mensagens dizia: 

No nó "Visão Geral", inválido Próximo: Modo Texinfo

Isso significava que o nó chamado ‘Visão Geral’ tinha um ponteiro ‘Próximo’ que não apontava para nada (o que era verdade nesse caso, já que o arquivo de teste tinha somente um nó nele).

Agora suponha que nós adicionássemos um nó chamado ‘Modo Texinfo’ ao nosso caso de teste, mas não especificássemos um ‘Anterior’ para esse nó. Então obteríamos a seguinte mensagem de erro: 

No nó "Modo Texinfo", deveria ter Anterior: Visão Geral

Isso ocorre porque, com uma estrutura padrão de documento, cada ponteiro ‘Próximo’ deveria ser correspondido por um ‘Anterior’ (no nó para onde o ‘Próximo’ aponta) que aponte para trás.

Info-validate também verifica se todas as entradas de menu e referências cruzadas apontam para nós reais.

Info-validate exige uma tabela de etiquetas e não funciona com arquivos que tiverem sido divididos. (O comando texinfo-format-buffer divide automaticamente arquivos grandes). Para a finalidade de usar Info-validate sobre um arquivo grande, você precisa executar texinfo-format-buffer com um argumento, de modo que ele não divida o arquivo do Info; e você precisa criar uma tabela de etiquetas para o arquivo não dividido.
