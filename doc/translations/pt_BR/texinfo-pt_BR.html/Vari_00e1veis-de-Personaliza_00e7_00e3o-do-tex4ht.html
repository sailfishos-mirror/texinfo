22.8.7.3 Variáveis de Personalização do tex4ht ¶

Esta tabela lista as variáveis de personalização que podem ser usadas quando tex4ht estiver sendo usado para converter seções @math, @displaymath, @tex e @latex para HTML. Estas variáveis de personalização serão relevantes somente se HTML_MATH estiver configurada como ‘t4h’.

Para realmente converter seções @tex, --iftex deveria ser usada; e para realmente converter seções @latex, --iflatex deveria ser usada.

T4H_LATEX_CONVERSION ¶

Se configurada, o tipo de conversão usado para seções @latex. As possibilidades são ‘latex’, ‘tex’ e ‘texi’. Configurada como ‘latex’ se não definida.

T4H_MATH_CONVERSION ¶

Se configurada, o tipo de conversão usado para @math e @displymath. As possibilidades são ‘latex’, ‘tex’ e ‘texi’. Configurada como ‘tex’ se não definida.

T4H_TEX_CONVERSION ¶

Se configurada, o tipo de conversão usado para seções @tex. As possibilidades são ‘latex’, ‘tex’ e ‘texi’. Configurada como ‘tex’ se não definida.
