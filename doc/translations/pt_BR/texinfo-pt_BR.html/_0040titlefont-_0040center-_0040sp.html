2.8.2.2 @titlefont, @center e @sp ¶

O Texinfo também fornece um segundo método para criar uma página de título, usando comandos de tipografia que não são usados no texto principal. Esse método usa os comandos @titlefont, @sp e @center para gerar uma página de título na qual as palavras na página ficam centralizadas.

Use o comando @titlefont para selecionar uma fonte grande adequada para o título em si. Você pode usar @titlefont mais que uma vez se tiver um título especialmente longo.

Para saída HTML, cada comando @titlefont produz um cabeçalho <h1>, porém o <title> do documento HTML não é afetado. Para isso, você poderia colocar colocar um comando @settitle antes do comando @titlefont (veja-se @settitle: Configura o Título do Documento).

Por exemplo: 

@titlefont{Texinfo}

Use o comando @center no início de uma linha para centralizar o restante do texto naquela linha. Assim, 

@center @titlefont{Texinfo}

centraliza o título, o qual neste exemplo é “Texinfo” impresso na fonte de título.

Use o comando @sp para inserir espaço vertical. Por exemplo: 

@sp 2

Isso insere duas linhas em branco na página impressa. (Veja-se @sp n: Inserir Linhas em Branco, para mais informações acerca do comando @sp).

Um modelo para esse método se parece com isto: 

@titlepage
@sp 10
@center @titlefont{nome-do-manual-quando-impresso}
@sp 2
@center subtítulo-se-algum
@sp 2
@center autor
...
@end titlepage

O espaçamento do exemplo se encaixa em um manual de 8,5 por 11 polegadas.
