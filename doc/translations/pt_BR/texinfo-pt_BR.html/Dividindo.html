D.9.2 Dividindo um Arquivo Manualmente ¶

Você deveria dividir um arquivo grande ou então deixar o comando texinfo-format-buffer ou makeinfo-buffer fazer isso para você automaticamente. (Geralmente você deixará um dos comandos de formatação fazer esse trabalho para você. Veja-se Formatação para Info).

Os arquivos divididos são chamados de subarquivos indiretos.

As tabelas de etiquetas são criadas automaticamente pelo comando de formatação; você só precisa criar uma tabela de etiquetas se estiver fazendo o trabalho manualmente. Veja-se Etiquetando um Arquivo, para informações acerca da criação de uma tabela de etiquetas.

Visite o arquivo do Info que você deseja etiquetar e dividir manualmente e digite os dois comandos: 

M-x Info-tagify
M-x Info-split

(Observe que o ‘I’ no ‘Info’ está maiúsculo).

Quando você usa o comando Info-split, o buffer é modificado em um (pequeno) arquivo do Info que lista os subarquivos indiretos. Esse arquivo deveria ser salvo no lugar do arquivo original visitado. Os subarquivos indiretos são escritos no mesmo diretório em que o arquivo original está, com nomes gerados pospondo-se ‘-’ e um número ao nome original do arquivo.

O arquivo primário ainda funciona como um arquivo do Info, mas ele contém apenas a tabela de etiquetas e um diretório de subarquivos. Veja-se Arquivos de Etiqueta e Arquivos Divididos.
