D.8 Sumário do Modo Texinfo ¶

No modo Texinfo, cada conjunto de comandos tem atalhos de teclado padrão que começam com as mesmas teclas. Todos os comandos que sejam personalizadamente criados para o modo Texinfo começam com C-c. As teclas são um tanto mnemônicas.

Comandos de Inserção ¶

Os comandos de inserção são invocados digitando-se C-c duas vezes e depois a primeira letra do comando @ a ser inserida. (Pode fazer mais sentido mnemonicamente usar C-c C-i, para ‘inserção personalizada’, mas C-c C-c é rápido de digitar). 

C-c C-c c       Inserir ‘@code’.
C-c C-c d       Inserir ‘@dfn’.
C-c C-c e       Inserir ‘@end’.
C-c C-c i       Inserir ‘@item’.
C-c C-c n       Inserir ‘@node’.
C-c C-c s       Inserir ‘@samp’.
C-c C-c v       Inserir ‘@var’.
C-c {       Inserir chaves.
C-c ]
C-c }       Mover para fora das chaves cercantes.


C-c C-c C-d     Inserir título da seção de um nó
               no espaço para a descrição
               em uma linha de entrada do menu.

Mostrar Estrutura ¶

O comando texinfo-show-structure frequentemente é usado em uma região estreitada. 

C-c C-s         Listar todos os títulos.

O Comando Mestre de Atualização ¶

O comando texinfo-master-menu cria um menu mestre; e também pode ser usado para atualizar cada nó e menu em um arquivo. 

C-c C-u m
M-x texinfo-master-menu
               Criar ou atualizar um menu mestre.



C-u C-c C-u m   Com C-u como um argumento de prefixo, primeiro
               criar ou atualizar todos os nós e menus regulares
               e, em seguida, criar um menu mestre.

Atualizar Ponteiros ¶

Os comandos de atualização de ponteiro são invocados digitando-se C-c C-u e, então, ou C-n para texinfo-update-node ou C-e para texinfo-every-node-update. 

C-c C-u C-n     Atualizar um nó.
C-c C-u C-e     Atualizar cada nó no buffer.

Menus de Atualização ¶

Invocar os comandos de atualização de menu digitando C-c C-u e, então, ou C-m para texinfo-make-menu ou C-a para texinfo-all-menus-update. Para atualizar ambos, nós e menus, ao mesmo tempo, preceder C-c C-u C-a com C-u. 

C-c C-u C-m     Criar ou atualizar um menu.


C-c C-u C-a     Criar ou atualizar todos
               os menus em um buffer.



C-u C-c C-u C-a Com C-u como um argumento de prefixo,
               primeiro criar ou atualizat todos os nós e, então,
               criar os atualizar todos os menus.

Formatar para Info ¶

Os comandos de formatação do Info que sejam escritos em Emacs Lisp são invocados digitando-se C-c C-e e, então, ou C-r para uma região ou C-b para o buffer inteiro.

Os comandos de formatação do Info que sejam baseados no programa texi2any/makeinfo são invocados digitando-se C-c C-m e, então, ou C-r para uma região ou C-b para o buffer inteiro.

Usar os comandos texinfo-format…: 

C-c C-e C-r     Formatar a região.
C-c C-e C-b     Formatar o buffer.

Usar texi2any/makeinfo: 

C-c C-m C-r     Formatar a região.
C-c C-m C-b     Formatar o buffer.
C-c C-m C-l     Recentralizar o buffer da saída do texi2any.
C-c C-m C-k     Encerra o trabalho de formatação do texi2any.

Tipografia e Impressão ¶

Os comandos de tipografia e de impressão do TeX são invocados digitando-se C-c C-t e, em seguida, outro comando de controle: C-r para texinfo-tex-region, C-b para texinfo-tex-buffer e assim por diante. 

C-c C-t C-r     Executar TeX sobre a região.
C-c C-t C-b     Executar texi2dvi sobre o buffer.
C-c C-t C-i     Executar texindex.
C-c C-t C-p     Imprimir o arquivo DVI.
C-c C-t C-q     Mostrar a fila de impressão.
C-c C-t C-d     Deletar um trabalho da fila de impressão.
C-c C-t C-k     Elimina o trabalho atual de formatação do TeX.
C-c C-t C-x     Fecha um trabalho de formatação do TeX atualmente interrompido.
C-c C-t C-l     Recentralizar a saída gerada de buffer.

Outros Comandos de Atualização ¶

Os comandos de atualização restantes não têm atalhos padrão de teclado porque raramente eles são usados. 

M-x texinfo-insert-node-lines
               Inserir linhas @node ausentes na região.
               Com C-u como argumento de prefixo,
               usar títulos de seção como nomes de nós.



M-x texinfo-multiple-files-update
               Atualizar um documento com vários arquivos.
               Com C-u 2 como um argumento de prefixo,
               criar ou atualizar todos os nós e menus
               em todos os arquivos incluídos primeiro.



M-x texinfo-indent-menu-description
               Recuar descrições.



M-x texinfo-sequential-node-update
               Inserir ponteiros de nó em sequência estrita.
