22.8.7.1 Variáveis de Personalização da MathJax ¶

Esta tabela lista as variáveis de personalização que podem ser usadas quando MathJax estiver sendo usado, o que será o caso quando HTML_MATH estiver configurada como ‘mathjax’.

MATHJAX_CONFIGURATION ¶

Dados a adicionar-se ao objeto de configuração global ‘MathJax’. Especifique como uma lista separada por vírgulas de pares de componente: { nome: valor, … }.

Por exemplo, você poderia configurar MATHJAX_CONFIGURATION para 

opções: { enableMenu: falso },
carregador: {
    carregar: [\'[tex]/physics\'],
    versionWarnings: falso
},
tex: {
  pacotes: {\'[+]\': [\'physics\']}
}

para desabilitar o menu do clique direito da MathJax e para carregar a extensão physics da MathJax. (Veja-se Configurando MathJax na documentação da MathJax).

Se você substituir qualquer um dos padrões para essa configuração gerada pelo texi2any, você deveria certificar-se de que tuas novas configurações alinhem-se com a saída HTML produzida pelo texi2any.

MATHJAX_SCRIPT ¶

URL do arquivo do componente MathJax (por exemplo tex-svg.js) que você estiver usando. texi2any fornece um valor padrão para essa variável, mas você é incentivado(a) a hospedar você mesmo(a) esse arquivo em teu sítio da web, de forma que não dependa da hospedagem de terceiros(as).

MATHJAX_SOURCE ¶

Uma URL do código-fonte completo na forma dela preferida para modificação, ou instruções para obter tal código-fonte, para o arquivo do componente nomeado por MATHJAX_SCRIPT. ‘Forma preferida para modificação’ significa que essa não deveria estar em uma forma ‘minificada’. Usada na página de rótulos de licença (veja-se Rótulos web de licença JavaScript).

Novamente, texi2any fornece um valor padrão para essa variável, mas você é incentivado(a) a hospedar você mesmo(a) o código-fonte para MathJax e as dependências dele. Isso é para a finalidade de tornar o código-fonte disponível confiavelmente e para reduzir tua dependência e a de teus usuários(as) dos sistemas de distribuição de terceiros(as).
