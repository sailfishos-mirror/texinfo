14.6.6 Programação Orientada a Objetos ¶

Aqui estão os comandos para formatar descrições acerca de objetos abstratos, tais como são usados em programação orientada a objetos. Uma classe é um tipo definido de objeto abstrato. Uma instância de uma classe é um objeto particular que tenha o tipo da classe. Uma variável de instância é uma variável que pertence à classe, mas para a qual cada instância tenha o próprio valor dela.
