5 Referências cruzadas ¶

Referências cruzadas são usadas para guiar o(a) leitor(a) para outras partes do mesmo ou de diferentes arquivo(s) Texinfo.

Use referências cruzadas para fornecer acesso a informações que sejam detalhadas demais para o contexto atual, ou incidental. Um sistema de ajuda online ou um manual de referência não é como um romance; poucos(as) leem tais documentos em sequência a partir do início até o final. Em vez disso, as pessoas buscam o que precisam. Por essa razão, tais criações deveriam conter muitas referências cruzadas para ajudar os(as) leitores(as) a achar outras informações que eles(as) podem não ter lido.

Em um manual impresso, uma referência cruzada resulta em uma referência de página, a menos que ela seja completamente para outro manual, caso no qual a referência cruzada nomeia esse manual. No Info, uma referência cruzada resulta em uma entrada que você pode seguir usando o comando ‘f’ do Info. (Veja-se Seguindo referências cruzadas em Info). Em HTML, uma referência cruzada resulta em um hiperlink. No DocBook, o elemento <link> é usado para referências cruzadas, a menos que ele seja para outro manual, caso no qual a referência cruzada nomeia esse manual.

Os vários comandos de referências cruzadas usam nós, âncoras (veja-se @anchor: Definindo Alvos Arbitrários de Referências Cruzadas) ou rótulos de flutuação (veja-se @float [tipo][,rótulo]: Material Flutuante) para definir locais de referências cruzadas. Quando o TeX gera um arquivo DVI, ele grava cada número de página do local da referência cruzada e usa os números de página na produção das referências. Assim, mesmo se você estiver escrevendo um manual que será somente impresso, e não usado online, você precisa, ainda assim, escrever linhas @node (ou âncoras @anchor) para a finalidade de nomear os lugares para os quais você faz referências cruzadas.
