D.1 Visão Geral do Modo Texinfo ¶

O modo Texinfo oferece recursos especiais para trabalhar com arquivos do Texinfo. Você consegue:

  • Inserir comandos @ frequentemente usados.
  • Criar automaticamente linha de @node
  • Mostrar a estrutura de um arquivo fonte do Texinfo.
  • Automaticamente criar ou atualizar os ponteiros ‘Próximo’, ‘Anterior’ e ‘Acima’ de um nó.
  • Automaticamente criar ou atualizar menus.
  • Automaticamente criar um menu mestre.
  • Formatar uma parte, ou todo, de um arquivo para Info.
  • Tipografar e imprimir parte, ou todo, de um arquivo.

Talvez os dois recursos mais úteis sejam aqueles para inserir comandos @ frequentemente usados e para criar ponteiros de nós e menus.
