21.1.1 O Arquivo de Diretório dir ¶

Para que o Info funcione, o diretório info precisa conter um arquivo que sirva como diretório de nível superior para o sistema Info. Por convenção, esse arquivo é chamado de dir. (Você pode encontrar o local desse arquivo no Emacs digitando C-h i para inserir Info e depois digitando C-x C-f para ver o local do diretório info).

O arquivo dir é em si um arquivo Info. Ele contém o menu de nível superior para todos os arquivos Info no sistema. O menu se parece com isto: 

* Menu:
* Info:    (info).     Sistema de navegação de documentação.
* Emacs:   (emacs).    O editor de texto extensível e
                      autodocumentado.
* Texinfo: (texinfo).  Com um arquivo fonte, faça ou um manual impresso
                      usando o @TeX{} ou um arquivo Info.
...

Cada uma dessas entradas de menu aponta para o nó ‘Top’ do arquivo Info que esteja nomeado entre parênteses. (A entrada do menu não precisa especificar o nó ‘Top’, uma vez que o Info vai para o nó ‘Top’ se nenhum nome de nó for mencionado. Veja-se Nós em Outros Arquivos do Info).

Assim, a entrada ‘Info’ aponta para o nó ‘Top’ do arquivo info e a entrada ‘Emacs’ aponta para o nó ‘Top’ do arquivo emacs.

Em cada um dos arquivos do Info, o ponteiro ‘Acima’ do nó ‘Topo’ referencia de volta para o arquivo dir. Por exemplo, a linha para o nó ‘Topo’ do manual do Emacs se parece com isto no Info: 

File: emacs  Node: Top, Up: (DIR), Next: Distribuição

Nesse caso, o nome do arquivo dir é escrito em letras maiúsculas—ele pode ser escrito ou em letras maiúsculas ou minúsculas. Isso não é verdade em geral; é um caso especial para dir.

Veja-se o arquivo util/dir-example na distribuição Texinfo para uma amostra grande do arquivo dir.
