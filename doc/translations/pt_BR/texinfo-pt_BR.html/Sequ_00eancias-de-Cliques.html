11.8.8 Sequências de Cliques ¶

Ao documentar interfaces gráficas, é necessário descrever sequências como ‘Clique em ‘Arquivo’, depois escolha ‘Abrir’, depois …’. O Texinfo oferece os comandos @clicksequence e click para representar isso, normalmente usados assim: 

... @clicksequence{Arquivo @click{} Abrir} ...

o que produz: 

... Arquivo → Abrir ...

O comando @click produz uma seta para a direita; esse glifo também está disponível independentemente por meio do comando @arrow{}.

O comando @clickstyle que poderia ser usado para mudar o glifo produzido por @click está obsoleto; você deveria não mais usá-lo. Você pode usar @alias (veja-se ‘@alias novo=existente’) para mudar o glifo produzido por @click.

Você pode substituir: 

@clickstyle @result

by 

@alias clique=resultado

O comando @clickstyle será removido em um lançamento futuro.
