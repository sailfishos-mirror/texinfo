6.1.10 @command{nome-comando} ¶

Use o comando @command para indicar os nomes de comandos, como ls ou cc.

@command é equivalente a @code nos efeitos dele. Por exemplo: 

O comando @command{ls} lista conteúdo de diretórios.

produz

O comando ls lista conteúdo de diretórios.

Você deveria escrever o nome de um programa na fonte comum de texto, em vez de usar @command, se considerá-lo uma nova palavra do inglês, como ‘Emacs’ ou ‘Bison’.

Quando escrever uma invocação inteira de comando de shell, como em ‘ls -l’, você deveria usar ou @samp ou @code a teu critério.
