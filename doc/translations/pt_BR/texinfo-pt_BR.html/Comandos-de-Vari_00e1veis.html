14.6.3 Variáveis e Entidades Similares ¶

Aqui estão os comandos para se definir variáveis e entidades similares:

@defvr categoria nome ¶

O comando @defvr é um comando geral de definição para algo como uma variável—uma entidade que registra um valor. Você precisa escolher um termo para descrever a categoria da entidade sendo definida; por exemplo, “Variável” poderia ser usado se a entidade fosse uma variável. Escreva o comando @defvr no início de uma linha e siga-o na mesma linha pela categoria da entidade e o nome da entidade.

Nós recomendamos maiusculizar o nome da categoria, como um título. Se o nome da categoria contiver espaços, como no nome “Opção de Usuário(a)”, circunde-o com chaves. Caso contrário, a segunda palavra será confundida com o nome da entidade. Por exemplo, 

@defvr {Opção de Usuário(a)} fill-column
Essa variável local e de buffer especifica
a largura máxima das linhas preenchidas.
...
@end defvr

Termine a definição com @end defvr em uma linha própria.

@defvr cria uma entrada no índice de variáveis para nome.

@defvar nome ¶

O comando @defvar é o comando de definição para variáveis. @defvar é equivalente a ‘@defvr Variável …’.

Por exemplo: 

@defvar kill-ring
...
@end defvar

@defvar cria uma entrada no índice de variáveis para nome.

@defopt nome ¶

O comando @defopt é o comando de definição para opções de usuário(a), ou seja, variáveis destinadas para usuários(as) mudarem de acordo com o gosto; Emacs tem muitas dessas (veja-se Variables em O Manual do GNU Emacs). @defopt é equivalente a ‘@defvr {Opção de Usuário(a)} …’.
