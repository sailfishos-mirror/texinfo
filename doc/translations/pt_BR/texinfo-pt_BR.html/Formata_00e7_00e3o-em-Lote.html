D.11 Formatação em Lote ¶

Você pode formatar arquivos do Texinfo para Info usando batch-texinfo-format e modo de lote do Emacs. Você pode executar o Emacs em modo de lote a partir de qualquer shell, incluindo um shell dentro do Emacs. (Veja-se Opções Iniciais em O Manual do GNU Emacs).

Aqui está um comando de shell para formatar todos os arquivos que terminem em .texinfo no diretório atual: 

emacs -batch -funcall batch-texinfo-format *.texinfo

O Emacs processa todos os arquivos listados na linha de comando, mesmo se um erro ocorrer enquanto tenta formatar alguns deles.

Execute batch-texinfo-format somente com Emacs em modo de lote conforme mostrado; ele não é interativo. Ele mata o modo de lote do Emacs após a conclusão.

batch-texinfo-format é conveniente se você carecer do texi2any e quiser formatar vários arquivos do Texinfo de uma vez. Ao usar o modo de Lote, você cria um novo processo do Emacs. Isso libera teu Emacs atual, de modo que você consiga continuar trabalhando nele. (Quando executar texinfo-format-region, ou texinfo-format-buffer, você não consegue usar esse Emacs para mais nada até que o comando termine).
