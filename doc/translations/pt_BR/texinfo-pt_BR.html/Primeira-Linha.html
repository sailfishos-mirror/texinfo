2.5.1 A Primeira Linha de um Arquivo do Texinfo ¶

Cada arquivo do Texinfo que deva ser a entrada de nível superior para TeX precisa começar com uma linha semelhante a esta: 

\input texinfo

Quando o arquivo for processado pelo TeX, o comando ‘\input texinfo’ diz ao TeX para carregar as macros necessárias para processar um arquivo do Texinfo. Elas estão em um arquivo chamado texinfo.tex, que deveria ter sido instalado no teu sistema ou junto com o software TeX ou com o Texinfo. O TeX usa a barra invertida, ‘\’, para marcar o início de um comando, exatamente como o Texinfo usa ‘@’. O arquivo texinfo.tex causa a comutação de ‘\’ para ‘@’; antes que a comutação ocorra, o TeX exige ‘\’, e é por isso que ela aparece no início do arquivo.

Opcionalmente, você pode seguir essa linha com um comentário para informar ao GNU Emacs para usar o modo Texinfo quando o arquivo for editado: 

\input texinfo   @c -*-texinfo-*-

Isso possivelmente seja útil quando o Emacs não detectar automaticamente o tipo do arquivo a partir da extensão do arquivo.
