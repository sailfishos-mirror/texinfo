22.8.7.2 Variáveis de Personalização do latex2html ¶

Esta tabela lista as variáveis de personalização que podem ser usadas quando latex2html estiver sendo usado para converter seções @math, @displaymath, @latex e @tex para HTML. Estas variáveis de personalização serão relevantes somente se HTML_MATH estiver configurada como ‘l2h’.

Para realmente converter seções @tex, --iftex deveria ser usada; e para realmente converter seções @latex, --iflatex deveria ser usada.

L2H_CLEAN ¶

Se configurada, os arquivos intermediários gerados em relação ao latex2html serão removidos; padrão verdadeiro.

L2H_FILE ¶

Se configurada, o arquivo fornecido será usado como arquivo de iniciação do latex2html; padrão desconfigurada.

L2H_HTML_VERSION ¶

A versão do HTML usada na chamada latex2html; padrão desconfigurada.

L2H_L2H ¶

O programa invocado como latex2html; padrão é latex2html.

L2H_SKIP ¶

Se configurada com um valor verdadeiro, a chamada real para latex2html será ignorada; o conteúdo gerado anteriormente será reusado. Se configurada como 0, o cache não será usado em absoluto. Se configurada como ‘undef’, o cache será usado para tantos fragmentos TeX quanto possível e para qualquer restante o comando será executado. O padrão é ‘undef’.

L2H_TMP ¶

Configurar o diretório usado para arquivos temporários. Nenhum dos componentes do nome de arquivo nesse nome de diretório pode começar com ‘.’; caso contrário, latex2html falhará (por causa do dvips). O padrão é a sequência vazia de caracteres, a qual significa o diretório atual.
