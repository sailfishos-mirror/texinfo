D.5.2 Exigências de Atualização ¶

Para usar os comandos de atualização, você precisa organizar o arquivo do Texinfo hierarquicamente com capítulos, seções, subseções e similares. Ao construir a hierarquia do manual, não ‘pule para baixo’ mais que um nível por vez: você pode seguir o nó ‘Top’ com um capítulo, mas não com uma seção; você pode seguir um capítulo com uma seção, mas não com uma subseção. Entretanto, você pode ‘pular para cima’ qualquer número de níveis ao mesmo tempo––por exemplo, de uma subseção para um capítulo.

Cada linha @node, com exceção da linha para o nó ‘Top’, precisa ser seguida por uma linha com um comando estruturante como @chapter, @section ou @unnumberedsubsec.

Cada combinação de linha @node/linha de comando estruturante precisa ou se parecer com esta: 

@node     Comentários,  Mínimo, Convenções, Visão Geral
@comment  nome-nó, próximo,    anterior,    acima
@section Comentários

ou com esta (sem a linha @comment): 

@node Comentários, Mínimo, Convenções, Visão Geral
@section Comentários

ou com esta (sem os ponteiros explícitos de nó): 

@node Comentários
@section Comentários

Neste exemplo, ‘Comentários’ é o nome de ambos, do nó e da seção. O próximo nó é denominado ‘Mínimo’ e o nó anterior é denominado ‘Convenções’. A seção ‘Comentários’ está dentro do nó ‘Visão Geral’, o qual é especificado pelo ponteiro ‘Acima’.

Se um arquivo tiver um nó ‘Top’, ele precisa ser chamado ‘top’ ou ‘Top’ e ser o primeiro nó no arquivo.

Os comandos de atualização de menu criam um menu de seções dentro de um capítulo, um menu de subseções dentro de uma seção e assim por diante. Isso significa que você precisa ter um nó ‘Top’ se quiser um menu de capítulos.
