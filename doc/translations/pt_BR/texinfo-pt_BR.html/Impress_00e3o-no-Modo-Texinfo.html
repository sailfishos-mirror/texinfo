D.7.1 Formatação e Impressão no Modo Texinfo ¶

O modo Texinfo fornece vários comandos de teclas predefinidos para formatação e impressão do TeX. Esses incluem comandos para ordenar índices, examinar a fila da impressora, encerrar o trabalho de formatação e recentralizar a exibição do buffer no qual as operações ocorrem.

Frequentemente, quando estiver escrevendo um documento, você desejará tipografar e imprimir somente parte de um arquivo para ver como ele ficará. Você consegue usar o texinfo-tex-region e comandos relacionados para essa finalidade. Use o comando texinfo-tex-buffer para formatar todo um buffer.

Para que texinfo-tex-region ou texinfo-tex-buffer funcionem, o arquivo precisa começar com uma linha ‘\input texinfo’ e precisa incluir uma linha @settitle. O arquivo precisa terminar com @bye sozinho em uma linha. (Ao usar texinfo-tex-region, você precisa envolver a linha @settitle com linhas de início de cabeçalho e de fim de cabeçalho).

C-c C-t C-b ¶
M-x texinfo-tex-buffer

Executar texi2dvi no buffer. Além de executar TeX no buffer, esse comando automaticamente cria ou atualiza índices conforme necessário.

C-c C-t C-r
M-x texinfo-tex-region

Executar TeX na região atual.

Se comandos @ relacionados à saída impressa estiverem entre as linhas de início de cabeçalho e de fim de cabeçalho, então texinfo-tex-region formatará a região de acordo. Por exemplo, se você escrever o comando @smallbook entre as linhas de início de cabeçalho e de fim de cabeçalho, texinfo-tex-region formatará a região no tamanho do livro “small”.

C-c C-t C-i
M-x texinfo-texindex

Executar texindex para ordenar os índices de um arquivo do Texinfo formatado com texinfo-tex-region. O comando texinfo-tex-region não executa texindex automaticamente; ele somente executa o comando de tipografia tex. Você precisa executar o comando texinfo-tex-region uma segunda vez depois de ordenar os arquivos brutos de índice com o comando texindex. (Normalmente, você não formata um índice ao formatar uma região, somente quando formata um buffer. Agora que o comando texi2dvi existe, existe pouca ou nenhuma necessidade para esse comando).

C-c C-t C-p
M-x texinfo-tex-print

Imprimir um arquivo DVI que foi criado com texinfo-tex-region ou texinfo-tex-buffer.

C-c C-t C-q
M-x tex-show-print-queue

Mostrar a fila de impressão.

C-c C-t C-d
M-x texinfo-delete-from-print-queue

Excluir um trabalho da fila de impressão; você será solicitado(a) a fornecer o número do trabalho mostrado por um comando C-c C-t C-q anterior (texinfo-show-tex-print-queue).

C-c C-t C-k
M-x tex-kill-job

Eliminar o trabalho TeX atualmente executando iniciado ou por texinfo-tex-region ou por texinfo-tex-buffer ou qualquer outro processo executando no buffer do shell do Texinfo.

C-c C-t C-x
M-x texinfo-quit-job

Encerre um trabalho de formatação do TeX que foi interrompido devido a um erro enviando um x para ele. Quando você faz isso, o TeX preserva um registro do que fez em um arquivo .log.

C-c C-t C-l
M-x tex-recenter-output-buffer

Reexibir o buffer do shell no qual os comandos de impressão e de formatação do TeX são executados para mostrar a saída gerada mais recente dele.

Assim, a sequência usual de comandos para formatar um buffer é a seguinte (com comentários à direita): 

C-c C-t C-b Executar texi2dvi no buffer.
C-c C-t C-p Imprimir o arquivo DVI.
C-c C-t C-q Exibir a fila da impressora.

Os comandos de formatação do TeX do modo Texinfo iniciam um subshell no Emacs chamado o *tex-shell*. Os comandos texinfo-tex-command, texinfo-texindex-command e tex-dvi-print-command são todos executados nesse shell.

Você consegue observar os comandos operarem no buffer ‘*tex-shell*’ e consegue comutar, para e de, e usar o buffer ‘*tex-shell*’ como faria com qualquer outro buffer de shell.

Os comandos de formatação e de impressão dependem dos valores de várias variáveis. Os valores padrão são: 

    Variável                              Valor padrão

texinfo-texi2dvi-command                  "texi2dvi"
texinfo-tex-command                       "tex"
texinfo-texindex-command                  "texindex"
texinfo-delete-from-print-queue-command   "lprm"
texinfo-tex-trailer                       "@bye"
tex-start-of-header                       "%**start"
tex-end-of-header                         "%**end"
tex-dvi-print-command                     "lpr -d"
tex-show-queue-command                    "lpq"

Você pode mudar os valores dessas variáveis com o comando M-x set-variable (veja-se Examinando e Configurando Variáveis em O Manual do GNU Emacs), ou com teu arquivo de inicialização .emacs (veja-se Arquivo de Iniciciação em O Manual do GNU Emacs).

A partir da versão 20, o GNU Emacs oferece uma interface amigável, chamada Customize, para mudança de valores de variáveis definíveis pelo(a) usuário(a). Veja-se Interface de Personalização Fácil em O Manual do GNU Emacs, para mais detalhes acerca disso. As variáveis do Texinfo podem ser encontradas no grupo ‘Development/Docs/Texinfo’, depois de invocar o comando M-x customize.
