E.10 Ampliação ¶

Você pode tentar direcionar o TeX para tipografar páginas maiores ou menores que o normal com o comando \mag do TeX. Tudo o que for tipografado é dimensionado proporcionalmente para maior ou para menor. (\mag significa “ampliação”). Esse não é um comando @ do Texinfo, mas é um comando bruto do TeX que é prefixado com uma barra invertida. Você tem que escrever esse comando entre @tex e @end tex (veja-se Comandos Brutos do Formatador).

Siga o comando \mag com um ‘=’ e depois um número que seja 1.000 vezes a ampliação que você desejar. Por exemplo, para imprimir páginas em tamanho normal 1,2, escreva o seguinte próximo ao início do arquivo do Texinfo, antes da página de título: 

@tex
\global\mag=1200
@end tex

Com algumas tecnologias de impressão, você consegue imprimir cópias de tamanho normal que aparentem melhor que o normal, fornecendo um mestre maior que o normal para tua gráfica. Elas fazem a redução, portanto aumentando efetivamente a resolução.

Dependendo do teu sistema, arquivos DVI preparados com um \mag não padrão possivelmente não imprimam ou possivelmente imprimam somente com determinadas ampliações. Esteja preparado(a) para experimentar.
