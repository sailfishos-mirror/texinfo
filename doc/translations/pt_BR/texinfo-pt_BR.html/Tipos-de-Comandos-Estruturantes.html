4.2 Tipos de Comandos Estruturantes ¶

Os comandos de estruturamento de capítulo se dividem em quatro grupos, cada um dos quais contendo comandos de estruturamento nos níveis de capítulos, seções, subseções e subsubseções:

  • Os comandos tipo @chapter e comandos tipo @appendix produzem entradas numeradas ou letradas, ambas no corpo de um documento e no sumário dele.
  • Os comandos tipo @unnumbered produzem entradas não numeradas, ambas no corpo de um documento e no sumário dele. O comando @top, o qual tem um uso especial, é um membro desse grupo (veja-se O Comando de Seccionamento @top). Uma seção @unnumbered é uma parte normal da estrutura do documento.
  • Os comandos tipo @heading produzem cabeçalhos não numerados simples que não aparecem em um sumário, não são associados com nós e não podem ser referenciados cruzadamente. Esses comandos de cabeçalhos nunca iniciam uma nova página.

Na saída gerada impressa, os comandos de estruturamento de capítulo produzem cabeçalhos no documento. Quando um comando @setchapternewpage diz para fazer isso, os comandos @chapter, @unnumbered e @appendix iniciam novas páginas no manual impresso; os comandos @heading não. Veja-se @setchapternewpage: Páginas em Branco Antes dos Capítulos.

Na saída Info e de texto simples, o comando faz com que o título apareça em uma linha por si só, com uma linha de um caractere ASCII (‘*’, ‘=’, …) inserido por baixo. Por exemplo, o cabeçalhos de “Estruturamento de Capítulo” poderia ser: 

5 Estruturamento de Capítulo
****************************

O caractere sublinhado é o mesmo para todos os comandos no mesmo nível. Por exemplo, é o mesmo para os comandos de nível de capítulo @chapter, @apppendix, @unnumbered e @chapheading.

No HTML, os comandos de nível de capítulo produzem um cabeçalho de nível <h2> por padrão (controlado pela variável de personalização CHAPTER_HEADER_LEVEL, veja-se Personalização da Saída Gerada Específica do HTML). O nível do elemento de cabeçalho é ajustado para os outros comandos.

Na saída gerada DocBook, o nível apropriado do elemento é usado. O elemento produzido inclui todas as seções seguintes até o próximo comando no mesmo nível ou superior. Por exemplo, um elemento <chapter> é produzido para @chapter, e contém quaisquer seções ou subseções no capítulo.
